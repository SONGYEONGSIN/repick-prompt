## 본문

```
당신은 시장 조사와 제품 포지셔닝을 담당하는 전략 분석가입니다.

아래 정보를 바탕으로 경쟁사 조사를 정리해주세요.
- 우리 제품/서비스: {{product}}
- 타깃 고객: {{target}}
- 조사 목적: {{purpose}}
- 비교하고 싶은 경쟁사: {{competitors}}
- 비교 기준: {{criteria}}

요구사항:
1. 직접 경쟁사와 간접 경쟁사를 구분해주세요. 고객은 대체재까지 함께 저울질하므로, 직접 경쟁사만 보면 진짜 위협과 시장을 놓치기 때문입니다.
2. 각 경쟁사의 핵심 메시지와 타깃 고객을 요약해주세요. 경쟁사가 누구에게 무엇을 약속하는지 알아야, 그들이 비운 자리에서 우리 자리를 찾을 수 있기 때문입니다.
3. 가격, 기능, 강점, 약점, 차별화 요소를 비교해주세요. 항목을 나란히 놓고 비교해야 감이 아닌 근거로 강약을 판단하고, 세일즈에서 바로 쓸 비교 우위가 드러나기 때문입니다.
4. 우리가 가져가야 할 포지셔닝 기회를 제안해주세요. 조사가 정보 나열로 끝나지 않고 '그래서 우리는 어디에 서야 하는가'라는 결론까지 가야 실무에 쓰이기 때문입니다.
5. 확실하지 않은 내용은 추정이라고 표시해주세요. AI의 경쟁사 정보는 오래됐거나 틀릴 수 있어, 추정과 사실을 구분해야 잘못된 정보로 전략을 세우는 걸 막기 때문입니다.

출력 형식:
- 시장 한 줄 요약
- 경쟁사 리스트
- 비교 표
- 경쟁사별 강점/약점
- 우리 제품의 포지셔닝 기회 3개
- 추가 리서치가 필요한 항목
```

## 해부

### 역할

> 시장 조사와 제품 포지셔닝을 담당하는 전략 분석가

'조사'와 '포지셔닝' 둘 다 역할에 넣어, 정보 나열에서 끝나지 않고 전략 제안까지 이어집니다.

### 맥락

> 우리 제품 / 타깃 / 조사 목적

'우리'가 누구인지 먼저 알려줘야 비교에 기준점이 생깁니다. 목적이 다르면 같은 경쟁사도 다르게 읽힙니다.

### 요구사항

> 직접 vs 간접 경쟁사 구분 / 추정 표시

'확실하지 않으면 추정이라고 표시' — AI가 아는 척하는 것을 막는 안전장치입니다. 리서치 프롬프트의 필수 문장.

### 출력 형식

> 비교 표 / 포지셔닝 기회 3개 / 추가 리서치 항목

'추가 리서치가 필요한 항목'을 요구하면 이 조사의 한계까지 받아볼 수 있습니다.

## 팁

- AI의 경쟁사 정보는 오래됐을 수 있습니다. 가격·기능은 반드시 공식 사이트에서 재확인하세요.
- 웹 검색이 가능한 AI라면 "최신 정보를 검색해서 반영해줘"를 붙이면 정확도가 올라갑니다.
