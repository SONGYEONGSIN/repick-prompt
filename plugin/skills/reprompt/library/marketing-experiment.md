# 마케팅 실험 기획

씨앗 — 사용자 제공 검증 프롬프트

## 필드

```json
[
  {
    "key": "goal",
    "label": "목표",
    "type": "text",
    "help": "숫자가 들어간 목표일수록 좋습니다.",
    "placeholder": "예: 한 달 안에 뉴스레터 구독자 500명"
  },
  {
    "key": "product",
    "label": "제품/서비스",
    "type": "text",
    "placeholder": "예: 프리랜서용 계약서 자동화 툴"
  },
  {
    "key": "target",
    "label": "타깃 고객",
    "type": "text",
    "placeholder": "예: 계약서 때문에 스트레스받는 1인 디자이너"
  },
  {
    "key": "channels",
    "label": "현재 채널",
    "type": "text",
    "placeholder": "예: 인스타그램 2천 팔로워, 블로그 월 5천 방문"
  },
  {
    "key": "constraints",
    "label": "제약 조건",
    "type": "text",
    "help": "예산·기간·인력. 솔직하게 적을수록 실행 가능한 안이 나옵니다.",
    "placeholder": "예: 월 30만원, 담당자 1명, 2주 단위"
  }
]
```

## 본문

```
당신은 적은 자원으로도 실행 가능한 마케팅 실험을 설계하는 그로스 매니저입니다.
다음 조건을 바탕으로 실험 기획안을 만들어주세요.

목표: {{goal}}
제품/서비스: {{product}}
타깃 고객: {{target}}
현재 채널: {{channels}}
제약 조건: {{constraints}}

요구사항:
- 실험 아이디어를 5개 제안할 것 — 하나에만 걸면 실패 시 대안이 없고, 여럿을 놓고 골라야 자원을 이길 만한 실험에 집중할 수 있기 때문.
- 각 아이디어에 가설, 실행 방법, 성공 지표를 포함할 것 — 이 셋이 없으면 결과가 나와도 왜 됐는지 몰라 다음 실험으로 배움이 쌓이지 않기 때문.
- 리소스 대비 기대 효과를 기준으로 우선순위를 매길 것 — 적은 자원으로는 다 할 수 없으니, 효율 높은 것부터 해야 같은 예산으로 더 많이 배우기 때문.
- 너무 추상적인 아이디어보다 2주 안에 실행 가능한 수준으로 구체화할 것 — 거창한 계획은 착수 전에 흐지부지되고, 2주 안에 돌려봐야 빠르게 배우고 다음으로 넘어가기 때문.
- 실패했을 때 무엇을 학습할 수 있는지도 적을 것 — 마케팅 실험은 대부분 실패하는데, 배울 것을 미리 정해둬야 그 실패가 낭비가 아니라 데이터가 되기 때문.

출력 형식:
1. 실험 아이디어 5개
2. 우선순위 추천
3. 이번 주 바로 시작할 실행안 1개
```

## 해부

### 역할

> 적은 자원으로도 실행 가능한 실험을 설계하는 그로스 매니저

역할 문장 안에 이미 제약('적은 자원')이 들어 있습니다. 대기업식 캠페인 제안을 원천 차단합니다.

### 맥락

> 목표 / 제품 / 타깃 / 현재 채널 / 제약

현재 채널을 알려주면 '0에서 시작'이 아니라 갖고 있는 자산을 활용하는 안이 나옵니다.

### 요구사항

> 가설·성공 지표 포함 / 2주 안에 실행 가능 / 실패 시 학습

실험의 3요소(가설-실행-지표)를 강제해, 해보고 끝나는 이벤트가 아니라 배움이 쌓이는 실험이 됩니다.

### 출력 형식

> 5개 → 우선순위 → 이번 주 실행안 1개

마지막이 '이번 주 실행안'이라 기획서가 아니라 할 일 목록으로 끝납니다.

## 팁

- 결과를 받은 뒤 "1순위 실험의 실행 체크리스트를 일자별로 쪼개줘"라고 하면 바로 착수할 수 있습니다.
- 지난 실험 결과가 있다면 함께 넣으세요. "지난달 인스타 광고는 CTR 0.5%로 실패" — 같은 실수를 반복하지 않습니다.
