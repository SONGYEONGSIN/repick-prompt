# 블로그 글 초안 작성

씨앗 — 사용자 제공 검증 프롬프트

## 필드

```json
[
  {
    "key": "topic",
    "label": "주제",
    "type": "text",
    "placeholder": "예: 프리랜서를 위한 세금 신고 가이드"
  },
  {
    "key": "reader",
    "label": "대상 독자",
    "type": "text",
    "placeholder": "예: 신고 경험이 없는 1년차 프리랜서"
  },
  {
    "key": "keywords",
    "label": "핵심 키워드",
    "type": "text",
    "help": "검색창에 입력될 법한 단어 2~3개. 쉼표로 구분.",
    "placeholder": "예: 프리랜서 세금, 종합소득세 신고"
  },
  {
    "key": "goal",
    "label": "글의 목표",
    "type": "select",
    "options": [
      "리드 확보",
      "브랜딩",
      "제품 소개",
      "교육"
    ]
  },
  {
    "key": "tone",
    "label": "톤앤매너",
    "type": "select",
    "options": [
      "전문적",
      "친근함",
      "실무형"
    ]
  },
  {
    "key": "length",
    "label": "분량",
    "type": "text",
    "placeholder": "예: 1800자"
  }
]
```

## 본문

```
당신은 한국어 콘텐츠 마케터이자 전문 에디터입니다.

아래 정보를 바탕으로 블로그 글 초안을 작성해주세요.
- 주제: {{topic}}
- 대상 독자: {{reader}}
- 핵심 키워드: {{keywords}}
- 글의 목표: {{goal}}
- 톤앤매너: {{tone}}
- 분량: {{length}}

요구사항:
1. 제목 후보 3개를 먼저 제안해주세요. 검색 유입은 제목에서 갈리므로, 여러 후보를 놓고 골라야 클릭을 부르는 각도를 잡을 수 있기 때문입니다.
2. 도입부에서 독자가 왜 이 글을 읽어야 하는지 분명히 보여주세요. 검색으로 들어온 독자는 첫 문단에서 원하는 답이 있는지 판단하고, 없다 싶으면 바로 뒤로가기를 누르기 때문입니다.
3. 본문은 h2, 필요 시 h3 구조로 나눠주세요. 헤딩 구조는 검색엔진이 글의 주제를 파악하는 신호이자, 독자가 필요한 대목으로 바로 건너뛰게 해주는 장치이기 때문입니다.
4. 사례, 체크리스트, 실수 방지 팁을 포함해주세요. 바로 써먹을 내용이 있어야 독자가 끝까지 읽고 저장하며, 그 체류 시간이 검색 순위로 이어지기 때문입니다.
5. 과장된 표현은 피하고, 한국어 문장을 자연스럽게 써주세요. 과장과 번역투는 신뢰를 떨어뜨리고, AI가 쓴 티가 나는 문장은 독자를 이탈시키기 때문입니다.
6. 마지막에는 핵심 요약과 CTA를 넣어주세요. 정보만 얻고 떠나기 쉬운 독자를 요약으로 각인시키고 CTA로 다음 행동에 붙잡아야 글이 성과로 이어지기 때문입니다.

출력 형식:
- 제목 후보 3개
- 최종 선택 제목 1개
- 메타 설명 1개 (120자 이내)
- 본문 초안
```

## 해부

### 역할

> 콘텐츠 마케터이자 전문 에디터

마케터(검색 유입 관점)와 에디터(문장 품질 관점) 두 역할을 겹치면 SEO와 가독성을 동시에 챙깁니다.

### 맥락

> 주제 / 독자 / 핵심 키워드 / 목표 / 톤 / 분량

키워드를 명시하면 제목·소제목에 자연스럽게 배치됩니다. 분량을 정하면 늘어지는 글을 막습니다.

### 요구사항

> h2/h3 구조 / 체크리스트 / 과장 금지

구조(헤딩)를 요구하면 검색엔진과 독자 모두에게 읽기 좋은 글이 됩니다.

### 출력 형식

> 제목 후보 3개 / 메타 설명 120자

메타 설명까지 한 번에 받으면 발행 준비가 끝난 상태로 결과를 받습니다.

## 팁

- 초안을 받은 뒤 "실제 사례 부분을 내 경험으로 교체할 테니 그 자리를 [사례] 로 비워줘"라고 하면 편집이 쉬워집니다.
- 경쟁 글 URL이나 제목을 주고 "이 글들과 겹치지 않는 각도로"라고 요청하면 차별화됩니다.
