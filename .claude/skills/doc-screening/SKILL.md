# 문서 판정 작업 하네스

비정형 문서(포스터·PDF·이미지)에서 조건과 규칙을 읽어 표로 고정하고, 명단·목록에 적용해 대상을 선별한 뒤 **지정된 형식 그대로** 결과 파일을 채운다.

아래 절차를 **순서대로** 수행한다. 각 단계의 `넘어가는 조건`을 충족하기 전에는 다음 단계로 가지 않는다. 여러 단계를 한 번에 처리하지 않는다.

## 0. 시작 전 확인

먼저 작업 폴더를 훑고 아래를 **표로** 보고한다. 이 표가 나오기 전에는 아무것도 만들지 않는다.

- 어떤 파일이 있는가 — 파일명, 형식(PDF·이미지·CSV·XLSX·문서), 무엇을 담고 있어 보이는가
- **결과를 어디에 어떤 형식으로 내야 하는가** — 채워야 할 파일이 이미 있으면 열어서 열 이름과 시트 구조를 그대로 읽어 적는다
- 지시서(`문제.md` 등)가 있으면 읽고 **목표 한 줄**과 **성공 기준**을 적는다
- 열리지 않거나 텍스트가 추출되지 않는 파일이 있으면 **그 사실을 지금 보고한다** (나중에 조용히 빈칸으로 두지 않는다)

> `넘어가는 조건`: 결과 형식(파일·시트·열 이름)을 적었고, 목표를 한 줄로 썼다.

## 1. 자료를 표로 바꾼다

표가 아닌 자료(포스터·안내문·계약서 PDF·이미지)에서 필요한 항목만 뽑아 **하나의 표**로 만든다.

- 양식이 제각각이어도 **같은 열**로 맞춘다. 문서마다 표현이 달라도 같은 뜻이면 같은 열에 넣는다
- **모든 값에 출처를 남긴다** — 어느 파일의 어디에서 나왔는지 (예: `CT-2023-045.pdf 3조`)
- 문서에 없는 값은 비워 두고 `[확인 필요]`로 표시한다. **추측해서 채우지 않는다**
- 표현이 애매해 해석이 갈리는 값도 `[확인 필요]`로 표시하고, 무엇이 애매한지 한 줄 적는다

> `넘어가는 조건`: 모든 행의 모든 값에 출처가 있거나 `[확인 필요]`가 붙어 있다. 출처 없는 값이 하나도 없다.

## 2. 규칙을 표로 고정한다

판정에 쓸 규칙을 **먼저 표로 만들고 나서** 적용한다. 머릿속에 두고 바로 판정하면 건마다 기준이 흔들린다.

- **조건이 자료 안에 있으면**(안내물의 자격 조건 등) 1단계 표에서 뽑아 규칙 표로 옮긴다
- **조건이 밖에서 주어지면**(지시서의 판정 규칙 등) 그 문장을 그대로 옮겨 적고, 판정 가능한 형태로 쪼갠다
- 규칙 하나당 한 행: `규칙 이름 / 판정 대상 / 조건 / 출처`
- 조건이 여러 개 걸리면 **그리고(AND)인지 또는(OR)인지**를 명시한다
- 규칙 표를 사용자에게 보여주고 넘어간다. **이 표는 이후 단계에서 바꾸지 않는다**

> `넘어가는 조건`: 규칙 표가 화면에 출력됐고, 각 규칙이 "예/아니오"로 판정 가능한 형태다.

## 3. 적용해서 판정한다

2단계 규칙 표를 **그대로** 각 건에 적용한다.

- 건마다 어떤 규칙에 걸렸는지, 왜 걸렸는지(어떤 값 때문인지)를 남긴다
- 규칙이 애매해 보여도 **여기서 바꾸지 않는다.** 애매하면 그 건을 `[확인 필요]`로 표시하고 넘어간다
- `[확인 필요]` 값이 있는 건은 판정을 **보류**로 두고, 어떤 값이 없어서 보류인지 적는다
- 건수를 센다 — 전체 몇 건 중 대상 몇 건, 비대상 몇 건, 보류 몇 건. 합이 전체와 맞는지 확인한다

> `넘어가는 조건`: 대상 + 비대상 + 보류의 합이 전체 건수와 일치한다.

## 4. 지정된 형식으로 낸다

0단계에서 읽은 형식에 **그대로** 맞춰 결과 파일을 채운다.

- 열 이름·순서·시트 이름을 **읽은 그대로** 쓴다. 더 좋아 보이는 이름으로 바꾸지 않는다
- 형식에 없는 열을 추가하지 않는다. 근거·메모는 별도 시트나 별도 파일로 뺀다
- 빈 셀은 비워 두되, 왜 비었는지 보류 목록에 남긴다

> `넘어가는 조건`: 결과 파일의 열 이름이 0단계에 적은 것과 글자 단위로 같다.

## 마지막. 자체 점검

아래를 하나씩 확인하고 **각 항목에 통과/문제를 적는다.** 문제가 있으면 고치고 다시 점검한다.

- [ ] **형식 일치** — 결과 파일의 시트·열 이름·순서가 0단계에 적은 것과 같은가
- [ ] **건수 일치** — 원본 건수와 결과 건수가 맞는가. 사라지거나 늘어난 건이 없는가
- [ ] **규칙 불변** — 3단계에서 적용한 규칙이 2단계 표와 같은가. 도중에 바뀐 규칙이 있는가
- [ ] **근거 추적** — 결과의 모든 값이 1단계 표에서 나왔는가. 출처 없는 값이 섞이지 않았는가
- [ ] **보류 보고** — `[확인 필요]`와 보류 건을 **한 곳에 모아** 목록으로 보고했는가

마지막으로 **보류 목록**을 출력한다: 무엇이 확인 안 됐고, 누구에게 무엇을 물어야 해결되는지.

## 이 하네스가 하지 않는 일

- 스캔 이미지의 글자 인식 품질은 보증하지 않는다 — 추출이 안 되면 0단계에서 알린다
- 규칙이 애매할 때 대신 결정해 주지 않는다 — 보류로 남긴다
- 결과가 업무적으로 옳은지는 판단하지 않는다 — **자료와 규칙에 맞는지까지**가 범위다

## 다른 환경에서 쓰기

이 문서는 외부 파일·링크를 참조하지 않는다. 스킬을 못 쓰는 환경에서는 **본문 전체를 첫 메시지로 붙여넣고** 작업 폴더 위치와 하려는 일을 한 줄 덧붙이면 동작이 같다.
