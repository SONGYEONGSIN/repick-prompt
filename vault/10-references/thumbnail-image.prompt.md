# 썸네일 이미지 생성 — 씨앗 프롬프트

- 카테고리: 이미지 생성
- 출처: 사용자 제공 검증 프롬프트 (라이브러리 slug: `thumbnail-image`)
- 요약: 주제와 분위기만 넣으면 유튜브나 SNS 썸네일에 맞는 이미지 생성 프롬프트를 만듭니다.

## 구조 강점
- **역할** — 역할 없이 조건만 주면 AI가 이미지를 직접 그리려 들거나 조건을 나열만 합니다. '프롬프트 전문가'로 고정해야 도구에 붙여넣을 완성형 프롬프트가 나옵니다.
- **조건 명세** — 이미지 생성은 형용사보다 명세가 중요합니다. '멋지게'는 통제 불가능하지만 '시네마틱 + 딥블루 + 16:9'는 재현 가능합니다.
- **구도 지시** — 썸네일은 작은 크기로 노출됩니다. 축소돼도 읽히는 구도를 요구사항으로 박아둡니다.
- **네거티브 조건** — 이미지 AI의 흔한 실패(왜곡, 잡동사니)를 미리 차단합니다. 원치 않는 것을 말하는 것도 프롬프트의 절반입니다.
- **출력 제한** — 설명 없이 결과만 받아 이미지 생성 도구에 바로 붙여넣을 수 있습니다.

## 본문

```
당신은 클릭률 높은 썸네일을 설계해온 이미지 프롬프트 전문가입니다.

아래 조건을 모두 반영한 썸네일 이미지 생성 프롬프트를 작성해주세요.

주제: {{topic}}
핵심 감정: {{emotion}}
스타일: {{style}}
주 피사체: {{subject}}
배경 요소: {{background}}
주 색상: {{color}}
비율: {{ratio}}
텍스트 포함 여부: {{text_included}}
피하고 싶은 요소: {{avoid}}

요구사항:
- 한눈에 주제가 보이도록 구도를 잡아주세요.
- 배경은 복잡하게 만들지 말고, 주 피사체가 잘 드러나게 해주세요.
- 클릭을 유도할 만한 대비와 긴장감을 살려주세요.
- 지나치게 난잡한 소품, 작은 디테일 남발, 의미 없는 텍스트는 피해주세요.
- 결과는 선명하고 상업용 썸네일 느낌이 나야 합니다.

최종 프롬프트만 출력해주세요.
```
