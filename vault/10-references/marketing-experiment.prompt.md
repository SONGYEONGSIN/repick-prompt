# 마케팅 실험 기획 — 씨앗 프롬프트

- 카테고리: 기획
- 출처: 사용자 제공 검증 프롬프트 (라이브러리 slug: `marketing-experiment`)
- 요약: 목표와 제약 조건만 주면 실행 가능한 마케팅 실험 아이디어와 우선순위를 기획안으로 정리합니다.

## 구조 강점
- **역할** — 역할 문장 안에 이미 제약('적은 자원')이 들어 있습니다. 대기업식 캠페인 제안을 원천 차단합니다.
- **맥락** — 현재 채널을 알려주면 '0에서 시작'이 아니라 갖고 있는 자산을 활용하는 안이 나옵니다.
- **요구사항** — 실험의 3요소(가설-실행-지표)를 강제해, 해보고 끝나는 이벤트가 아니라 배움이 쌓이는 실험이 됩니다.
- **출력 형식** — 마지막이 '이번 주 실행안'이라 기획서가 아니라 할 일 목록으로 끝납니다.

## 본문

```
당신은 적은 자원으로도 실행 가능한 마케팅 실험을 설계하는 그로스 매니저입니다.
다음 조건을 바탕으로 실험 기획안을 만들어주세요.

목표: {{goal}}
제품/서비스: {{product}}
타깃 고객: {{target}}
현재 채널: {{channels}}
제약 조건: {{constraints}}

요구사항:
- 실험 아이디어를 5개 제안할 것
- 각 아이디어에 가설, 실행 방법, 성공 지표를 포함할 것
- 리소스 대비 기대 효과를 기준으로 우선순위를 매길 것
- 너무 추상적인 아이디어보다 2주 안에 실행 가능한 수준으로 구체화할 것
- 실패했을 때 무엇을 학습할 수 있는지도 적을 것

출력 형식:
1. 실험 아이디어 5개
2. 우선순위 추천
3. 이번 주 바로 시작할 실행안 1개
```
