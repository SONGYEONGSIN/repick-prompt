# 블로그 글 초안 작성 — 씨앗 프롬프트

- 카테고리: 글쓰기
- 출처: 사용자 제공 검증 프롬프트 (라이브러리 slug: `blog-draft`)
- 요약: 주제와 독자, 핵심 키워드를 넣으면 검색 유입을 고려한 한국어 블로그 글 초안을 작성합니다.

## 구조 강점
- **역할** — 마케터(검색 유입 관점)와 에디터(문장 품질 관점) 두 역할을 겹치면 SEO와 가독성을 동시에 챙깁니다.
- **맥락** — 키워드를 명시하면 제목·소제목에 자연스럽게 배치됩니다. 분량을 정하면 늘어지는 글을 막습니다.
- **요구사항** — 구조(헤딩)를 요구하면 검색엔진과 독자 모두에게 읽기 좋은 글이 됩니다.
- **출력 형식** — 메타 설명까지 한 번에 받으면 발행 준비가 끝난 상태로 결과를 받습니다.

## 본문

```
당신은 한국어 콘텐츠 마케터이자 전문 에디터입니다.

아래 정보를 바탕으로 블로그 글 초안을 작성해주세요.
- 주제: {{topic}}
- 대상 독자: {{reader}}
- 핵심 키워드: {{keywords}}
- 글의 목표: {{goal}}
- 톤앤매너: {{tone}}
- 분량: {{length}}

요구사항:
1. 제목 후보 3개를 먼저 제안해주세요.
2. 도입부에서 독자가 왜 이 글을 읽어야 하는지 분명히 보여주세요.
3. 본문은 h2, 필요 시 h3 구조로 나눠주세요.
4. 사례, 체크리스트, 실수 방지 팁을 포함해주세요.
5. 과장된 표현은 피하고, 한국어 문장을 자연스럽게 써주세요.
6. 마지막에는 핵심 요약과 CTA를 넣어주세요.

출력 형식:
- 제목 후보 3개
- 최종 선택 제목 1개
- 메타 설명 1개 (120자 이내)
- 본문 초안
```
