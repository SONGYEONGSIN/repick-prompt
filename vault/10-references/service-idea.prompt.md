# 신규 서비스 아이디어 발상 — 씨앗 프롬프트

- 카테고리: 기획
- 출처: 사용자 제공 검증 프롬프트 (라이브러리 slug: `service-idea`)
- 요약: 타깃 고객과 문제만 넣으면 사업성, 차별화, MVP까지 고려한 서비스 아이디어를 제안합니다.

## 구조 강점
- **역할** — '검토하는'이 핵심입니다. 아이디어를 뿜는 역할이 아니라 걸러내는 역할을 주면 실현 가능성 중심으로 답합니다.
- **맥락** — 제약 조건(자원, 제외 방향)이 있어야 뜬구름 아이디어가 걸러집니다. 제약이 창의성을 만듭니다.
- **요구사항** — 아이디어의 품질 기준을 '재미'가 아니라 '지불 의사'로 고정합니다.
- **출력 형식** — 발산(7개) → 수렴(1개) → 행동(실험 3개)의 깔때기 구조로, 읽고 끝나는 게 아니라 실행으로 이어집니다.

## 본문

```
당신은 스타트업 아이디어를 검토하는 제품 전략가입니다.

아래 조건을 바탕으로 신규 서비스 아이디어를 제안해주세요.
- 타깃 고객: {{target}}
- 해결하고 싶은 문제: {{problem}}
- 활용 가능한 자원: {{resources}}
- 원하는 비즈니스 모델: {{business_model}}
- 제외하고 싶은 방향: {{exclude}}

요구사항:
1. 단순 나열 말고 실현 가능성이 있는 아이디어 위주로 제안해주세요.
2. 각 아이디어마다 고객이 돈을 낼 이유를 분명히 써주세요.
3. 차별화 포인트와 초기 MVP 범위를 함께 제시해주세요.
4. 리스크와 검증해야 할 가정도 같이 적어주세요.
5. 가장 유망한 아이디어 1개는 실행 순서까지 더 자세히 설명해주세요.

출력 형식:
- 아이디어 7개
- 각 아이디어별 문제/해결 방식/차별화/수익화/MVP/리스크
- 가장 유망한 아이디어 1개 상세안
- 다음 주에 검증할 실험 3개
```
