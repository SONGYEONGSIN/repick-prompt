# 역할
당신은 스타트업 인터뷰를 수백 건 설계해온 UX 리서처입니다. 창업자나 PM이 그대로 낭독할 수 있는 인터뷰 질문지를 만들어주세요.

# 맥락
- 리서치 주제: 가입 후 3일 이내 이탈(재접속 안 함)하는 사용자가 많은 이유
- 인터뷰 대상: 가계부 앱 '머니로그'를 설치하고 카드 연동까지 마쳤지만 가입 후 3일 이내 앱을 다시 열지 않은 사용자
- 검증하고 싶은 가설 (진행자만 참고, 응답자에게 직접 언급하지 않음): 카드 연동 과정의 보안 인증 절차가 복잡해서 설치 초반에 포기했을 것이라고 팀은 추정 중
- 리서치 단계: 문제 탐색 (아직 원인을 모름)
- 인터뷰 예상 시간: 30분
- 다루지 않을 주제: 소득·자산 규모에 대한 직접 질문, 프리미엄 요금제(월 9,900원) 가격 정책은 이미 확정되어 논의하지 않음

# 요구사항
1. 모든 핵심 질문은 미래 가정형("이 기능이 있으면 쓰시겠어요?", "~라면 하실 건가요?")이 아니라, 과거에 실제로 있었던 행동을 캐묻는 형태로 써주세요. 예: "최근에 비슷한 문제를 겪었을 때 실제로 어떻게 하셨나요?"
2. 카드 연동 과정의 보안 인증 절차가 복잡해서 설치 초반에 포기했을 것이라고 팀은 추정 중에서 암시하는 답을 질문 문장 안에 직접 넣지 마세요. 질문을 하나 쓸 때마다 "이 질문이 특정 답변 쪽으로 유도하고 있지 않은가?"를 스스로 점검하고, 유도성이 느껴지면 중립적인 표현으로 다시 써주세요.
3. 예/아니오로 끝나는 닫힌 질문은 전체 핵심 질문의 3분의 1을 넘기지 마세요. 핵심 질문마다 "조금 더 자세히 말씀해주시겠어요?", "구체적으로 어떤 상황이었는지 말씀해주실 수 있나요?" 같은 후속 캐묻기 문구를 하나씩 붙여주세요.
4. 문제 탐색 (아직 원인을 모름)가 "문제 탐색"이면 질문을 열어두고 사용자가 스스로 문제를 정의하게 하고, "솔루션 검증"이면 가설과 관련된 과거 행동을 구체적으로 캐묻되 가설을 정답처럼 제시하지 마세요.
5. 30분에 맞춰 질문 개수를 조절해주세요 (15분=핵심질문 3~4개, 30분=5~7개, 1시간=8~10개). 시간 안에 다 못 다룰 것 같으면 우선순위가 낮은 질문에 표시를 해주세요.
6. 라포 형성을 위한 도입 질문 1~2개와, 놓친 것이 없는지 확인하는 마무리 질문 1개를 포함해주세요.

# 출력 형식
## 인터뷰 목적 (진행자 전용, 응답자에게 보여주지 않음)
- 이번 인터뷰로 확인하려는 것을 1~2문장으로

## 도입 질문
- (질문 1~2개, 라포 형성용)

## 핵심 질문
각 질문마다 아래 3줄을 반복:
- 질문: (과거 행동을 캐묻는 문장)
- 후속 캐묻기: (구체화를 유도하는 후속 문구)
- 유도성 자가점검: (이 질문이 답을 암시하는지 스스로 판정한 한 줄. 예: "가설을 언급하지 않고 중립적으로 물음 - 통과" 또는 "OO 표현이 유도성이 있어 XX로 수정함")

## 마무리 질문
- (1개, 놓친 부분 확인용)

## 진행 전 체크리스트
- [ ] 닫힌 질문 비율이 전체 핵심 질문의 1/3 이하인가
- [ ] 어떤 질문도 카드 연동 과정의 보안 인증 절차가 복잡해서 설치 초반에 포기했을 것이라고 팀은 추정 중의 답을 직접 말하고 있지 않은가
- [ ] 각 핵심 질문에 후속 캐묻기가 붙어 있는가
- 다음 행동: 최소 5명 인터뷰 후 답변을 모아 패턴을 정리하세요 (인터뷰 인사이트 분석 템플릿 활용 권장)
