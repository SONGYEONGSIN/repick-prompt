# R6 결정 — 자기소개서 문항 답변

- **승자**: 후보 c — 프레임워크 내장 (자소서의 문법 내장: 두괄식·상황→과제→행동→결과·나의 기여·요구역량 연결 + 면접 세트 착지)
- **선택**: 휴먼 게이트 — 사용자가 추천안(심사 1위, 20/20) 승인
- **이유**: 4기준 어디에도 감점 없는 유일 응답. 결정적 차별점은 부속물 세트 — 제출 전 셀프 체크 4개 + 두괄식 첫 문장 대안 2개 + 면접 예상 질문·답변 포인트가 "오늘 바로 제출·검증"을 가장 직접 지원. 환각 0, "매출 15%"는 사장님 말씀으로 정직 귀속. 프레임워크 내장 5연속 승 (단 마진 0.5점 초박빙).
- **탈락 사유**:
  - b 프레임워크+가이드 결합 (19.5, 2위): 4문단 가독성 최고·3역량 정면 매핑이나, 회사 연결이 "소비자에게 더 자주 닿게" 수준으로 일반적 — 회사 맥락(현재 전략·제품)을 받는 빈칸이 회사명·직무 한 줄뿐이던 **필드 설계의 구조적 결과**. 신규 가설(구조+코치 help 결합) 자체는 0.5점 차 2위로 유효성 확인.
  - a 후속 질문형 (19, 3위): 회사 밀착 최고 + "15%" 리스크 선제 대응(검증 불가 수치 대체 제안)은 3후보 중 최고 평가. 그러나 스스로를 '초안'으로 규정 + 면접 답변에 내부 작성 메모("후속 질문 4번 답을 받아 보강 예정") 노출 + 허용량 84%만 사용 — 무편집 제출 리스크로 타이브레이커 패배. 신규 가설의 '되묻기' 요소는 부속물로선 강점, 본문 완성도 선언을 흔들면 감점.
- **방향 풀 교체 결과** (R2~R4 보고서 제안 이행): '최소 빈칸' 퇴출 후 3후보 전원 19+ — 라운드 바닥 점수가 12→19로 상승. 방향 풀 진화는 유효했다.
- **차기 관찰 메모**: ① 대상 밀착 문서(자소서·제안서)는 "대상의 현재 맥락(전략·제품·상황)"을 받는 빈칸이 회사 특정성을 가른다 (b의 감점 원인, a의 강점 원인 — 재현 시 원칙 승격). ② 후보 a의 "본문 안 내부 메모 노출"은 후속 질문형 설계 시 "부속물 섹션과 본문의 완성도 분리"로 방지 가능. ③ 공통 경미 확장("비교해봄"→"반영했다") — 3후보 동일이라 변별 아님, 메모만.
