# 벤더 비교 평가표 — 고객문의 티켓 관리 SaaS 벤더 선정

- 작성자: 이현우 (CS 오퍼레이션 매니저)
- 목적: 고객문의 티켓 관리 SaaS 벤더 선정 (최종 결정: 박서연 CS팀장)
- 대조 대상: 오르카데스크 / 헬로티켓 / 클리어헬프 (제안서 3건)
- 예산 상한: 25명 기준 월 100만원
- 확인 요청 기한: 다음주 화요일(8/25) 벤더 계약 논의 전까지

## 1. 집계 요약

기준 5개 × 벤더 3곳 대조, 충족 7·부분충족 3·미충족 2·확인필요 3

## 3. 판정 근거 상세

### ① 월 구독 비용(25명 기준)

- **오르카데스크 — 충족**: "25명 기준 월 92만원(인당 3.68만원)." (검토자 대조: 예산상한 100만원 대비 92만원으로 상한 이내)
- **헬로티켓 — 충족**: "25명 기준 월 78만원(인당 3.12만원)." (검토자 대조: 예산상한 100만원 대비 78만원으로 상한 이내, 3사 중 최저가)
- **클리어헬프 — 미충족**: "25명 기준 월 105만원(인당 4.2만원)." (검토자 대조: 예산상한 100만원을 5만원 초과)

### ② 응답 SLA(첫 응답시간 보장 여부)

- **오르카데스크 — 충족**: "응답 SLA는 평균 응답 30분 이내, 긴급 티켓은 10분 이내 보장한다고 계약서 SLA 조항에 명시되어 있습니다." — 계약서 SLA 조항에 명문화된 구체적 시간 보장.
- **헬로티켓 — 미충족**: ""고객 만족을 최우선으로 빠르게 응대합니다"라고만 되어 있고 구체적인 응답 시간 약속은 없습니다." — 제안서 스스로 구체적 시간 약속이 없음을 명시.
- **클리어헬프 — 부분충족**: "국내 상주 엔지니어가 30분 내 응답한다고 밝혔습니다." — 구체적 응답 시간(30분)은 제시되었으나, 오르카데스크와 달리 계약서 SLA 조항으로 명시되었다는 언급은 원문에 없어 보장 성격이 오르카데스크보다 약함.

### ③ 자체 CRM '고객허브' API 연동 가능 여부

- **오르카데스크 — 충족**: "REST API를 제공하며 고객허브와 연동한 사례가 있다고 소개했습니다(A사 레퍼런스)." — API 제공 및 실제 연동 사례(A사) 존재.
- **헬로티켓 — 부분충족**: "Zapier 연동은 지원하지만 고객허브 직접 연동은 "별도 문의 필요"라고 안내했습니다." — 간접 연동(Zapier)은 확인되나 고객허브 직접 연동 가능 여부는 원문 스스로 미확정 상태로 안내됨.
- **클리어헬프 — 충족**: "고객허브와는 사전 연동 인증을 이미 완료해 즉시 사용 가능하다고 설명했습니다." — 사전 연동 인증 완료로 즉시 사용 가능.

### ④ 고객 데이터 국내 리전 저장 여부

- **오르카데스크 — 확인 필요**: 제안서 원문(92만원/SLA/REST API/온보딩 관련 문장) 어디에도 데이터 저장 리전에 대한 언급이 없음.
- **헬로티켓 — 확인 필요**: 제안서 원문(78만원/응대 방침/Zapier·고객허브 연동/온보딩 관련 문장) 어디에도 데이터 저장 리전에 대한 언급이 없음.
- **클리어헬프 — 충족**: "AWS 서울(ap-northeast-2) 리전 기반으로 운영하며…" — 국내(서울) 리전 기반 운영을 명시.

### ⑤ 온보딩 지원 기간

- **오르카데스크 — 충족**: "온보딩은 전담 매니저를 배정해 최초 4주간 무료로 지원합니다." — 전담 매니저 배정, 4주 무료 지원이 조건 없이 명시됨.
- **헬로티켓 — 부분충족**: "온보딩은 2주간 무료로 지원하고 이후는 유료 컨설팅으로 전환됩니다." — 무료 지원 기간이 2주로 짧고, 이후 유료 전환 조건이 붙어 있음.
- **클리어헬프 — 확인 필요**: 제안서 원문(105만원/AWS 서울 리전/응답 시간/고객허브 연동 관련 문장) 어디에도 온보딩 지원 기간에 대한 언급이 없음.
