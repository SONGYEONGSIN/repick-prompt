## 2. 판정 근거 상세

### 기준 ①: 월 구독 비용(25명 기준, 예산 상한 월 100만원)

- **오르카데스크** — 원문: "25명 기준 월 92만원(인당 3.68만원)". 92만원은 상한 100만원 이내 → **충족**.
- **헬로티켓** — 원문: "25명 기준 월 78만원(인당 3.12만원)". 78만원은 상한 100만원 이내, 3사 중 최저가 → **충족**.
- **클리어헬프** — 원문: "25명 기준 월 105만원(인당 4.2만원)". 105만원은 상한 100만원 초과(검토자 계산: 105만원 − 100만원 = 5만원 초과) → **미충족**.

### 기준 ②: 응답 SLA(첫 응답 시간 보장 여부)

- **오르카데스크** — 원문: "응답 SLA는 평균 응답 30분 이내, 긴급 티켓은 10분 이내 보장한다고 계약서 SLA 조항에 명시되어 있습니다." 계약서 조항 형태의 명시적 보장 → **충족**.
- **헬로티켓** — 원문: "'고객 만족을 최우선으로 빠르게 응대합니다'라고만 되어 있고 구체적인 응답 시간 약속은 없습니다." 구체적 시간 보장이 없음이 제안서에 명시되어 있음 → **미충족**.
- **클리어헬프** — 원문: "국내 상주 엔지니어가 30분 내 응답한다고 밝혔습니다." 구체적 시간(30분)은 제시되었으나, 오르카데스크처럼 계약서 SLA 조항에 명시된 보장 문구는 확인되지 않음 → **부분충족**.

### 기준 ③: 자체 CRM '고객허브' API 연동 가능 여부

- **오르카데스크** — 원문: "REST API를 제공하며 고객허브와 연동한 사례가 있다고 소개했습니다(A사 레퍼런스)." REST API 제공 및 타사(A사) 연동 사례는 있으나, 본 건에 대한 직접 연동 확인은 아님 → **부분충족**.
- **헬로티켓** — 원문: "Zapier 연동은 지원하지만 고객허브 직접 연동은 '별도 문의 필요'라고 안내했습니다." 간접 연동 수단(Zapier)은 존재하나 고객허브 직접 연동 여부는 미확정 상태로 남아 있음 → **부분충족**.
- **클리어헬프** — 원문: "고객허브와는 사전 연동 인증을 이미 완료해 즉시 사용 가능하다고 설명했습니다." 사전 인증 완료 및 즉시 사용 가능이라는 직접적 확인 → **충족**.

### 기준 ④: 고객 데이터 국내 리전 저장 여부

- **오르카데스크** — 제안서 원문 어디에도 데이터 저장 리전에 대한 언급이 없음 → **확인 필요**.
- **헬로티켓** — 제안서 원문 어디에도 데이터 저장 리전에 대한 언급이 없음 → **확인 필요**.
- **클리어헬프** — 원문: "AWS 서울(ap-northeast-2) 리전 기반으로 운영하며" 국내 리전 운영이 명시됨 → **충족**.

### 기준 ⑤: 온보딩 지원 기간

- **오르카데스크** — 원문: "온보딩은 전담 매니저를 배정해 최초 4주간 무료로 지원합니다." 지원 기간과 방식이 구체적으로 명시됨 → **충족**.
- **헬로티켓** — 원문: "온보딩은 2주간 무료로 지원하고 이후는 유료 컨설팅으로 전환됩니다." 지원 기간과 이후 전환 조건이 구체적으로 명시됨 → **충족**.
- **클리어헬프** — 제안서 원문 어디에도 온보딩 지원 기간에 대한 언급이 없음 → **확인 필요**.
