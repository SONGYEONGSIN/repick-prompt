## 판정 근거 상세

### 1. 월 구독 비용(25명 기준) — 예산 상한: 25명 기준 월 100만원

- **오르카데스크**: 원문 — "25명 기준 월 92만원(인당 3.68만원)." (검토자 계산: 상한 100만원 대비 8만원 여유, 상한 미초과) → **충족**
- **헬로티켓**: 원문 — "25명 기준 월 78만원(인당 3.12만원)." (검토자 계산: 상한 100만원 대비 22만원 여유, 상한 미초과) → **충족**
- **클리어헬프**: 원문 — "25명 기준 월 105만원(인당 4.2만원)." (검토자 계산: 상한 100만원 대비 5만원 초과) → **미충족**

세 벤더의 절대 금액 비교(상대 서열)만 참고로 덧붙이면, 헬로티켓(78만원) < 오르카데스크(92만원) < 클리어헬프(105만원) 순으로 낮음. 단, 이는 상한 충족 여부 판정과 별개의 단순 금액 비교이며 종합 순위가 아님.

### 2. 응답 SLA(첫 응답 시간 보장 여부)

- **오르카데스크**: 원문 — "응답 SLA는 평균 응답 30분 이내, 긴급 티켓은 10분 이내 보장한다고 계약서 SLA 조항에 명시되어 있습니다." → 계약서 조항에 명시된 구체적 보장 시간이 있음 → **충족**
- **헬로티켓**: 원문 — "'고객 만족을 최우선으로 빠르게 응대합니다'라고만 되어 있고 구체적인 응답 시간 약속은 없습니다." → 제안서 자체가 구체적 보장 시간의 부재를 명시함 → **미충족**
- **클리어헬프**: 원문 — "국내 상주 엔지니어가 30분 내 응답한다고 밝혔습니다." → 30분 이내 응답을 명시적으로 밝힘 → **충족**

### 3. 자체 CRM '고객허브' API 연동 가능 여부

- **오르카데스크**: 원문 — "REST API를 제공하며 고객허브와 연동한 사례가 있다고 소개했습니다(A사 레퍼런스)." → 범용 REST API 제공 및 연동 사례 소개는 있으나, 이는 A사 레퍼런스로 소개된 사례이며 우리 측 고객허브에 대한 사전 인증·검증 완료를 명시한 문장은 없음 → **부분충족**
- **헬로티켓**: 원문 — "Zapier 연동은 지원하지만 고객허브 직접 연동은 '별도 문의 필요'라고 안내했습니다." → Zapier를 통한 간접 연동 경로는 있으나, 고객허브 직접 연동 가능 여부는 벤더 스스로 별도 확인이 필요하다고 안내함 → **부분충족**
- **클리어헬프**: 원문 — "고객허브와는 사전 연동 인증을 이미 완료해 즉시 사용 가능하다고 설명했습니다." → 사전 인증 완료 및 즉시 사용 가능을 명시적으로 설명 → **충족**

### 4. 고객 데이터 국내 리전 저장 여부

- **오르카데스크**: 제안서 원문 전체("25명 기준 월 92만원… REST API를 제공하며… 온보딩은 전담 매니저를 배정해 최초 4주간 무료로 지원합니다.")에 데이터 저장 리전에 관한 언급이 전혀 없음 → **확인 필요**
- **헬로티켓**: 제안서 원문 전체("25명 기준 월 78만원… Zapier 연동은 지원하지만… 온보딩은 2주간 무료로 지원…")에 데이터 저장 리전에 관한 언급이 전혀 없음 → **확인 필요**
- **클리어헬프**: 원문 — "AWS 서울(ap-northeast-2) 리전 기반으로 운영하며" → 국내 리전(서울) 기반 운영을 명시 → **충족**

### 5. 온보딩 지원 기간

- **오르카데스크**: 원문 — "온보딩은 전담 매니저를 배정해 최초 4주간 무료로 지원합니다." → 전담 매니저 배정 및 4주 무료 지원을 명시 → **충족**
- **헬로티켓**: 원문 — "온보딩은 2주간 무료로 지원하고 이후는 유료 컨설팅으로 전환됩니다." → 2주 무료 지원은 명시되어 있으나 이후 유료 전환이라는 제약이 함께 명시됨 → **부분충족**
- **클리어헬프**: 제안서 원문 전체("25명 기준 월 105만원… AWS 서울 리전 기반으로 운영하며… 고객허브와는 사전 연동 인증을 이미 완료해 즉시 사용 가능하다고 설명했습니다.")에 온보딩 지원 기간에 관한 언급이 전혀 없음 → **확인 필요**
