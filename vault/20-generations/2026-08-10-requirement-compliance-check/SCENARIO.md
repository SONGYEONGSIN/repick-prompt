# SCENARIO — 규정·요건 대조표 (2026-08-10)

현실적인 초보자 입력값 세트. 심사자는 이 문서만 보고 결과물의 정당한 문구와 창작을 구분한다 — 여기 없는 사실이 결과물에 나오면 창작이다.

## 상황

스타트업 **클로버플로우**의 보안담당 **정하윤**(정보보호팀 대리)이, 클라우드 문서저장 서비스 벤더 **파일드라이브社**와 정식 계약을 맺기 전에 벤더가 보내온 **서비스 이용약관(계약서 초안)**을 사내 **벤더 보안 요건 체크리스트** 8개 항목과 하나하나 대조한다. 결과는 **정보보호팀장 오세훈**(서명 승인권자)에게 전달되어 "이대로 서명해도 되는지, 조건부로 서명해야 하는지"를 정하는 데 쓰인다. 검토 기한은 **8/14(금) 오후 계약 서명 미팅 전까지**.

## 벤더 보안 요건 체크리스트 (8개 항목)

```
1. (필수) 고객 데이터는 국내 리전에 저장되거나, 저장 위치(국가/리전)가 계약서에 명시되어야 한다.
2. (필수) 침해사고 발생 시 72시간 이내에 고객에게 통지해야 한다.
3. (필수) 계약 종료 시 고객 데이터를 파기하고, 요청 없이도 파기확인서를 제공해야 한다.
4. (권장) 연 1회 이상 보안 감사 보고서(또는 동등 자료)를 제공해야 한다.
5. (필수) 제3자(하도급업체·서브프로세서)에게 데이터 처리를 위탁할 경우 사전 서면 동의를 받아야 한다.
6. (권장) 벤더의 배상 책임 상한이 연간 계약금액의 2배 이상이어야 한다.
7. (필수) 서비스 중단 또는 가격 변경 시 최소 30일 전에 사전 고지해야 한다.
8. (권장) SOC2 Type II 또는 동등한 제3자 보안 인증을 보유해야 한다.
```

## 파일드라이브社 서비스 이용약관 (계약서 초안, 발췌)

```
제2조(서비스 변경 및 중단) 3항: 회사는 서비스 내용 변경 또는 중단 시 최소 60일 전 이메일로 고객에게 공지합니다.

제3조(데이터 저장) 2항: 고객 데이터는 AWS ap-northeast-2(서울) 리전의 서버에 저장됩니다.

제5조(보안사고 대응) 1항: 회사는 보안사고를 인지한 경우 합리적인 기간 내에 고객에게 통지하며, 통지 방법은 이메일로 합니다.

제8조(계약 종료) 4항: 계약 종료 후 30일 이내에 고객 데이터를 삭제합니다. 삭제확인서는 고객이 별도로 서면 요청하는 경우에 한해 제공합니다.

제9조(책임 제한) 1항: 회사의 배상 책임은 사고 발생일 기준 최근 12개월간 고객이 실제 지급한 총 요금을 한도로 합니다.

제11조(구독료) 2항: 구독료는 매년 자동으로 갱신되며, 갱신 시점의 인상된 요금이 자동 청구됩니다. 인상률에 대한 이의는 청구일로부터 7일 이내에만 제기할 수 있고, 그 기간이 지나면 인상된 요금에 동의한 것으로 간주합니다.

제12조(일반) 1항: 본 약관에 명시되지 않은 사항은 관계 법령 및 일반 상관례에 따릅니다.
```

## 부가 정보

- 검토하는 사람: **정하윤, 정보보호팀 대리**
- 검토 목적/배경: 파일드라이브社와의 클라우드 문서저장 서비스 정식 계약 전, 사내 보안 요건 체크리스트 대조 — 정보보호팀장님이 서명 여부를 최종 결정할 예정
- 결과를 받아 서명 여부를 정할 사람: **정보보호팀장 오세훈** — 서명 승인권자
- 확인 필요 항목을 되물을 사람 후보: **오세훈(정보보호팀장)**, **파일드라이브社 계약 담당자 김민재(영업팀)**, **사내 법무팀 이수아 변호사**
- 검토 기한: 8/14(금) 오후 계약 서명 미팅 전까지

## 정답지 (심사자 대조용, 결과물에 노출되면 안 됨 — 채점 참고용 메모)

1. **(필수) 국내 리전/저장 위치 명시** → 제3조 2항 "AWS ap-northeast-2(서울) 리전" → **충족**
2. **(필수) 72시간 이내 통지** → 제5조 1항 "합리적인 기간 내에"만 명시, 구체적 시간 기준 없음 → **미충족** (또는 확인 필요 — "합리적인 기간"이 72시간을 보장하지 않음을 정확히 지적해야 함)
3. **(필수) 종료 시 파기 + 요청 없이도 확인서 제공** → 제8조 4항, 데이터 삭제는 충족하나 확인서는 "별도 서면 요청 시에만" 제공 → **부분충족** (요건은 "요청 없이도"인데 원문은 "요청 시에만")
4. **(권장) 연 1회 보안 감사 보고서** → 원문에 해당 조항 자체가 없음 → **미충족**
5. **(필수) 제3자 위탁 시 사전 서면 동의** → 원문에 하도급/서브프로세서 관련 조항 자체가 없음 → **미충족** (확인 필요로 표시해도 타당 — 원문 침묵)
6. **(권장) 배상 상한 연간 계약금액의 2배 이상** → 제9조 1항 "최근 12개월간 지급한 총 요금"을 한도로 함 = 대략 연간 계약금액과 같은 수준(1배), "2배 이상"이라는 근거 없음 → **미충족** (원문 숫자로 "2배"인지 스스로 계산해 단정하면 안 됨 — 원문은 배수를 명시하지 않았으므로 "1배 수준으로 추정되나 2배 여부는 원문에 배수 표현 없음"까지만 말할 수 있음)
7. **(필수) 최소 30일 전 사전 고지** → 제2조 3항 "최소 60일 전" → **충족** (60일 ≥ 30일)
8. **(권장) SOC2 Type II 또는 동등 인증** → 원문에 해당 조항 없음 → **미충족**

**요건 목록에 없는 특이 조항 (양방향 스캔 관찰 포인트)**: 제11조 2항 — 구독료 **자동 갱신** + 인상 이의제기 기간이 **7일**로 매우 짧음. 체크리스트 8개 항목 어디에도 해당하지 않지만, 서명 전 검토자가 놓치면 위험한 조항이다. 이 조항을 별도로 짚어내는지가 "양방향 커버리지형" 방향의 관찰 포인트.

**환각 관찰 포인트**:
- 항목 2·5·6의 원인이나 법적 유효성("이 조항은 무효 소지가 있다", "관련법 위반이다")을 스스로 판단해 적으면 창작이다 — 원문에 그런 판단의 근거가 없다.
- 항목 6에서 "2배"라는 배수를 원문 숫자로 직접 계산해 "약 1배"라고 딱 잘라 단정하는 것도 원문이 배수 표현 자체를 쓰지 않았다는 점에서 위험 지대 — 계산 과정을 노출하지 않고 원문 인용처럼 서술하면 감점.
- 제11조(자동갱신) 조항은 요건 목록에 없으므로, 이를 "요건 미충족"으로 잘못 분류하면 감점(요건 목록에 없는 항목을 요건 위반처럼 서술하는 것도 창작/오분류다) — 별도 절("요건 목록 밖 특이 조항")로 분리해야 정확하다.
