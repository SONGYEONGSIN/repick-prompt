## Touch 1 — Day0(가입 직후)

[발송 시점: 가입 완료 즉시 (가입 후 10분 이내)]

**제목/알림 문구 후보**
1. 환영해요! 손으로 쓰던 견적서, 이제 3분이면 끝나요
2. 가입 완료 - 첫 견적서, 지금 3분이면 만들 수 있어요

**본문**

안녕하세요, 견적박스에 가입해주셔서 감사합니다. 견적박스 고객성공팀 박서준입니다.

손으로 견적서를 쓰다 보면 실수도 잦고 시간도 오래 걸리죠. 회원님께서 가입하실 때도 바로 그 점이 가장 불편하셨다고 남겨주셨는데요, 지금 바로 첫 견적서를 한 번 만들어보시면 얼마나 달라지는지 3분 만에 체감하실 수 있어요.

방법은 정말 간단합니다.
1. 홈 화면 상단 '새 견적서 만들기' 버튼 클릭
2. 업종 템플릿(인테리어·시공·전기설비) 중 하나 선택
3. 항목 3개만 입력하면 합계가 자동으로 계산돼요
4. 저장하면 끝!

클릭 4번, 약 3분이면 첫 견적서가 완성됩니다.

## 발송 전 체크리스트

1. 세 통의 발송 시점이 겹치거나 역전되지 않는지: Touch1(가입 후 10분) → Touch2(가입 후 40시간) → Touch3(가입 후 120시간) 순으로 시간이 순차적으로 증가하며, Touch2는 활성화 판정 마감(72시간)보다 앞서 도착하도록 배치되어 있는지 확인했습니다.
2. Day1~2 문구를 이미 활성화한 사람이 봐도 무례하지 않은지: "혹시 아직 ~ 안 하셨다면"이라는 조건부 어법으로 시작해, 이미 견적서를 만든 사람이 받아 보더라도 자신에게 해당하지 않는 안내로 자연스럽게 지나칠 수 있는지 확인했습니다.
3. 세 통에 담긴 소재가 위에 적은 내용과 정확히 일치하는지: Touch1은 day0_content(새 견적서 만들기 버튼 → 업종 템플릿 택1 → 항목 3개 입력 → 저장, 클릭 4번·3분, /new 링크), Touch2는 reminder_content(업종별 템플릿 3종, 카드 등록 없이 시작·종료 3일 전 알림), Touch3는 retention_tips(즐겨찾기, 카카오톡 공유, 자동 정산 리포트)에 적힌 내용만 사용했고 새로운 화면·기능은 언급하지 않았는지 확인했습니다.
