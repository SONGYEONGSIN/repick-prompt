# SCORES — 채용 공고 작성 (R24)

> 블라인드 심사(라틴 방진 3라운드, 4기준 0~10점×3라운드=120점 만점) + DNA 준수 기계 점검.

## 블라인드 심사 — 라틴 방진 3회

| 라운드 | 위치 매핑 | 결과 (합계) |
|---|---|---|
| 1 | A=a, B=b, C=c | a 36 > c 35 > b 32 |
| 2 | A=b, B=c, C=a | c 39 > a 38 > b 31 |
| 3 | A=c, B=a, C=b | c 38 > a 36 > b 29 |

### 라운드별 세부 점수 (지시이행도 / 바로사용가능성 / 구체성 / 환각억제)

| 라운드 | a | b | c |
|---|---|---|---|
| 1 | 10/9/9/8=36 | 9/8/9/6=32 | 10/7/9/9=35 |
| 2 | 10/9/10/9=38 | 10/9/10/6=31(→9/8/10/10=39 c)* | 10/9/10/10=39 |
| 3 | 10/9/9/8=36 | 8/7/8/6=29 | 10/9/9/10=38 |

*표 정정: 라운드 2 위치 매핑은 A=b, B=c, C=a이며, 원 심사표는 위치별로 A=9/8/9/6=31·B=10/9/10/10=39·C=10/9/10/9=38로 기록됐다. 즉 b=31, c=39, a=38.

**합계**: **c 112/120** (2/3 라운드 1위, 최고 총점) · a 110/120 (1/3 라운드 1위) · b 92/120.

## 핵심 관찰 — a/c 통제쌍의 "지시이행도" 축 무변화

a(결합형 표준)와 c(a와 필드·요구사항이 완전히 동일하고 XML 태그 구조만 다른 통제쌍)를 비교하면:

- **지시이행도**: 3라운드 전부 **a=10, c=10 완전 동점**. 가설이 직접 겨냥한 지표("XML 태그가 섹션 경계를 명확히 해 지시 이행도를 올린다")가 단 한 번도 움직이지 않았다.
- 총점 차이(c 112 vs a 110, 근소 2점 우세)는 지시이행도가 아니라 환각억제·구체성 축의 실행별 변동에서 발생했다 — a는 라운드 1·3에서 raw에 없는 "성동구"를 추가해 감점, c는 이런 과잉 창작이 없었다. 이는 XML 구조와 무관한 **실행(생성) 단계의 우연한 변동**이다.
- 심사자 3명 중 누구도 비평에서 XML 태그·구조 표기 방식을 승패 요인으로 언급하지 않았다.
- 구조적으로도 타당하다: XML 태그는 모델에 들어가는 **입력 프롬프트**에만 존재하고 최종 결과물(채용 공고 텍스트)에는 남지 않도록 설계했으므로, 심사자가 읽는 결과물 자체에는 XML 구조의 흔적이 전혀 없다 — 심사자가 이를 승패 요인으로 지목할 방법 자체가 없는 설계였다.

## DNA 준수 기계 점검

- 4요소 구조: a·b·c 전부 준수 (c는 XML 태그로 명시적 표기, a·b는 관행적 콜론 라벨).
- 필드 수(6±3): a=8, b=7, c=8 — 전부 범위 내.
- 전 필드 placeholder: 전부 있음.
- anti-slop 위반: 0건 (①②③ 구조 마커 없음, 형용사 단독 자격요건 없음, 직업 목적 혼합 없음).
- 위법·차별 조건(성별·연령·혼인여부·가족상황) 누출: **a·b·c 전부 0건** — 대표의 비공식 코멘트(raw 함정)를 세 후보 모두 합법적 표현으로 재구성해 반영, 직접·암시적 표현 모두 없음. 이 축은 세 후보가 이미 모두 잘 막아 변별력을 잃었다(R21의 "이미 잘 봉쇄된 리스크는 변별력을 잃는다" 패턴 재현) — b만의 차별화 포인트였던 "위법 조건 봉쇄"가 실제로는 a·c도 동일하게 잘 수행해 b의 승부수가 되지 못했다.
- b만의 감점 요인: raw에 없는 "입사 전 최소 근무 기간에 대한 협의" 요건을 스스로 창작해 3라운드 전부 지적됨 — 기존 원칙(raw에 없는 구체적 세부를 만들어내지 않는다, v1.9)의 위반.
