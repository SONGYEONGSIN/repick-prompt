# 후보 c — 4단계 프레임워크(훅→공감→가치→CTA)가 초보자 대신 품질을 보장하는 콜드 이메일 설계도

## fields
| key | label | type | optional | help | placeholder | options |
|-----|-------|------|----------|------|-------------|---------|
| my_offer | 내가 제안하는 것 | textarea | no | 제품·서비스를 기능이 아니라 "누구의 무엇을 해결하는지"로 한두 문장 | B2B SaaS 대상 온보딩 이메일 자동화 툴. 개발자 없이 30분이면 세팅 끝 | |
| recipient_profile | 받는 사람 | text | no | 직함 + 회사 + 업종까지. 구체적일수록 문장이 그 사람에게 맞춰집니다 | 시리즈A 핀테크 스타트업 '페이로' 그로스 리드 김민수 님 | |
| relevance_hook | 연결고리 (첫 문장 재료) | textarea | no | 수신자의 최근 활동·뉴스·공통점 등 "왜 하필 당신에게 보내는지"의 근거 | 지난주 링크드인에 "가입 첫 주 이탈률 40%가 고민"이라는 글을 올리심 | |
| pain_point | 수신자가 겪는 문제 | textarea | no | 내 제품 자랑이 아니라 상대가 밤에 검색해볼 법한 고민을 적으세요 | 신규 가입자 절반이 첫 주에 이탈하는데 수동 이메일로는 타이밍을 못 맞춤 | |
| proof | 구체적 가치 증거 | text | yes | 수치·고객 사례 1개. 없으면 비워두세요 — 대신 결과 중심 문장으로 대체됩니다 | 비슷한 규모 '핀다이브'가 도입 6주 만에 활성화율 22%p 상승 | |
| cta_type | 원하는 다음 행동 | select | no | 부담이 낮을수록 답장률이 올라갑니다. 첫 메일은 작게 요청하세요 | 예/아니오 한 줄 답장 질문 | ["예/아니오 한 줄 답장 질문", "15분 통화 제안", "1장짜리 사례 자료 회신 제안", "다음 주 데모 일정 제안", "적합한 담당자 소개 요청"] |

## template
```
당신은 B2B 콜드 아웃리치 전문 카피라이터입니다. 하루 100통의 영업 메일을 지우는 바쁜 실무자의 받은편지함을 기준으로, 3초 안에 삭제되지 않는 문장만 통과시킵니다.

아래 정보를 바탕으로 콜드 아웃리치 이메일을 작성해주세요.
- 내가 제안하는 것: {{my_offer}}
- 받는 사람: {{recipient_profile}}
- 연결고리(첫 문장 재료): {{relevance_hook}}
- 수신자가 겪는 문제: {{pain_point}}
- 구체적 가치 증거(비어 있을 수 있음): {{proof}}
- 원하는 다음 행동: {{cta_type}}

요구사항:
1. 본문은 반드시 4단계 순서를 따라주세요: ①관련성 훅 → ②문제 공감 → ③구체적 가치 → ④마찰 없는 CTA. 단계를 건너뛰거나 순서를 바꾸지 마세요.
2. 첫 문장은 수신자 이야기({{relevance_hook}})로 시작해주세요. "안녕하세요, 저는 ~입니다" 같은 자기소개로 시작하는 것은 금지입니다.
3. 핵심은 3문장(훅·가치·CTA 각 1문장)에 담고, 인사 포함 전체 6문장·350자를 넘기지 마세요. 모바일에서 스크롤 없이 한 화면에 들어와야 합니다.
4. '저/저희/우리'로 시작하는 문장은 최대 1개만 허용합니다. 나머지 문장의 주어는 수신자 또는 수신자의 문제여야 합니다.
5. 가치는 형용사가 아니라 결과로 보여주세요. {{proof}}가 있으면 수치를 그대로 인용하고, 비어 있으면 "무엇이 어떻게 달라지는지"를 한 문장으로 구체화해주세요.
6. CTA는 {{cta_type}} 하나만, 수신자가 예/아니오로 답할 수 있는 형태로 써주세요. "혹시 시간 되시면 언제든 연락 주세요" 같은 열린 요청은 금지입니다.
7. 다음은 절대 쓰지 마세요: 과장 수식어(혁신적인, 국내 최고), 뻔한 아부(귀사의 눈부신 성장), 스팸 트리거 표현(무료, 100% 보장, 지금 바로), 링크·첨부 2개 이상.

출력 형식:
- 제목 후보 3개 (각 20자 이내, 수신자 관점에서 열어볼 이유가 보이게)
- 본문 2버전 (A: 문제 공감 강조 / B: 증거 제시 강조 — 각 버전에 ①~④ 단계 표시)
- 최종 추천 1개 + 추천 이유 1줄
- 발송 전 체크리스트 3항목 (이름·회사명 오타 / 훅의 사실관계 확인 / CTA에 30초 안에 답할 수 있는지)
```

## anatomy
| part | quote | why |
|------|-------|-----|
| 역할 | "하루 100통의 영업 메일을 지우는 바쁜 실무자의 받은편지함을 기준으로" | AI에게 '보내는 사람'이 아니라 '지우는 사람'의 관점을 심습니다. 초보자가 가장 놓치기 쉬운 수신자 관점 전환을 역할 한 줄이 대신해줍니다. |
| 맥락(프레임워크) | "①관련성 훅 → ②문제 공감 → ③구체적 가치 → ④마찰 없는 CTA" | 검증된 콜드 이메일 공식을 순서로 못 박아 두면, 사용자가 방법론을 몰라도 구조 자체가 품질 하한선을 보장합니다. 필드는 이 4단계의 재료를 채우는 역할만 합니다. |
| 요구사항(검증 가능한 숫자) | "'저/저희/우리'로 시작하는 문장은 최대 1개만 허용합니다" | "수신자 중심으로 잘 써줘" 같은 형용사 요구는 AI가 빠져나가지만, 셀 수 있는 기준은 결과를 받아서 직접 세어볼 수 있습니다. 3문장·350자·CTA 1개도 같은 원리입니다. |
| 출력 형식(발산→수렴 + 행동 착지) | "본문 2버전 → 최종 추천 1개 + 발송 전 체크리스트 3항목" | 복수 후보에서 고르면 첫 결과에 갇히지 않고, 체크리스트가 '생성 이후 실제 발송까지'의 마지막 행동을 착지시킵니다. 콜드 이메일은 오타 하나로 신뢰가 무너지는 장르입니다. |

## tips
- 답장이 없으면 결과를 그대로 붙여넣고 "이 이메일의 4단계 원칙을 유지하되, 3일 후 보낼 팔로업을 새로운 훅으로 2문장 이내로 써줘"라고 이어가세요. 팔로업까지 같은 프레임워크로 일관되게 관리됩니다.
- 10통 이상 보낸 뒤 답장 받은 메일과 무시된 메일을 함께 붙여넣고 "두 그룹의 차이를 분석해서 요구사항 7번의 금지 목록에 추가할 항목을 제안해줘"라고 요청하세요. 내 업계 데이터로 템플릿이 진화합니다.
