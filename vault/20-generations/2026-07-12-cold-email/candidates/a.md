# 후보 a — 3칸 30초: 받는 사람·제안·원하는 행동만 넣으면 완성되는 최소 입력 콜드메일

## fields
| key | label | type | optional | help | placeholder | options |
|-----|-------|------|----------|------|-------------|---------|
| recipient | 받는 사람 | text | false | 직함·회사·업종 등 상대를 한 줄로 적어주세요 | 예: 시리즈 A 커머스 스타트업의 마케팅 팀장 | - |
| offer | 내 제안 | textarea | false | 무엇을 주는지 + 상대가 얻는 이득을 한두 줄로 | 예: 광고비를 평균 30% 아껴주는 자동화 툴, 2주 무료 체험 제공 | - |
| goal | 원하는 행동 | select | false | 이 메일로 상대가 해줬으면 하는 딱 한 가지 | 예: 15분 통화 잡기 | 15분 통화 잡기, 답장 받기, 소개 자료 보내도 되는지 허락받기, 데모 미팅 잡기 |
| hook | 상대에 대해 아는 것 | text | true | 최근 소식·글·성과 등 한 가지. 비우면 일반 버전으로 작성됩니다 | 예: 지난주 브런치에 올린 퍼포먼스 마케팅 회고 글 | - |

## template
```
당신은 답장률로 평가받는 B2B 콜드 아웃리치 카피라이터입니다. 화려한 문장이 아니라 '바쁜 사람이 답장하게 만드는 짧은 메일'을 씁니다.

아래 정보로 콜드 아웃리치 이메일을 작성해주세요.
- 받는 사람: {{recipient}}
- 내 제안: {{offer}}
- 이 메일로 원하는 행동: {{goal}}
- 상대에 대해 아는 것 (비어 있으면 이 줄은 무시): {{hook}}

요구사항:
1. 제목은 20자 이내로, 받는 사람의 일과 관련된 단어를 1개 이상 넣어주세요.
2. 첫 문장은 반드시 상대의 이야기로 시작해주세요. '저희는 ~하는 회사입니다' 같은 자기소개로 시작하지 마세요.
3. 본문은 인사말 제외 5문장 이내로 쓰고, 한 문장에는 하나의 정보만 담아주세요.
4. 제안은 기능 나열 대신 받는 사람이 얻는 이득 딱 1가지로 좁혀주세요.
5. 마지막 문장은 '{{goal}}'로 이어지는, 예/아니오로 답할 수 있는 질문 1개로 끝내주세요.
6. 피할 것: 과장 표현('혁신적인', '국내 최초', '파격'), 상투어('귀사의 무궁한 발전'), 링크·첨부 언급, 한 메일에 두 가지 이상 요청.

출력 형식:
- 제목 후보 3개 (서로 다른 각도: 상대 이득형 / 질문형 / 아는 것 활용형)
- 본문 2안: A안(3문장 초단문) / B안(5문장 표준)
- 최종 추천: 제목 1개 + 본문 1안 조합, 추천 이유 1줄
```

## anatomy
| part | quote | why |
|------|-------|-----|
| 역할 | "답장률로 평가받는 B2B 콜드 아웃리치 카피라이터입니다" | 평가 기준(답장률)까지 역할에 박아두면 AI가 '멋진 글'이 아니라 '답장 오는 글'을 목표로 씁니다. 직업만 주는 것보다 결과물의 방향이 훨씬 또렷해집니다. |
| 맥락 | "상대에 대해 아는 것 (비어 있으면 이 줄은 무시): {{hook}}" | 필수 3칸만으로도 돌아가지만, 선택 칸 하나가 개인화 수준을 좌우합니다. '비어 있으면 무시'라고 명시해 초보자가 빈칸 때문에 막히지 않게 합니다. |
| 요구사항 | "마지막 문장은 예/아니오로 답할 수 있는 질문 1개로 끝내주세요" | '잘 마무리해줘'가 아니라 검증 가능한 조건입니다. 결과를 받고 마지막 문장만 봐도 조건 충족 여부를 초보자도 바로 판별할 수 있고, 상대의 답장 부담을 최소로 만듭니다. |
| 출력 형식 | "제목 후보 3개 → 최종 추천: 제목 1개 + 본문 1안 조합" | 후보를 여러 개 받은 뒤 AI가 직접 최종안을 고르게 하는 발산→수렴 구조입니다. 초보자가 뭘 골라야 할지 몰라도 '최종 추천'을 그대로 복사해 보내면 되는 상태로 착지합니다. |

## tips
- 답장이 없을 때는 이 결과 대화에 이어서 "3일 뒤 보낼 팔로업 메일을 같은 규칙으로 2문장만 써줘"라고 요청하세요. 맥락이 유지되어 새로 빈칸을 채울 필요가 없습니다.
- '상대에 대해 아는 것' 칸에는 받는 사람의 링크드인 최근 게시물이나 회사 뉴스 한 줄을 복사해 넣어보세요. 이 한 칸 유무가 첫 문장의 개인화 품질을 가장 크게 바꿉니다.
