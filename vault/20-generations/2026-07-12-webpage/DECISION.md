# R3 DECISION — 웹페이지(랜딩페이지) 제작

- **승자: c (프레임워크 내장)** — 사용자 선택 (추천 수용)
- 이유: 심사 20/20 + 환각 0 (가장 깨끗). 검증된 전환 구조(첫 화면→문제 공감→혜택→사회적 증거→FAQ→마지막 CTA)와 PAS 카피 공식·모바일 우선·동사형 버튼을 요구사항 문장으로 내장 — 초보자가 랜딩 구조를 전혀 몰라도 전환형 페이지가 나옴.

## 탈락 사유

- **b (가이드 최대화, 19점)** — 헤드라인 후보 3개 발산→수렴, 숫자 카드, 반과장 장치 등 완성도 최상급. 그러나 유일한 실제 후기에 "재구매한 고객"이라는 시나리오에 없는 속성을 덧붙임 (경미한 출처 각색).
- **a (최소 빈칸, 17점)** — 디자인은 가장 세련됐으나 핵심 차별점 2건(평균 3일 발송·주문 후 로스팅) 누락 + "3분 완성" 임의 수치·근거 없는 희소성 문구("수량이 넉넉하지 않습니다").

## 학습 (principles 반영)

**도메인의 검증된 방법론은 빈칸이 아니라 요구사항 문장으로 내장한다** — 사용자 입력 품질과 무관하게 구조 품질이 보장된다 (R2·R3 승자 공통 패턴).
