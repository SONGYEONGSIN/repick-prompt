# 후보 b — 필드가 코치가 된다: 고민·증거·행동을 빈칸으로 끌어내 바로 열리는 완성 페이지를 뽑는 가이드 최대화형

## template

```
당신은 소규모 브랜드의 전환율 높은 원페이지 랜딩페이지를 만들어온 웹 디자이너 겸 카피라이터입니다. 코드를 모르는 사람도 파일 하나만 열면 바로 볼 수 있는, 지금 당장 게시 가능한 완성 페이지를 만드는 것이 당신의 목표입니다.

아래 정보를 바탕으로 원페이지 랜딩페이지를 만들어주세요.
- 소개할 제품·서비스: {{product}}
- 누구를 위한 것인가: {{audience}}
- 고객이 겪는 고민: {{customer_pain}}
- 그 고민을 해결하는 방법: {{value}}
- 믿을 근거(증거): {{proof}}
- 방문자가 하길 원하는 단 하나의 행동: {{cta}}
- 그 행동이 도착할 곳: {{cta_link}}
- 브랜드 분위기: {{brand_mood}}

요구사항:
1. 페이지는 위에서 아래로 이렇게 이어지게 구성해주세요: 첫 화면(핵심 약속) → 고객 고민 공감 → 해결책 → 믿을 근거 → 행동 유도. 방문자가 스크롤만 내리면 자연스럽게 설득되도록.
2. 첫 화면 헤드라인은 제품 이름이 아니라 "고객이 얻는 결과"로 써주세요. 한 줄만 읽어도 무엇인지 바로 알 수 있게.
3. 고민 섹션은 방문자가 "이거 내 얘기네"라고 느끼도록, 위에 적힌 고객의 고민을 그들의 언어로 다시 써주세요.
4. 모든 카피는 실제 문장으로 완성해서 채워주세요. "여기에 소개 입력" 같은 빈 자리(플레이스홀더)를 절대 남기지 마세요.
5. 증거 정보가 있으면 신뢰를 주는 섹션(후기·숫자·수상 표시)으로 눈에 띄게 배치하고, 없으면 증거를 지어내지 말고 대신 "무엇을 약속하는지"를 분명히 하는 문장으로 그 자리를 채워주세요.
6. 행동 유도 버튼은 페이지에서 가장 눈에 띄게 배치하고, 위에 적힌 도착 링크로 실제로 연결(<a href>)해주세요. 버튼 문구는 "제출"처럼 밋밋하지 않게, 누르면 무엇을 얻는지 드러나게.
7. 다음은 피해주세요: "최고의", "혁신적인", "업계 1위" 같은 근거 없는 과장 / 가짜 후기나 지어낸 숫자 / 무지개 그라데이션·번쩍이는 애니메이션 같은 유행 지난 디자인 / 읽기 힘든 화려한 폰트.
8. 결과물은 HTML과 CSS가 한 파일에 담긴 단일 문서 하나로 주세요. 외부 라이브러리나 인터넷 연결 없이 열리게 하고, 스타일은 문서 안 <style> 태그에 넣고, 휴대폰 화면에서도 깨지지 않게 반응형으로 만들어주세요.

출력 형식:
- 첫 화면 헤드라인 후보 3개 (각각 다른 각도: 결과 강조형 / 고민 공감형 / 질문형) — 그중 가장 강한 하나를 페이지에 적용
- 완성된 단일 HTML 파일 전체 (복사해서 그대로 저장하면 되는 코드 블록 하나)
- 이 파일을 여는 방법 3줄 안내 (메모장 등에 코드 붙여넣기 → 파일 이름을 index.html로 저장 → 파일을 더블클릭)
- 게시 전 확인 체크리스트 4개 (예: 오타 확인 / 버튼 링크가 진짜 열리는지 / 휴대폰에서 보기 / 연락처가 정확한지)
```

|------|-------|-----|

| 맥락 | "고객이 겪는 고민: {{customer_pain}}" | 방문자가 스크롤을 멈출지는 첫 화면의 '내 얘기네' 순간에 달렸습니다. 고객의 고민을 선택이 아닌 필수 빈칸으로 강제하면, 초보자가 가장 많이 저지르는 '제품 자랑만 늘어놓는 페이지'를 구조적으로 막습니다 — 전환을 가르는 결정 요인입니다. |

| 출력 형식 | "헤드라인 후보 3개 → 완성된 단일 HTML → 여는 방법 안내 → 게시 전 체크리스트 4개" | 헤드라인을 복수로 받아 고르는 발산→수렴 구조로 초보자도 카피 안목을 기르고, 완성 HTML에 더해 '여는 방법'과 '게시 전 체크리스트'까지 받으면 "이제 이걸 어떻게 띄우지?"라는 다음 고민까지 풀립니다 — 파일을 받고 끝나지 않는 행동 착지입니다. |

## tips

1. **먼저 한 페이지, 완벽은 나중에.** 지금 채운 값으로 일단 페이지를 띄우고, 방문자 반응을 본 뒤 고민 문구나 버튼 문구를 바꿔 다시 요청하세요. 받은 HTML 전체를 그대로 붙여넣고 "고민 섹션 문구만 이렇게 바꿔줘"라고 하면, 이 템플릿 하나로 페이지를 계속 다듬을 수 있습니다.
2. **헤드라인 후보 3개로 5초 테스트를 하세요.** 결과로 받은 3개 헤드라인을 지인 몇 명에게 보여주고 "무엇을 파는 페이지 같아?"라고 물어보세요. 5초 안에 제품이 안 읽히면 그 헤드라인은 탈락입니다. 어떤 각도(결과/공감/질문)가 잘 통하는지 기록해두면, 다음 페이지의 첫 화면 칸을 채우는 눈이 훨씬 날카로워집니다.
