## template

```
당신은 소상공인과 1인 브랜드의 소개 웹페이지를 만들어온 웹 카피라이터이자 프론트엔드 개발자입니다. 코드를 전혀 모르는 사람이 파일 하나를 더블클릭하면 바로 열리는, 카피가 완성된 원페이지를 만드는 것이 당신의 목표입니다.

아래 정보를 바탕으로 한 페이지짜리 소개 웹페이지를 만들어주세요.
- 제품·서비스 이름: {{brand_name}}
- 무엇을, 누구에게, 어떤 문제를 풀어주나: {{product}}
- 주요 고객: {{audience}}
- 신뢰 요소(실적·후기): {{proof}}
- 방문자가 눌렀으면 하는 버튼: {{cta}}
- 버튼이 연결될 곳: {{contact}}
- 분위기: {{mood}}

요구사항:
1. 제품 설명 한 칸을 바탕으로 페이지 카피 전체를 직접 완성해주세요. {{brand_name}}에 어울리는 헤드라인, 한 줄 소개, 핵심 가치 3가지, 버튼 문구를 실제 문장으로 채워주세요. "여기에 내용을 넣으세요" 같은 빈칸은 하나도 남기지 마세요.
2. 페이지 맨 위(첫 화면) 영역에는 한 줄 헤드라인 + 한 줄 보조 설명 + {{cta}} 버튼을 배치해주세요. 방문자가 3초 안에 "이게 나에게 무엇을 해주는지" 알 수 있어야 합니다.
3. 모든 버튼과 연락처는 {{contact}}로 실제 연결되게 만들어주세요. 이메일이면 mailto:, 전화번호면 tel:, 링크면 href로 정확히 걸어서 버튼이 아무 데도 가지 않는 일이 없게 해주세요.
4. 신뢰 요소(후기·실적)가 주어지지 않았다면, 없는 후기·평점·숫자를 절대 지어내지 마세요. 이 경우 후기 영역은 통째로 생략해주세요. 주어졌을 때만 그 내용을 그대로 후기 영역에 넣어주세요.
5. 다음은 피해주세요: "업계 최고", "혁신적인", "고객 만족 100%" 같은 과장·상투어 / 촌스러운 무지개 그라데이션이나 유행 지난 디자인 / 지어낸 후기·가짜 별점 / 읽기 힘든 화려한 폰트.
6. 디자인은 요즘 감각의 깔끔한 반응형으로 만들어주세요. 별도 이미지 파일 없이 CSS만으로 색·여백·정렬을 살리고, 휴대폰 화면에서도 무너지지 않게 해주세요.

출력 형식:
- 완성된 단일 HTML 파일 1개 — <!DOCTYPE html>부터 </html>까지, CSS는 <style> 안에 포함하고, 카피가 모두 채워진 상태로 주세요.
- 이 파일을 여는 방법 안내 3줄 — (1) 위 코드를 전체 복사 (2) 메모장이나 텍스트 편집기에 붙여넣고 "브랜드이름.html"로 저장 (3) 저장한 파일을 더블클릭하면 브라우저에서 바로 열림.
- 게시 전 확인 체크리스트 4개 — 버튼을 눌러 실제로 연결되는지 / 오탈자·어색한 문장은 없는지 / 휴대폰 화면에서 잘 보이는지 / 지어낸 실적이나 과장 문구는 없는지.
```

## anatomy

| part | quote | why |
|------|-------|-----|
| 역할 | "코드를 전혀 모르는 사람이 파일 하나를 더블클릭하면 바로 열리는, 카피가 완성된 원페이지를 만드는 것이 당신의 목표입니다." | 역할에 직업(카피라이터+개발자)만이 아니라 결과물의 형태(더블클릭으로 열리는 완성 파일)까지 목표로 못 박습니다. 그래서 AI가 카피만 늘어놓거나 반쪽짜리 코드 조각을 주지 않고, 받아서 바로 열어볼 수 있는 한 개 파일로 수렴합니다. |
| 맥락 | "무엇을, 누구에게, 어떤 문제를 풀어주나: {{product}}" | 이 후보의 핵심은 최소 빈칸입니다. 헤드라인·소개·핵심 가치를 따로 묻지 않고, 이 한 칸의 정직한 설명에서 카피 전체를 뽑아냅니다. 초보자는 열 개의 칸을 채우다 이탈하는 대신 "내 제품이 누구의 뭘 덜어주는지" 한 칸에만 집중하면 됩니다. |
| 요구사항 | "모든 버튼과 연락처는 {{contact}}로 실제 연결되게 만들어주세요… 버튼이 아무 데도 가지 않는 일이 없게 해주세요." | 연락처를 필수 빈칸으로 두고 버튼에 실제로 연결시키는 것이 이 페이지를 "받은 그대로 게시 가능"하게 만드는 지점입니다. 아무 데도 안 가는 버튼은 서명 없는 콜드 메일과 같습니다 — 빈칸은 줄이되 사용 세트는 포기하지 않습니다. |
| 출력 형식 | "완성된 단일 HTML 파일 → 여는 방법 안내 3줄 → 게시 전 확인 체크리스트 4개" | 코드를 모르는 사람에게는 코드만으로 부족합니다. 여는 방법과 게시 전 점검까지 한 세트로 받아야 "이걸 어떻게 열지, 올려도 되나?"라는 다음 고민이 남지 않습니다. 카피가 채워진 파일 + 여는 법 + 체크리스트가 곧 행동 착지입니다. |

## tips

1. **한 번에 끝내지 말고 이어서 다듬으세요.** 완성된 HTML을 받은 뒤 같은 대화에서 "헤드라인을 더 강하게", "가격 안내 영역 하나 추가해줘", "색을 좀 더 차분하게"처럼 한 가지씩 요청하면 페이지를 계속 키울 수 있습니다. 처음부터 완벽하게 채우려 하지 말고, 나온 페이지를 눈으로 보고 고치는 편이 훨씬 빠릅니다.
2. **제품 설명 칸을 아끼지 마세요.** 이 템플릿은 빈칸이 적은 대신 '제품 설명' 한 칸에서 페이지 전체가 나옵니다. 그래서 이 칸을 자랑이 아니라 "누가, 어떤 상황에서, 무엇 때문에 힘든데, 내가 그걸 어떻게 덜어주는지"로 구체적으로 적을수록 헤드라인과 핵심 가치가 날카로워집니다. 고민되면 실제 고객에게 했던 말을 그대로 옮겨 적어보세요.
