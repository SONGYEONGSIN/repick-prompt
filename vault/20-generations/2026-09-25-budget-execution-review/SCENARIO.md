# SCENARIO — 예산 집행 내역 점검 (R60)

라틴 방진 3회(각 후보가 각 위치에 1회씩) 순서 편향 통제. 심사자는 이 문서만 보고 결과물을 대조하므로, values.json에 들어갈 모든 사실을 아래에 빠짐없이 명기한다.

## 배경

45인 규모 IT 스타트업. 이번 점검은 **2026년 3분기(7/1~9/30) 예산 집행 현황**을 분기 마감(9/30) 직전에 재무팀이 점검해, 마감 전 마지막으로 조치가 필요한 항목을 각 부서에 확인 요청하기 위해 작성한다. 작성자(재무팀 예산 담당)와 각 항목의 실제 집행 당사자(부서장)는 분리되어 있고, 최종 예산 승인권자는 또 다른 사람이다 — 감사형 도메인.

## 계획 예산 항목 원문 (번호 매김, textarea 필드에 그대로 들어갈 원문)

```
1. 마케팅팀 - SNS 광고 운영비 (회계기간: 2026 3분기, 7/1~9/30) — 계획 3,000,000원
2. 마케팅팀 - 인플루언서 협찬비 (회계기간: 2026 3분기, 7/1~9/30) — 계획 2,000,000원
3. 개발팀 - 클라우드 인프라 이용료 (회계기간: 2026 3분기, 매월 청구) — 계획 월 1,200,000원 × 3개월 = 3,600,000원
4. 디자인팀 - 폰트·에셋 구독료 (회계기간: 2026 3분기, 정기결제) — 계획 300,000원
5. 마케팅팀 - 브랜드 리뉴얼 디자인비 (회계기간: 2026 3분기, 7/1~9/30) — 계획 1,500,000원
6. 개발팀 - 외부 보안감사 컨설팅비 (회계기간: 2026 연간, 1/1~12/31) — 계획 4,000,000원
7. 총무팀 - 사내 시스템 라이선스 갱신비 (회계기간: 2026 3분기, 7/1~9/30) — 계획 600,000원
```

## 실제 집행 내역 원문 (원문 전체, textarea 필드에 그대로 들어갈 원문)

```
1. SNS 광고 운영비 — 7~9월 누적 집행 2,980,000원 (7월 980,000 / 8월 1,020,000 / 9월 980,000, 카드 명세 대조 완료)
2. 인플루언서 협찬비 — 7~9월 누적 집행 3,150,000원 (계약 단가가 사전 협의 없이 인상되어 계획 대비 초과, 마케팅팀장 확인 완료)
3. 클라우드 인프라 이용료 — 7월 청구 1,320,000원(+120,000, 신규 스토리지 옵션 추가), 8월 청구 1,280,000원(+80,000, 같은 스토리지 옵션 유지), 9월분은 9/30 마감 후 발행 예정이라 아직 청구서 없음
4. 폰트·에셋 구독료 — 7~9월 누적 결제 312,000원 (구독 업체가 7월분부터 환율 연동 가격으로 12,000원 인상, 디자인팀 확인 완료, 4분기부터는 계획을 320,000원으로 조정 예정)
5. 브랜드 리뉴얼 디자인비 — 집행 0원. 마케팅팀 회의록(8/20): "리뉴얼 프로젝트는 외주 디자이너 일정 문제로 4분기(10월)로 전체 연기하기로 결정, 3분기 예산은 사용하지 않음"
6. 외부 보안감사 컨설팅비 — 집행 0원. 개발팀장 확인(9/18): "컨설팅 업체와 계약 조건 협상 중이며 10월 중 계약 체결 예정, 원래 사업계획상으로도 4분기 집행 항목이었음"
7. 사내 시스템 라이선스 갱신비 — 회계 시스템에 집행 620,000원으로 기록되어 있으나, 9/22 회계 시스템 점검 중 오류 코드 F-411(중복 청구 가능성)가 함께 표시되어 총무팀이 재조회를 요청한 상태. 정확한 최종 금액 미확정.
8. (계획 목록에 없는 지출) 총무팀 - 사무실 화재보험 갱신료 850,000원 — 7/15 집행. 연 1회 자동 갱신 계약으로 이번 분기 예산 항목 목록에는 별도로 편성되어 있지 않았음.
```

## 부서·담당자 정보

마케팅팀장 오세연, 개발팀장 김도훈, 디자인팀장 백하늘, 총무팀장 유지원. 재무팀 예산 담당(점검자·작성자) 강민재. 최종 예산 승인권자 박태준 경영지원본부장.

## 점검 기준일

2026년 9월 25일 (3분기 마감 5일 전)

## 점검자

강민재, 재무팀 예산관리 담당

## 확인 상태가 필요한 항목 최종 회신 기한

9/29(화) 오후까지 — 9/30 3분기 마감 전 최종 반영 필요.

## 비용 임계값 (조치 우선순위를 낮출 수 있는 분기 누적 차액 하한선)

분기 누적 차액(계획 대비 초과 또는 미집행) 250,000원 미만

## 기대 판정 (심사·검산용 — SCENARIO 자체 사실이며 결과물이 반드시 이 결론에 도달해야 하는 것은 아니고, 후보가 도달한 판정의 근거 타당성을 심사할 때 참고)
