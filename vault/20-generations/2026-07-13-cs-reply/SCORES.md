# R7 채점 — 고객 문의(CS) 답변

> 블라인드 매핑: A=c(프레임워크 내장), B=a(후속 질문형 개선판), C=b(결합형) — comparator는 매핑을 모른 채 심사. R6과 다른 셔플 사용.
> 방향 풀: a=후속 질문형 개선판(R6 결함 2건 수정 재도전) / b=프레임워크+가이드 결합(R6 2위 가설 지속 + 대상 맥락 빈칸 반영) / c=프레임워크 내장(5연속 챔피언 대조군).

### 심사 한 줄 비평 (익명 해제)

- **b (1위, 20/20)**: "지키지도 못할 '내일까지 해드리겠다'는 말씀은 드리고 싶지 않습니다"로 불가능 약속을 명시 문장으로 스스로 봉쇄. "한 겹" 주장은 직접 반박 없이 자기 기록만 담담히 밝히고 원인 미확정으로 열어둔 균형 최상. 리뷰 협박에는 재반박 대비에서 "보상으로 리뷰를 막으려 하지 않는다"며 비거래적 정면 대응. 선택지 불릿 구성으로 즉시 스캔 가능. 약점: "제 포장이 부족했던 건지" 1인칭 자기 노출(단정 아님), 배송 지연 언급은 불필요.
- **c (2위, 19.5)**: "완전 망했어요" 원문 인용 밀착 공감 + "내일이 급하시면 환불이 오히려 나을 수 있다"는 고객 이익 우선 조언 발군. 감점 0.5: 원인 미확정 상태에서 "포장 방식을 보강하겠습니다"가 은연중 자기 포장 부족 인정 뉘앙스 — 미확정 프레임과 미세 충돌.
- **a (3위, 17)**: R6 결함 수정은 성공 — 본문 완성본 선언 지켜졌고 되묻기 섹션 격리도 성공, "[사장님께 드리는 확인 질문]"(부산 특송 여지·쿠폰 조건·수거 방식)은 실무 감각 최고 평가. 신규 감점: 고객의 "뽁뽁이 한 겹" 주장을 직접 인용 후 "기록상 2겹" 대조하는 구성이 화난 고객에게 방어적·대립적으로 읽힘(대안 문장으로 완화했으나 본문 자체가 대립 인상) + 본문·부속물 어디에도 리뷰 언급 대응 전무.

## 관찰 (LEARN 후보)

1. **프레임워크 내장 연승이 5에서 끊김** — 결합형(구조 내장 + 코치형 help + 대상 맥락 빈칸)이 20/20으로 첫 승. R6 관찰 메모 ①("대상 맥락 빈칸")을 반영한 b의 `situation` 필드가 첫 구매·선물 포장·화남 정도를 받아낸 것이 밀착 공감의 재료가 됨 — **원칙 승격 조건(재현) 충족**.
2. **불가능 약속의 명시 봉쇄 문장** — "지키지 못할 약속은 하지 않겠다"를 결과물이 스스로 말하게 만드는 요구사항("여기 적힌 범위 밖은 약속하지 마라" + 실행 여건 정직 고지)이 승부처. CS류의 "결정 요청 상단 고정"에 대응하는 도메인 원칙 후보.
3. **후속 질문형 2연속 열세** — R6 결함 수정에 성공했음에도 3위(17). 되묻기 섹션 자체는 두 라운드 연속 최고 평가를 받았으나, 본문 품질에서 계속 밀림. "되묻기는 승자 템플릿의 부속물로 흡수하고, 독립 방향으로는 은퇴" 검토 시점.
4. **사실 대조의 화법** — 같은 사실(뽁뽁이 2겹)을 a는 고객 주장 인용 → 반박 구성(대립 인상), b·c는 자기 기록 담담히 서술 + 원인 미확정 열어두기(균형). "고객 주장과 다른 사실은 고객 말 반박이 아니라 우리 기록 서술로" — 원칙 후보.
