# R7 결정 — 고객 문의(CS) 답변

- **승자**: 후보 b — 프레임워크+가이드 결합형 (CS 문법 내장 + 코치형 help + 대상 맥락 빈칸 `situation`)
- **선택**: 휴먼 게이트 — 사용자가 추천안(심사 1위, 20/20) 승인
- **이유**: 4기준 전부 만점 — **5연속 챔피언(프레임워크 내장)을 꺾은 첫 라운드.** ① "지키지도 못할 '내일까지 해드리겠다'는 말씀은 드리고 싶지 않습니다"로 불가능 약속을 명시 문장으로 스스로 봉쇄 ② "뽁뽁이 한 겹" 주장을 방어적 반박도 거짓 인정도 없이 자기 기록 서술 + 원인 미확정으로 처리 ③ 리뷰 협박에 재반박 대비에서 "보상으로 리뷰를 막으려 하지 않는다"며 비거래적 정면 대응 ④ 환불/재발송 불릿 선택지로 즉시 스캔 가능.
- **탈락 사유**:
  - c 프레임워크 내장 (19.5, 2위): 고객 이익 우선 조언("급하시면 환불이 나으실 수 있다") 발군이나, 원인 미확정 상태에서 "포장 방식을 보강하겠습니다"가 은연중 자기 포장 부족 인정 뉘앙스 — 미확정 프레임과 미세 충돌(0.5 감점). 운영자 메모: "내일 오전까지 원인 확인 결과 회신"도 택배사 조사 속도 감안 시 경미한 과잉 약속 소지.
  - a 후속 질문형 개선판 (17, 3위): R6 결함 수정은 성공(완성본 선언 유지 + 되묻기 격리), "[사장님께 드리는 확인 질문]"은 실무 감각 최고 평가. 신규 감점: 고객 주장 직접 인용 → "기록상 2겹" 반박 구성이 화난 고객에게 대립적으로 읽힘 + 리뷰 언급 대응 전무. **후속 질문형 2연속 열세 — 독립 방향 은퇴, 되묻기는 승자 부속물로 흡수 검토.**
- **가설 검증 결과**: R6 관찰 메모 ①("대상 밀착 문서는 대상의 현재 맥락 빈칸 필요")이 R7에서 재현 — b의 `situation` 빈칸(첫 구매·선물 포장 메모·화남 정도)이 밀착 공감의 재료가 되어 승리에 기여. **재현 조건 충족 → 원칙 승격.**
- **차기 관찰 메모**: ① 사실 대조 화법 — 고객 주장과 다른 사실은 "고객 말 반박"이 아니라 "우리 기록 담담한 서술 + 판단 유보"로 (a 감점 원인, b·c 강점 — 재현 시 원칙 승격) ② 재발 방지 약속은 원인 미확정과 논리 충돌하지 않게 (c의 0.5 감점) ③ 결합형이 신챔피언 — 다음 라운드 대조군은 b 방향, 도전자 가설 필요.
