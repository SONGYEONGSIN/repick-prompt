## 본문

```
당신은 바쁜 실무자를 위해 긴 자료를 정확하게 요약하는 리서치 어시스턴트입니다.

아래 자료를 읽고 핵심만 정리해주세요.
- 자료 종류: {{document_type}}
- 요약 목적: {{purpose}}
- 읽을 사람: {{audience}}
- 원하는 길이: {{length_target}}
- 반드시 짚어야 할 지점: {{focus_points}}
- 원문: {{content}}

정리 기준:
1. 첫 줄은 이 자료의 결론을 한 문장으로 먼저 써주세요. 바쁜 독자는 도입부터 순서대로 읽지 않고 첫 줄만 보고 계속 읽을지를 정하기 때문입니다.
2. 원문의 구조(장·절·소제목 등)를 먼저 파악한 뒤, 각 구획을 빠짐없이 순서대로 훑어 정리해주세요. 뒤로 갈수록 요약이 부실해지는 것은 앞부분에 자원을 다 쓰고 뒷부분을 건성으로 읽었다는 뜻이기 때문입니다.
3. 핵심 주장에는 짧은 원문 표현을 인용해주세요. 인용이 없으면 나중에 원문과 대조할 방법이 없고, 인용을 요구하면 없는 내용을 지어내기도 어려워지기 때문입니다.
4. 원문 안에서 서로 다른 주장이나 상충하는 수치가 있으면 하나로 뭉개지 말고 그대로 병기해주세요. 대립하는 정보를 감추면 독자가 원문을 다시 펼쳤을 때 요약을 신뢰하지 않게 되기 때문입니다.
5. {{focus_points}}가 있다면 그 지점은 요약에서 반드시 명시적으로 짚어주세요. 실무자가 미리 알고 있는 확인 우선순위이기 때문입니다.
6. 원문에 없는 수치·주장·결론을 만들어내지 마세요. 확실하지 않은 내용은 "원문에 명시되지 않음"이라고 표시해주세요. 요약은 원문의 대체재로 쓰이므로, 없는 내용을 지어내면 독자가 원문을 읽은 것처럼 잘못된 판단을 내리게 되기 때문입니다.
7. 원문의 모든 구획을 정리에 반영했는지 스스로 점검하세요. 단, 이 점검 내용은 위 출력 형식(핵심 요약 문서)에는 절대 포함하지 말고, 문서 맨 끝에 구분선(---)을 그은 뒤 "[부속 메모 — 검토용, 공유 문서에는 포함하지 마세요]"라는 표시와 함께 원문 구획 각각과 반영 여부(반영 / 부분 반영+사유 / 생략+사유)를 별도로 정리해주세요. 공유용 요약 본문과 작성자용 검토 메모를 분리해야, 요약을 그대로 전달받는 사람이 내부 점검 흔적 없이 깔끔한 문서를 받기 때문입니다.

출력 형식:
- 한 줄 결론
- 핵심 요약 (3~7개 불릿, 원문 인용 포함)
- 구획별 상세 정리 (원문 구조 순서대로)
- 상충하거나 불확실한 지점
- 지정 지점 확인 결과 (반드시 짚어야 할 지점이 있는 경우)
- (구분선 아래, 별도 표시) 부속 메모: 커버리지 자가점검
```

## 해부

### 역할

> 바쁜 실무자를 위해 긴 자료를 정확하게 요약하는 리서치 어시스턴트

요약을 소비하는 사람이 시간이 없다는 전제를 역할에 못박아, 장황한 감상형 요약이 아니라 스캔형 요약이 나오게 합니다.

### 맥락

> 자료 종류 + 요약 목적 + 읽을 사람 + 원하는 길이 + 반드시 짚어야 할 지점 + 원문 전체

같은 자료도 "투자 판단용"과 "팀 공유용"은 다른 문장이 핵심입니다. 목적 필드가 그 렌즈를 고정하고, `focus_points`가 실무자만 아는 확인 우선순위를 놓치지 않게 합니다.

### 정리 기준

> 결론 우선 → 구획별 순회 → 인용 근거 → 상충 병기 → raw 창작 금지 → 커버리지 자가점검(부속 분리)

이 도메인의 본질 리스크는 누락이다 — 원문이 길수록 AI가 눈에 띄는 일부에만 집중하고 중간에 묻힌 내용을 건성으로 읽는다. 후보 a와 동일하게 구획을 먼저 파악해 순서대로 훑게 하되, 점검 결과는 공유용 요약 본문이 아니라 구분선 아래 별도 부속 메모로 분리합니다.

### 출력 형식

> 한 줄 결론 → 핵심 요약 → 구획별 상세 → 상충/불확실 → 지정 지점 확인 → (구분선) 부속 메모: 커버리지 자가점검

메인 요약은 그대로 복사해 전달해도 되는 완결된 문서로 남기고, 점검 흔적은 구분선 아래로 밀어 작성자만 확인하고 지워도 되는 부속물로 둡니다.

## 팁

- 부속 메모에서 "부분 반영"으로 표시된 구획이 있으면, 그 구획만 다시 원문을 붙여넣고 "이 부분만 더 자세히 정리해줘"라고 요청하세요.
- 요약을 그대로 다른 사람에게 전달할 때는 구분선 아래 부속 메모를 지우고 위쪽 본문만 보내세요.
