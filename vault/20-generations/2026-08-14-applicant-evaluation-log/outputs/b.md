## 평가 기준 카드

### 카드 1
- **기준 원문:** (필수) 최근 2년 내 React 기반 실무 프로젝트를 주도적으로 이끈 경험
- **대응 발언:**
  - 면접관: "최근 2년 안에 React로 진행한 프로젝트 중 본인이 주도적으로 이끈 경험이 있으면 말씀해주세요."
  - 지원자: "네, 작년에 사내 어드민 대시보드를 리뉴얼하는 프로젝트가 있었는데, 제가 처음부터 컴포넌트 구조랑 상태관리 방식(React Query + Zustand 조합)을 설계했고, 프론트엔드 파트 인원 2명을 데리고 3개월간 이끌었습니다."
- **판정: 충족**

### 카드 2
- **기준 원문:** (필수) 협업 중 갈등 상황을 실제로 해결한 구체적 사례
- **대응 발언:**
  - 면접관: "그 프로젝트 진행하면서 팀원이나 다른 팀과 의견이 부딪힌 적은 없었나요? 있었다면 어떻게 풀어가셨는지 궁금합니다."
  - 지원자: "음... 저희 팀은 다들 성향이 맞아서 크게 부딪힌 적은 없었던 것 같아요. 다들 잘 맞춰주셔서 큰 갈등 없이 진행했습니다."
- **판정: 미충족**
- (판정 근거: 면접관이 갈등 상황과 해결 과정을 구체적으로 요청했으나, 지원자는 갈등이 없었다는 취지로 답했을 뿐 실제로 부딪힌 뒤 해결한 구체적 사례를 제시하지 않음. 면접 발언 전체를 다시 살펴봐도 이를 대체할 만한 갈등 해결 사례는 발견되지 않음.)

### 카드 3
- **기준 원문:** (필수) 성능 최적화 경험과 그 결과를 구체적 지표로 설명할 수 있는가
- **대응 발언:**
  - 면접관: "성능을 개선해본 경험이 있다면, 어떤 지표가 어떻게 바뀌었는지 구체적으로 말씀해주시겠어요?"
  - 지원자: "어드민 대시보드 초기 로딩이 느려서 코드 스플리팅이랑 이미지 lazy loading을 적용한 적이 있어요. 정확한 수치는 지금 기억이 잘 안 나는데, 팀장님이 확실히 체감될 정도로 빨라졌다고 피드백 주셨던 건 기억나요."
- **판정: 부분충족**
- (판정 근거: 성능 최적화를 실제로 수행한 경험 자체는 확인되나, 본인이 직접 "정확한 수치는 기억이 안 난다"고 밝혀 구체적 지표는 제시되지 않음. 개선 사실은 인정되나 정량적 근거는 없음.)

### 카드 4
- **기준 원문:** (우대) 최근 1년 내 새로운 기술을 스스로 학습해 적용한 사례
- **대응 발언:**
  - 면접관: "최근에 새로 배운 기술이 있다면요?"
  - 지원자: "최근 두 달 정도 사내 스터디에서 Next.js 14 App Router를 공부했고, 배운 걸 바로 개인 사이드 프로젝트(중고거래 플랫폼 클론)에 적용해봤어요. 서버 컴포넌트랑 클라이언트 컴포넌트를 어떻게 나눠야 하는지 직접 부딪히면서 배웠습니다."
- **판정: 충족**

### 카드 5
- **기준 원문:** (필수) 코드 리뷰 문화에 기여한 경험
- **대응 발언:**
  - 면접관: "코드 리뷰는 어떻게 하고 계신가요?"
  - 지원자: "저희 팀은 PR 올리면 리뷰 받는 게 프로세스라 저도 당연히 참여하고 있어요."
- **판정: 부분충족**
- (판정 근거: 팀에 이미 정착된 코드 리뷰 프로세스에 참여하고 있다는 사실은 확인되나, 본인이 리뷰 문화를 만들거나 개선·주도한 구체적 기여 사례는 언급되지 않음. 기존 프로세스 준수 이상의 근거는 발언 전체에서 확인되지 않음.)

## 평가 기준 목록 밖 특이 발언

- **발언 원문:** 지원자: "네, 지난 2년 동안 쭉 한 회사에서 일했습니다." (이후 면접관이 이력서상 이전 회사 재직 기간(2023년 3월~2024년 11월)을 근거로 재질문하자) 지원자: "아, 그게 사실 2024년 11월에 퇴사하고 나서 3개월 정도는 프리랜서로 몇 개 프로젝트를 받아서 했었어요. 그러다가 올해 3월부터 지금 회사에 합류했습니다."
  - **주목할 만한 이유:** 경력 공백 여부를 직접 물었을 때 지원자는 처음에 "쭉 한 회사에서 일했다"고 답했으나, 면접관이 이력서 재직 기간을 근거로 다시 확인하자 실제로는 2024년 11월 퇴사 후 약 3개월간 프리랜서로 활동했고 올해 3월에 현재 회사에 합류했다고 정정함. 최초 답변과 이후 정정 답변, 이력서 기재 재직 기간 사이에 불일치가 있었다는 사실 자체가 기록으로 남을 필요가 있음.

- **발언 원문:** 지원자: "사이드로 오픈소스 라이브러리를 하나 만들어서 관리하고 있는데, 깃허브 스타가 200개 정도 됩니다. 실무 외 시간에도 계속 코드를 보고 있다는 걸 말씀드리고 싶어요."
  - **주목할 만한 이유:** 평가 기준 어디에도 직접 대응하지 않지만, 업무 외 시간에 오픈소스 라이브러리를 자발적으로 만들고 지속적으로 관리하고 있다는 진술로, 실무 외 학습·기여 의지를 보여주는 자발적 강점 발언임.
