# 후보 a — 필수 빈칸 4개로 5분 안에 채워 바로 제출용 초안까지 뽑는 최소 빈칸 이력서 템플릿

## Fields
| key | label | type | optional | help | placeholder | options |
|-----|-------|------|----------|------|------|---------|
| target_role | 지원 직무 | text | | 직무명과 연차를 함께 적으면 문체와 강조점이 그 연차 수준에 맞춰집니다. | 예: 콘텐츠 마케터 (2~3년차 경력직) | |
| target_company | 지원 회사 · 채용공고 요구역량 | textarea | | 회사명과 특징, 공고에 적힌 요구역량을 붙여넣으세요. 이 내용이 구체적일수록 이력서가 "아무 회사에나 내는 이력서"처럼 보이지 않습니다. | 예: 그린테이블(신선식품 새벽배송 스타트업, 시리즈B) / 요구역량: 데이터 기반 콘텐츠 기획, SNS·이메일 마케팅 운영 경험, 콘텐츠 제작 툴 활용 능력 | |
| career_raw | 경력·학력·자격 (raw 메모) | textarea | | 정리되지 않은 메모 그대로 붙여넣어도 됩니다. 재직기간, 담당업무, 구체적 수치(팔로워·매출·개선율 등), 학력, 자격증을 빠짐없이 적어주세요. 여기 없는 내용은 AI가 만들어내지 않습니다. | 예: 미미박스 콘텐츠팀 인턴→계약직 전환(2023.01~2024.12) / 인스타 카드뉴스·릴스 기획 주4건 / 팔로워 8,200→15,600(90%↑, 1년반) / 신제품 캠페인 3건 중 1건 메인 기획, 관련 게시물 평균 도달 12만·저장 900건(팀평균 2배) / 뉴스레터 오픈율 22%→31%(제목 A/B테스트 도입) / Canva·프리미어 기초·GA4 리포트 / 한국대 미디어커뮤니케이션학과 졸업(2023.02) / 컴활2급, GAIQ | |
| concern | 강조하고 싶은 점 · 걱정되는 부분 | textarea | | 가장 자신 있는 성과와, 약점처럼 보일까 걱정되는 이력(경력 공백, 비정규직 위주 등)을 함께 적어주세요. 약점은 감출수록 더 크게 보입니다. | 예: 강조 - 인턴에서 계약직으로 전환된 점, 숫자로 증명한 캠페인 성과 / 걱정 - 정규직 경력이 없고 전부 인턴·계약직이라 이 부분이 약점으로 보일까 걱정 | |
| extra_request | 추가로 반영하고 싶은 것 | textarea | true | 분량, 어투, 특정 형식 등 더 반영하고 싶은 것이 있으면 적어주세요. 없으면 비워도 됩니다. | 예: A4 1장 분량 유지, 자기소개서 느낌의 문장은 빼고 담백한 어투로 | |

## Template
```
당신은 스타트업·IT 업계 채용을 다수 진행해온 헤드헌터 출신 이력서 첨삭 코치입니다. 채용공고의 요구역량과 지원자의 실제 경험을 정확히 매칭시켜 서류 통과율을 높이는 것이 전문 분야입니다.

아래 정보를 바탕으로 한국어 이력서/경력기술서를 작성해주세요.
- 지원 직무: {{target_role}}
- 지원 회사 · 채용공고 요구역량: {{target_company}}
- 경력·학력·자격 (raw 메모): {{career_raw}}
- 강조하고 싶은 점 · 걱정되는 부분: {{concern}}
- 추가로 반영하고 싶은 것: {{extra_request}}

요구사항:
1. 경력은 최신순(역순 연대기)으로 배치하고, 각 항목은 "~을 담당했다/관리했다"가 아니라 기획, 개선, 운영, 분석, 전환 같은 액션 동사로 문장을 시작하세요.
2. 성과는 위 raw 메모에 있는 수치와 사실만 사용해 정량화하세요(예: "팔로워 8,200→15,600, 90% 증가" 형태). raw 메모에 없는 성과나 숫자는 절대 지어내지 말고, 표현이 애매해 확인이 필요한 부분은 [확인 필요: 무엇을 확인해야 하는지]로 표시하세요.
3. 지원 회사·채용공고 요구역량에 나온 키워드를 실제 경험 문장 속에 자연스럽게 녹여 배치하세요. 키워드를 그대로 나열하지 말고 문맥 안에 스며들게 하세요.
4. 걱정되는 부분에 적힌 약점(경력 공백, 비정규직 위주 이력 등)은 숨기거나 변명하지 말고, 이력서 상단 요약에서 정면으로 인정한 뒤 raw 메모의 실제 데이터(전환 이력, 정량 성과 등)로 반박하세요.
5. 전체 분량은 A4 1페이지를 넘지 않도록 핵심만 압축하고, 실무와 무관한 미사여구는 덜어내세요.
6. 초안을 완성한 뒤에는 지원 회사의 채용 담당자 입장에서 다시 읽고 "이 지원자를 왜 탈락시켜야 할까"를 스스로 찾아 최소 두 곳을 고친 최종본만 출력하세요. 중간 검토 과정 자체는 출력하지 마세요.
7. 이력서 본문 안에는 ①②③ 같은 구조 기호를 쓰지 말고, 실제 이력서에 쓰이는 문장과 항목 형태로만 작성하세요.

출력 형식:
- 이력서 상단 요약 (3줄 이내, 약점 정면 반박 포함)
- 경력기술서 본문 (역순 연대기, 성과 중심)
- 학력·자격 요약
- 핵심 문장 대안 후보 (상단 요약 문장을 다른 어투로 2개 더 제안)
- 제출 전 셀프 체크리스트 (키워드 매칭, 수치 근거, 분량, 약점 서술 톤 등)
- 예상 면접 질문 5개 (이 이력서 내용 기반, 약점 관련 질문 최소 1개 포함)
```

## Anatomy
1. 역할 — 인용: "헤드헌터 출신 이력서 첨삭 코치입니다. 채용공고의 요구역량과 지원자의 실제 경험을 정확히 매칭시켜 서류 통과율을 높이는 것이 전문 분야입니다." / 이유: 단순 '이력서 작가'가 아니라 채용공고와 지원자를 매칭하는 헤드헌터 관점을 고정해, 요구사항 3·4번(키워드 매칭·약점 반박)이 역할 정체성에서 자연스럽게 이어지게 만든다.
2. 맥락 — 인용: "지원 직무 / 지원 회사·채용공고 요구역량 / 경력·학력·자격(raw 메모) / 강조점·걱정되는 부분 / 추가로 반영하고 싶은 것" / 이유: 결과물에 실제로 실릴 데이터(경력·수치·학력)를 전부 필수 빈칸(career_raw)에 몰아 받아 AI가 가짜 경력을 창작할 여지를 없앤다. 대상 맥락(지원 회사·요구역량)과 설득 재료(강조점)도 전용 빈칸으로 분리해 특정성을 확보한다.
3. 요구사항 — 인용: "raw 메모에 없는 성과나 숫자는 절대 지어내지 말고... [확인 필요]로 표시" / "약점은 숨기거나 변명하지 말고... 정면으로 인정한 뒤... 반박" / "채용 담당자 입장에서 다시 읽고... 최소 두 곳을 고친 최종본만 출력" / 이유: 근거 요구(환각 억제)·약점 정면 인정 후 반박·자기검증 루프 세 가지 품질 장치를 한 번에 내장해, 검증 가능한 기준으로 결과를 스스로 점검하게 만든다. 역순 연대기·액션 동사·정량화·키워드 매칭·1페이지 원칙 같은 이력서 검증된 프레임워크는 빈칸으로 묻지 않고 문장에 통째로 내장했다.
4. 출력 형식 — 인용: "핵심 문장 대안 후보 / 제출 전 셀프 체크리스트 / 예상 면접 질문 5개" / 이유: 본문 한 뭉치가 아니라 실제 제출 워크플로에 필요한 발송 세트(대안 후보로 발산→수렴, 셀프 체크, 다음 관문인 면접까지 대비)까지 한 번에 받아 결과를 받은 즉시 검토·제출·면접 준비로 이어지게 한다.

## Tips
- career_raw는 정리하지 않은 날것 메모를 그대로 붙여넣을수록 좋습니다. 다듬어서 요약해 넣으면 오히려 AI가 근거로 삼을 구체적 수치가 줄어듭니다.
- concern에는 반드시 약점(공백기, 비정규직 이력 등)을 적어주세요. 비워두면 요구사항 4번이 적용될 재료가 없어 약점 방어 문장이 결과물에서 빠집니다.
- extra_request를 비우면 해당 줄이 통째로 사라지므로, "이 정도면 충분하다" 싶으면 굳이 채우지 않아도 됩니다 — 이 템플릿은 필수 4개(target_role, target_company, career_raw, concern)만 채워도 바로 쓸 수 있는 초안이 나오도록 설계되었습니다.
