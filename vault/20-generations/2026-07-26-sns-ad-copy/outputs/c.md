## 최종 광고 카피

[광고] 재택근무 하면서 원두 떨어질 때마다 사러 나가야 하는 거, 번거로우셨죠.

자체 로스터리에서 원두를 볶아 매달 집으로 보내주는 모닝빈 구독을 유료 광고로 소개해 드려요.

1인이 직접 운영하는 로스터리라 로스팅 후 3일 안에 바로 발송돼요. 250g 두 봉지가 한 달 분으로 오고, 가격은 월 29,000원이에요.

지금 87명이 구독 중이고, 3개월째 유지율은 71%예요. 구독자 한 분은 "출근 전에 원두 사러 나가는 시간이 없어졌어요"라는 후기를 남겨주셨어요.

커피는 어차피 매일 마신다면, 이번 달부터 모닝빈으로 받아보세요.

## 금지 표현 자가검증 체크리스트

- [x] 근거 없는 최상급·순위가 없는가 — "업계 1위/최고/최초/유일" 등 미사용
- [x] 효능을 단정하지 않았는가 — 카페인 효과 등 건강·효능 표현을 전혀 쓰지 않고 신선도·배송 사실만 서술
- [x] 무근거 비교가 없는가 — 경쟁사·카페 대비 가격/품질 비교 문구 없음 (비교 데이터 미확보 상태를 반영)
- [x] 조작된 긴박감이 없는가 — "마감임박"·"품절임박" 등을 쓰지 않고 87명이라는 수치를 담백하게만 제시
- [x] 광고 표시가 눈에 띄게 들어갔는가 — 맨 앞 "[광고]" 태그 + 본문 내 "유료 광고로 소개해 드려요" 문장으로 이중 고지

## 대안 표현 메모

- "3개월 유지율 업계 최고 수준" → 업계 평균 유지율을 확인한 적이 없어 상대적 우수성을 주장할 근거가 없는 무근거 비교였음 → 대신 "3개월째 유지율은 71%예요"로 수치만 그대로 제시
- "87명, 벌써 마감 임박 / 지금 아니면 늦어요" → 실제 정원·재고 제한 데이터가 없는데 긴박감만 만들어내는 조작된 긴박감이었음 → 대신 "지금 87명이 구독 중이에요"로 있는 그대로의 구독자 수만 전달
- "다들 맛보다 편의성 때문에 구독해요" → 구독 이유를 데이터나 설문으로 확인한 적 없는 추측을 단정형으로 쓰면 근거 없는 주장이 됨 → 대신 실제 확보된 후기 원문 "출근 전에 원두 사러 나가는 시간이 없어졌어요"만 그대로 인용
- "카페보다 훨씬 저렴하게" → 카페 대비 가격 비교를 실제로 해본 적이 없어 무근거 비교에 해당 → 대신 "가격은 월 29,000원이에요"라는 사실만 제시하고 비교 문구는 넣지 않음

## 심사 반려 대응 메모

가장 먼저 의심할 조항: 첫 문장이 "재택근무 하면서… 번거로우셨죠"처럼 독자의 생활 방식을 2인칭으로 직접 짚어 말하는 형식이라, 플랫폼의 개인 속성(생활 상황 단정) 관련 심사 기준에 걸려 반려될 가능성이 가장 큽니다.
수정 방향: 2인칭 직접 지칭("~하셨죠")을 3인칭 일반 서술(예: "재택근무 중엔 원두 떨어지는 순간이 은근히 번거롭습니다")로 바꿔 특정 독자를 지목하지 않는 표현으로 완화합니다.
