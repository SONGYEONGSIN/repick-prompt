# 테스트 시나리오 — SNS 광고 카피 작성 (R20)

> 세 후보 모두 **이 시나리오 하나**로 실제 결과물을 만든다. 심사자는 이 문서만 보고 결과물을 대조하므로,
> values.json에 채우는 모든 사실을 여기 빠짐없이 적는다 ([[2026-07-12-cold-email/DECISION|R1]] 재검·[[2026-07-17-process-judgment/DECISION|R11]]에서 2회 실측된 오판 원인).

## 상황

1인 운영 원두 구독 서비스 **"모닝빈"** 의 대표가 인스타그램 유료 광고를 처음 집행하려 한다.

## 사실 (values에 들어가는 전부)

**제품·가격**
- 월 구독: 원두 250g × 2봉 / 월 **29,000원**
- 자체 로스터리 운영, **로스팅 후 3일 이내 발송**

**타깃**
- 30~40대 재택근무자, 커피를 매일 마심
- 카페 지출(월 10만원 안팎)에 부담을 느끼는 사람

**광고 목표·집행 조건**
- 목표 행동: **첫 구독 결제** (무료 체험 신청이 아님)
- 채널: 인스타그램 피드 + 릴스
- 예산: **하루 3만원, 2주간**

**보유한 실데이터 (raw)**
- 기존 구독자 **87명**
- 3개월 유지율 **71%**
- 구독자 후기 원문: *"출근 전에 원두 사러 나가는 시간이 없어졌어요"*

**모르는 것 (raw에 없음 — 확인 안 됨)**
- 경쟁사 대비 가격이 싼지 비싼지 비교해 본 적 없음
- 구독 서비스 업계 평균 유지율이 얼마인지 모름

**감 (근거 없는 개인 추측)**
- "사람들이 맛보다 **편의성** 때문에 구독하는 것 같다" — 물어본 적도, 데이터로 확인한 적도 없음

**제약**
- 건강·효능 표현 금지 (카페인의 건강 효과 등)
- 광고임을 표시해야 함

## 이 시나리오가 시험하는 것

| 축 | 함정 |
|---|---|
| 실데이터 활용 | 87명·71%·후기 원문을 실제로 쓰는가, 아니면 그럴듯한 다른 숫자를 만드는가 |
| raw 창작 금지 | "업계 평균보다 높은 유지율", "가장 저렴한" 등 확인 안 된 비교 주장을 만드는가 |
| 감의 출처 유지 | 개인 감(편의성)을 "사람들은 편의성 때문에 구독합니다" 같은 외부 통설로 승격시키는가 ([[2026-07-20-insta-content/DECISION]] (R15)) |
| 측정 본질 | 예산·기간·목표 행동이 주어졌는데 성과 판정 기준을 내놓는가, 카피만 던지는가 |
| 심사·규제 | 최상급·효능 표현을 피하고 광고 표시를 처리하는가 |
| 소비 문법 | 피드 스크롤 0.5~2초, "더보기" 접힘 전 첫 줄을 의식하는가 |
