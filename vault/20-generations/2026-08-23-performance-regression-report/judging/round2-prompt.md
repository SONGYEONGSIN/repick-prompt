### 1. 박서연 — "칸반보드 로딩이 요즘 답답할 정도로 느려요. 예전보다 훨씬 자주 그런 것 같고, 하루에도 몇 번씩 멈칫거려요."

(참고: "8/17(월) 오전 배포 로그: 칸반보드 카드 렌더링 로직 리팩토링 v3.9.0 프로덕션 배포 완료." / 보조 자료로 "8/19(수) 저녁 7시 모니터링: 동시 접속 480세션(이번 주 최고 피크), 카드 목록 API P95 890ms, P50 310ms"도 있으나, 이는 세션 수 조건(480 vs 150)이 기준선과 달라 직접 대조 대상은 아님.)
