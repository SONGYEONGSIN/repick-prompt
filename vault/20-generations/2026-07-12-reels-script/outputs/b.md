# 스티치룸 자수 원데이 클래스 — 30초 숏폼 대본 세트

## 1. 첫 3초 훅 후보 3개

**후보 A — 질문형**
- 대사: "손으로 뭐 만드는 거… 나만 못하는 거 아니었어?"
- 화면 자막: `바느질 한 번도 안 해봤는데요`

**후보 B — 반전·의외형**
- 대사: "이거 방금 처음 바늘 잡은 사람이 만든 거예요."
- 화면 자막: `이거… 오늘 처음 바느질한 사람 작품`

**후보 C — 공감형**
- 대사: "손재주 없어서 못 한다고요? 여기 90%가 그래요."
- 화면 자막: `수강생 90%가 바느질 처음`

## 2. 최종 대본 1개 (30초)

> 선택 훅: 후보 B (반전·의외형) — 완성물부터 보여주고 "이걸 초보가?"로 궁금증 유발

| 초 단위 시간 | 화면에 보이는 것 | 말 또는 자막 |
|---|---|---|
| 0~3초 | 완성된 이니셜 손수건을 손에 들고 카메라 가까이 툭 내밀기 | (말) "이거 방금 처음 바늘 잡은 사람이 만든 거예요." / 자막: `이거… 오늘 처음 바느질한 사람 작품` |
| 3~9초 | 바늘·실을 어색하게 쥔 손 클로즈업, 카메라 향해 실 꿴 바늘 흔들기 | (말) "네, 저도 똥손이에요. 근데요." / 자막: `똥손도 됩니다` |
| 9~16초 | 천 위에 이니셜 밑그림 따라 한 땀 한 땀 놓는 손 | (말) "왕초보도 2시간이면 이니셜 손수건 하나 완성." / 자막: `왕초보 → 2시간이면 이니셜 손수건 완성` |
| 16~23초 | 테이블에 놓인 재료 세트, 손가락으로 하나씩 짚기 | (말) "성수동에서, 매주 토요일 오후 2시, 딱 4명만." / 자막: `성수 · 매주 토요일 오후 2시 · 정원 4명` |
| 23~27초 | 완성 손수건을 예쁘게 펼쳐 각도 바꿔 보여주기 | (말) "2시간 원데이, 3만 5천 원, 재료까지 다 포함." / 자막: `2시간 원데이 · 3.5만원 (재료 포함)` |
| 27~30초 | 손수건 옆에 얼굴 살짝 들이밀고 씩 웃기, 화면 아래를 손가락으로 가리키기 | (말) "토요일 자리 궁금하면… 프로필 한 번 눌러봐요." / 자막: `예약은 프로필 링크에서 (네이버 예약)` |

## 4. 혼자 아이폰으로 찍는 촬영 팁 3개

1. **구도 — 손과 손수건이 주인공.** 폰을 테이블 위 컵이나 책 몇 권에 기대 세워두고, 화면 가운데를 비워 그 자리에서 손을 움직이세요. 얼굴은 굳이 다 안 나와도 되고, 손 클로즈업이 초보 티도 자연스럽게 살려줍니다.

2. **밝기 — 창문을 정면 아니면 옆에.** 공방 안에서 찍을 땐 낮 시간 창가 자리에 테이블을 붙이고, 창을 등지지 말고 창을 마주 보거나 옆에 두세요. 등지면 손이 시커멓게 나옵니다. 캡컷에서 마지막에 '밝기' 살짝만 올려도 충분합니다.

3. **손 떨림 — 폰은 고정, 나만 움직이기.** 폰은 절대 손에 들지 말고 어딘가에 기대 고정한 채로 촬영하세요. 카메라가 아니라 내 손과 손수건만 움직이면 흔들림이 거의 없습니다. 클로즈업 장면은 팔꿈치를 테이블에 붙이고 찍으면 더 안정적입니다.
