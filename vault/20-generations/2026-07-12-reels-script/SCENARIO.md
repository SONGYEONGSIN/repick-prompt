# R4 테스트 시나리오 — 인스타 릴스·숏폼 대본

> 모든 후보를 **동일한 사실 집합**으로 채워 조립한다. 후보별 필드 구성이 다르므로,
> 아래 사실에서 각 필드에 해당하는 값을 그대로 매핑한다 (새 사실 창작 금지).

## 상황 (초보자 페르소나: 릴스를 처음 만드는 공방 운영자)

- **사용자**: 김하늘 — 성수동 자수 원데이 클래스 공방 "스티치룸" 운영, 릴스 제작 경험 거의 없음, 팔로워 800명
- **목표 영상**: 30초 릴스 — "왕초보도 2시간이면 이니셜 손수건 자수 완성" 클래스 홍보
- **타깃 시청자**: 손으로 뭔가 만들고 싶은 20~30대 직장인 여성
- **클래스 실데이터**: 2시간 원데이 코스 3.5만원(재료 포함) / 정원 4명 / 매주 토 오후 2시 / 완성물은 이니셜 손수건
- **후킹 소재**: 수강생 90%가 바느질이 처음 / "똥손도 됩니다" 컨셉
- **CTA**: 프로필 링크(네이버 예약)에서 예약
- **톤**: 유쾌하고 힘 빼는 톤, 과장 금지
- **촬영 여건**: 아이폰 1대, 공방 내부, 혼자 촬영, 편집은 캡컷 초보 수준
- **피할 것**: 유행 지난 밈, "인생이 바뀝니다" 류 과장, 특정 저작권 음악 지정

## 심사 기준 (블라인드)

1. 지시 이행도 — 프롬프트의 요구사항을 결과물이 실제로 지켰나
2. 바로 사용 가능성 — 이 대본을 들고 오늘 혼자 아이폰으로 촬영에 들어갈 수 있나 (장면별 촬영 지시가 여건 안에 있나, 30초 분량이 실제로 맞나)
3. 구체성 — 클래스 사실(3.5만원·정원 4명·토 2시·이니셜 손수건·90% 초보)이 대본에 살아 있나
4. 환각·과장 억제 — 시나리오에 없는 수치·후기·과장 문구를 지어내지 않았나
