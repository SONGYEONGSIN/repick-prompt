# 후보 a — 최소 빈칸: 4칸만 채우면 나머지는 프롬프트가 알아서 정하는 오늘 촬영용 대본 세트

## fields
| key | label | type | optional | help | placeholder | options |
|-----|-------|------|----------|------|-------------|---------|
| subject | 무엇을 알리는 영상인가 | text | no | 이 영상으로 알리고 싶은 것 한 줄이면 됩니다. 가게·제품·클래스·이벤트 무엇이든 좋아요. | 성수동 자수 공방 '스티치룸'의 이니셜 손수건 만들기 원데이 클래스 홍보 | |
| real_info | 영상에 꼭 들어갈 실제 정보 | textarea | no | 가격·시간·일정·정원·완성물처럼 영상에 실제로 나와야 하는 정보를 아는 대로 적어주세요. 여기 적은 것만 대본에 들어가고, 안 적은 건 AI가 지어내지 않습니다. 이 칸이 영상을 '내 것'으로 만드는 핵심입니다. | 2시간 코스 / 3.5만원(재료 포함) / 정원 4명 / 매주 토요일 오후 2시 / 완성물은 이니셜 손수건 | |
| hook_point | 시선을 붙잡을 한 가지 | text | no | 영상 첫 2초에 사람을 멈추게 할, 남들과 다른 한 가지입니다. 놀라운 사실, 흔한 오해, 솔직한 고백 무엇이든 좋아요. | 수강생 90%가 바느질 처음 — 손재주 없어도 2시간이면 완성 | |
| cta | 영상을 본 사람이 했으면 하는 것 | select | no | 숏폼은 한 영상에 부탁 하나만 담을 때 가장 잘 먹힙니다. 고민되면 '프로필 링크에서 예약/구매하기'를 고르세요. | 프로필 링크에서 예약/구매하기 | ["프로필 링크에서 예약/구매하기", "댓글로 질문·신청 남기기", "저장하고 다음에 다시 보기", "팔로우하고 다음 편 기다리기", "DM으로 문의하기"] |
| target | 누구에게 보여주고 싶나 | text | yes | 비워두면 위에 적은 홍보 대상에서 자연스럽게 짐작해 정합니다. 떠오르면 한 줄만 적어주세요. | 손으로 뭔가 만들어 보고 싶은 20~30대 직장인 | |

## template

```
당신은 한국어 인스타 릴스·쇼츠·틱톡 대본을 쓰는 숏폼 작가입니다. 영상을 처음 만드는 사람이 오늘 혼자 스마트폰으로 바로 촬영에 들어갈 수 있는 대본을 만드는 것이 당신의 목표입니다.

아래 정보를 바탕으로 30초 안팎의 숏폼 대본 세트를 만들어주세요.
- 무엇을 알리는 영상인가: {{subject}}
- 영상에 꼭 들어갈 실제 정보: {{real_info}}
- 시선을 붙잡을 한 가지: {{hook_point}}
- 영상을 본 사람이 했으면 하는 것: {{cta}}
- 보여주고 싶은 사람: {{target}}

요구사항:
1. 영상 전체 길이는 30초 안팎으로 잡고, 각 장면이 몇 초부터 몇 초까지인지 초 단위로 표시해 합이 30초에 맞게 해주세요. 첫 2초 안에 "시선을 붙잡을 한 가지"가 화면과 말·자막에 모두 드러나게 하고, "안녕하세요 여러분" 같은 뻔한 인사로 시작하지 마세요.
2. "영상에 꼭 들어갈 실제 정보"에 적힌 가격·일정·정원·완성물은 하나도 빼놓지 말고 적힌 그대로 대본과 자막에 넣어주세요. 거기 없는 수치·후기·인원·가격·효과는 절대 지어내지 마세요.
3. 소리를 끄고 보는 사람이 대부분입니다. 모든 장면에 화면에 얹을 짧은 자막을 따로 만들어, 음소거로도 내용이 전부 전달되게 해주세요.
4. 톤 지정이 없으면 친근하고 힘을 뺀, 과장 없는 말투(가벼운 반말 또는 해요체)로 써주세요. 보여주고 싶은 사람이 비어 있으면 홍보 대상에서 자연스럽게 짐작해 정하고, 지어낸 티가 나지 않게 해주세요.
5. 촬영은 스마트폰 1대로 혼자, 편집은 초보 수준이라고 가정하세요. 삼각대·조명·전문 장비가 없어도 찍을 수 있는 장면만 지시하고, 화면 지시는 "무엇을 어떻게 비추는지"까지 구체적으로 적어주세요.
6. 다음은 피해주세요: 유행 지난 밈이나 철 지난 챌린지, "인생이 바뀝니다"·"무조건"·"100%" 같은 근거 없는 과장, 특정 가수·곡을 저작권 음악으로 지정하는 것(대신 "잔잔한 배경음"처럼 분위기만 제안).
7. 대본의 마지막 대사·자막은 영상을 본 사람이 "영상을 본 사람이 했으면 하는 것"을 하도록 자연스럽게 이끄는 한마디로 끝내주세요.

출력 형식:
- 첫 2초 훅 문구 후보 3개 (서로 다른 각도: 놀라운 사실형 / 솔직한 고백형 / 질문형)
- 최종 대본 1개 — 아래 표로 정리:
  | 시간 | 화면에 보이는 것 | 하는 말(음성) | 화면에 얹을 자막 |
- 혼자 스마트폰으로 이 대본을 찍는 촬영 팁 3개 (카메라 각도 / 손이 나오는 장면 잡는 법 / 다시 찍을 때 요령)
- 인스타에 올릴 캡션 글 1개 + 어울리는 해시태그 5개 (과하지 않게)
- 올리기 전 확인할 체크리스트 4개 (마지막 항목은 "프로필에 예약·구매 링크가 걸려 있는지")
```

## anatomy

| part | quote | why |
|------|-------|-----|
| 역할 | "영상을 처음 만드는 사람이 오늘 혼자 스마트폰으로 바로 촬영에 들어갈 수 있는 대본을 만드는 것이 당신의 목표입니다." | 역할에 직업만 주지 않고 "오늘 혼자 촬영 가능"이라는 목표까지 고정하면, AI의 판단 기준이 "멋진 대본"에서 "장비 없이 찍히는 대본"으로 좁혀집니다. 모든 장면 지시가 그 제약 안에서 나옵니다. |
| 맥락 | "영상에 꼭 들어갈 실제 정보: {{real_info}}" | 이 템플릿은 빈칸이 4개뿐이라 나머지는 AI가 알아서 정합니다. 그럴수록 가격·일정 같은 실데이터만은 반드시 받아야 합니다 — 안 물으면 AI가 그 자리를 지어내 "내 것이 아닌" 영상이 됩니다. 최소 빈칸에서도 이 칸만은 필수로 남긴 이유입니다. |
| 요구사항 | "거기 없는 수치·후기·인원·가격·효과는 절대 지어내지 마세요." | 빈칸을 적게 두면 편하지만, AI가 빈 곳을 창작으로 메울 위험이 커집니다. 이 네거티브 조건이 그 위험을 막는 안전장치입니다 — 적게 묻는 대신, 모르는 건 지어내지 말라고 못 박습니다. |
| 출력 형식 | "훅 후보 3개 → 대본 표 → 촬영 팁 → 캡션·해시태그 → 올리기 전 체크리스트" | 훅을 여러 개 받아 고르는 발산→수렴 구조에, 촬영부터 업로드까지 이어지는 세트를 한 번에 받습니다. 대본만 주면 "이제 어떻게 찍지?"에서 멈추지만, 체크리스트로 끝나면 읽고 바로 촬영·업로드로 넘어가는 행동 착지가 됩니다. |

## tips

1. **훅 후보 3개를 실제로 테스트하세요.** 세 각도(놀라운 사실 / 솔직한 고백 / 질문) 중 하나로 먼저 찍어 올려 보고, 저장 수와 끝까지 본 비율이 높은 각도를 다음 영상의 기본값으로 삼으세요. 반응이 데이터가 되어 "시선을 붙잡을 한 가지" 칸을 채우는 눈이 점점 날카로워집니다.
2. **한 번 쓰고 버리지 말고 시리즈로 돌리세요.** "영상에 꼭 들어갈 실제 정보" 칸만 바꿔(다른 클래스·다른 메뉴·다른 이벤트) 같은 프롬프트를 다시 돌리면, 톤과 구조가 일관된 영상을 계속 찍어낼 수 있습니다. 계정 전체가 한 사람이 정성껏 만든 것처럼 보이기 시작합니다.
