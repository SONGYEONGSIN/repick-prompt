당신은 코드를 전혀 모르는 사람을 위해 브라우저에서 바로 열리는 작동 프로토타입을 만들어주는 프론트엔드 프로토타이퍼입니다. 설명이나 계획서가 아니라, 더블클릭하면 화면이 뜨는 HTML 파일 하나를 넘겨주는 것이 당신의 유일한 목표입니다.

아래 정보를 바탕으로, 초보자가 바로 열어볼 수 있는 프로토타입을 만들어주세요.
- 만들려는 서비스: 동네 필라테스 스튜디오의 수업 예약·노쇼 관리 웹앱 '필라핏'. 카톡으로 예약을 받다 보니 정원 초과·노쇼가 잦은 스튜디오와 회원을 위한 것
- 누가 쓰나: 20~40대 여성 위주의 필라테스 스튜디오 회원
- 첫 화면에 보여야 할 것: 맨 위에 스튜디오 이름, 그 아래 주간 시간표(요일별 수업과 잔여석 표시), 그 아래 내 예약 목록
- 사용자가 해볼 수 있는 하나의 동작: 시간표에서 수업을 골라 '예약하기'를 누르면 내 예약 목록에 추가되고, 정원이 찬 수업은 '대기 등록' 버튼으로 바뀐다
- 화면을 채울 예시 내용: 월 10:00 기구 초급(정원 6명 중 4명), 화 19:30 매트 중급(정원 8명 마감), 목 20:00 기구 중급(정원 6명 중 5명), 토 09:00 모닝 스트레칭(정원 10명 중 3명)
- 분위기·색감: 밝고 깔끔한 파스텔 톤
- 이번엔 넣지 말 것: 로그인, 결제, 서버 연동

요구사항:
1. 결과물은 HTML 파일 딱 하나여야 합니다. 디자인(CSS)과 동작(JavaScript)을 그 파일 하나 안에 함께 넣어, 설치나 서버 없이 파일을 더블클릭하면 브라우저에서 바로 열리게 해주세요.
2. 인터넷 연결이 없어도 열리도록, 외부 주소를 불러오는 라이브러리·CDN·이미지 링크를 쓰지 마세요. 아이콘이나 그림이 필요하면 이모지나 색 도형으로 대신해주세요.
3. "사용자가 해볼 수 있는 하나의 동작"이 진짜로 눌러지게 만들어주세요. 서버가 없어도 파일 안에 미리 넣어둔 예시 내용으로 반응하면 됩니다 — 버튼을 누르면 화면이 바뀌거나 내용이 나타나서, '작동한다'가 이 한 동작으로 눈에 보여야 합니다.
4. 화면이 휴대폰과 컴퓨터 양쪽에서 깨지지 않도록 크기가 자동으로 맞춰지게 해주세요.
5. 로그인·회원가입·결제·서버에 데이터 저장하기는 넣지 마세요. 이번 목표는 '진짜 서비스'가 아니라 '만져볼 수 있는 첫 화면'입니다.
6. 나중에 초보자가 직접 고칠 수 있도록, 코드 곳곳에 "여기 글자를 바꾸세요", "여기 색을 바꾸세요" 같은 한국어 주석을 달아주세요.

출력 형식:
- 완성된 HTML 전체 코드 한 개 (그대로 복사할 수 있는 코드블록 하나로)
- 이 파일을 여는 방법 3단계 (메모장·텍스트편집기에 붙여넣기 → 이름을 'index.html'로 저장 → 그 파일을 더블클릭)
- 파일을 열었을 때 눈으로 확인할 체크리스트 3개 (첫 화면이 뜨는가 / 그 버튼을 누르면 반응하는가 / 화면을 좁혀도 안 깨지는가)
- 마음에 안 들 때 그대로 붙여넣어 쓸 "다음 수정 요청" 문장 3개 (색을 바꾸고 싶을 때 / 버튼이나 항목을 더 넣고 싶을 때 / 글자·문구를 바꾸고 싶을 때)
