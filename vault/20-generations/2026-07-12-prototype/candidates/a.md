## template

```
당신은 코딩을 전혀 모르는 사람을 위해 '작동하는 프로토타입'을 만들어주는 시니어 프론트엔드 개발자입니다. 당신의 유일한 목표는, 상대가 파일을 더블클릭하는 것만으로 브라우저에서 바로 열어볼 수 있는 진짜로 동작하는 화면을 만들어내는 것입니다.

아래 아이디어로 작동하는 프로토타입을 하나 만들어주세요.
- 만들고 싶은 것: {{idea}}
- 이 화면에서 사용자가 하는 가장 중요한 행동: {{core_action}}
- 첫 화면에 꼭 보여야 하는 것: {{must_show}}
- 주로 쓰는 사람: {{who}}
- 화면 분위기: {{vibe}}

요구사항:
1. 결과물은 반드시 HTML 파일 하나여야 합니다. 디자인(CSS)과 동작(자바스크립트)을 모두 그 파일 안에 넣고, 외부 라이브러리나 인터넷 연결 없이도 열리게 해주세요.
2. 위에 적은 "가장 중요한 행동"은 실제로 눌렀을 때 화면이 반응하도록 만들어주세요. 버튼만 있고 아무 일도 안 일어나는 껍데기는 안 됩니다.
3. 화면이 비어 보이지 않게, 진짜처럼 보이는 예시 데이터를 3~5개 미리 채워 넣어주세요. "샘플1", "이름 없음" 같은 빈 값 말고 실제로 있을 법한 내용으로 넣어주세요.
4. 휴대폰과 컴퓨터 화면 모두에서 깨지지 않게 반응형으로 만들어주세요.
5. 제가 말하지 않은 것(색상·세부 문구·배치·예시 데이터)은 되묻지 말고, 가장 흔하고 무난한 기본값으로 알아서 정해서 끝까지 완성해주세요.
6. 다음은 피해주세요: 설치가 필요한 도구(React·npm 등) 사용, 파일을 여러 개로 쪼개기, 로그인·결제처럼 서버가 있어야 하는 기능을 실제로 구현하기 — 이런 건 눌러보면 되는 것처럼 보이게 화면으로 흉내만 내주세요.

출력 형식:
- 완성된 HTML 전체 코드 (그대로 복사할 수 있게 코드 블록 하나로)
- 이 파일을 여는 방법 3단계 (메모장·텍스트편집기 열기 → 코드 붙여넣고 "이름.html"로 저장 → 파일 더블클릭)
- 잘 만들어졌는지 확인하는 체크리스트 3개 (화면이 뜨는지 / 핵심 버튼이 반응하는지 / 휴대폰 크기에서도 보이는지)
- 다음에 고치고 싶을 때 그대로 복사해 쓸 수정 요청 문장 2개 (예: "색을 파란색 계열로 바꿔줘")
```

## anatomy

| part | quote | why |
|------|-------|-----|
| 역할 | "상대가 파일을 더블클릭하는 것만으로 브라우저에서 바로 열어볼 수 있는 진짜로 동작하는 화면을 만들어내는 것" | 역할에 "개발자"만 주면 그럴듯한 목업 이미지나 설명만 내놓기 쉽습니다. "더블클릭으로 열리는 동작하는 화면"이라는 목표를 역할에 못박으면, AI의 모든 선택이 "코드 모르는 사람이 실제로 결과를 보는 것"에 맞춰집니다. |
| 맥락 | "이 화면에서 사용자가 하는 가장 중요한 행동: {{core_action}}" | 초보자는 보통 아이디어만 던지고, 그러면 AI는 눌러도 아무 일 없는 정적인 그림을 줍니다. 필수 3칸 중 "가장 중요한 행동" 하나를 강제하면, 정지 화면이 아니라 실제로 눌리는 프로토타입으로 방향이 고정됩니다 — 최소 입력이면서도 '작동'을 놓치지 않는 장치입니다. |
| 요구사항 | "외부 라이브러리나 인터넷 연결 없이도 열리게 해주세요" | 코딩 초보를 가장 많이 좌절시키는 건 "npm install 하세요" 같은 설치 단계입니다. 단일 파일·오프라인을 요구사항으로 못박는 게 이 템플릿의 심장입니다 — 더블클릭 한 번으로 끝나야 코드를 모르는 사람이 결과를 직접 확인할 수 있습니다. |
| 출력 형식 | "여는 방법 3단계 → 확인 체크리스트 3개 → 수정 요청 문장 2개" | 코드 덩어리만 받으면 초보자는 그걸로 뭘 해야 할지 모릅니다. 여는 법·확인법·고치는 법까지 한 세트로 줘야 "받아서 바로 열어보는" 완결된 결과가 됩니다 — 결과물 하나가 아니라 사용 세트 전체를 착지시키는 부분입니다. |

## tips

1. **한 번에 완벽하게 만들려 하지 말고, 먼저 열어본 뒤 조금씩 고치세요.** 결과로 받은 HTML 전체 코드를 다시 붙여넣고 "이 코드에서 ○○만 바꿔줘"라고 요청하면, 앞서 만든 화면을 잃지 않고 이어서 개선할 수 있습니다. "처음부터 다시 만들어줘"라고 하면 이전 화면이 통째로 바뀌니 피하세요.
2. **다른 사람에게 링크로 보여주고 싶으면 무료 호스팅에 파일만 올리세요.** 완성된 HTML 파일을 Netlify Drop 같은 곳에 끌어다 놓기만 하면 인터넷 주소가 자동으로 만들어집니다. 코드를 전혀 몰라도 파일 하나만 있으면 주소로 공유할 수 있습니다.
