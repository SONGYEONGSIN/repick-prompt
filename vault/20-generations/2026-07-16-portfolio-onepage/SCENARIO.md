# R10 테스트 시나리오 — 포트폴리오 원페이지 제작 (인터랙티브)

> 공정성 주석 (R5 학습 이행): 3개 후보 생성 에이전트의 지시가 고정된 뒤, 후보·결과물 열람 전에 작성 — 양방향 오염 차단. 모든 후보를 동일한 사실 집합으로 채워 조립한다 (각 후보의 필드가 묻는 것만 아래 사실에서 채움).

## 페르소나

**김하늘(가명), 5년차 브랜드·그래픽 디자이너.** 에이전시 4년 + 뷰티 스타트업 인하우스 1년. 프리랜서 전환을 준비 중이라 잠재 클라이언트에게 보낼 웹 포트폴리오가 처음으로 필요해졌다. 코딩은 전혀 못 하고, 지금까지는 PDF 포트폴리오만 있었다.

## 사실 집합 (raw)

- **대상(볼 사람)**: 브랜딩·패키지를 의뢰할 소규모 F&B/라이프스타일 브랜드 대표들. 인스타 DM과 이메일로 링크를 보낼 예정.
- **프로젝트 raw 메모 3건**:
  1. 수제 그래놀라 '오트오트' 리브랜딩 (2024) — 로고, 패키지 6종, 인스타 템플릿. 결과: 패키지 리뉴얼 후 와디즈 펀딩 1,800만 원 달성(공개 수치). 대표가 "재방문 구매가 늘었다"고 말했으나 정확한 수치는 모름.
  2. 카페 '모루' BI (2023) — 로고, 간판, 메뉴판, 컵·포장 일체. 오픈 3개월 만에 지역 블로그·인스타에 다수 소개됨(집계 수치 없음). 공간 사진이 잘 나온 프로젝트.
  3. 뷰티 앱 '글로우데이' 브랜드 리뉴얼 (2025, 인하우스) — 디자이너 2명과 함께 리뉴얼 **리드**. 앱 스토어 스크린샷 일체, 온보딩 일러스트 12종. 마케팅팀이 "리뉴얼 후 스토어 전환율 12% 개선"이라 했으나 측정 기간은 기억나지 않음.
- **스킬·도구**: 브랜드 아이덴티티, 패키지 디자인, Illustrator·Photoshop·Figma
- **걱정**: ① 팀 작업(글로우데이)에서 내 역할이 어디까지인지 구분해 쓰는 것 ② 작업 사진·이미지 파일을 아직 준비 못 함
- **연락처**: hello@haneulkim.design · 인스타 @haneul.design
- **원하는 분위기**: 따뜻하지만 정돈된, 작업이 주인공

## 채점 관전 포인트

1. **성과 수치 정직 처리 (R9 원칙)** — "재방문 늘었다(수치 모름)", "12%(기간 불명)"를 확정형으로 쓰는가, [확인 필요]/뭉뚱그림으로 정직하게 처리하는가
2. **팀 역할 구분** — 인하우스 리드(2명과 협업)를 단독 성과처럼 부풀리는가
3. **인터랙션 실작동** — 외부 라이브러리 없이 단일 HTML로 인터랙션이 실제 작동하는 코드인가, 장식용 버튼은 없는가
4. **이미지 부재 처리** — 실제 이미지가 없는 상태에서 자리표시 문구 금지 원칙을 어떻게 지키며 완성하는가 (교체 가이드 포함 여부)
5. **대상 맥락 반영** — 소규모 F&B 브랜드 대표가 볼 포트폴리오로 특정되는가, 범용 디자이너 포트폴리오인가
6. **발송 세트 완결성** — 파일 여는 법·게시 방법·게시 전 체크리스트 등 행동 착지
