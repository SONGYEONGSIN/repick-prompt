# SCENARIO — 회의 액션아이템 이행 점검 (R59)

라틴 방진 3회(각 후보가 각 위치에 1회씩) 순서 편향 통제. 심사자는 이 문서만 보고 결과물을 대조하므로, values.json에 들어갈 모든 사실을 아래에 빠짐없이 명기한다.

## 배경

8인 스타트업 프로덕트팀의 위클리 회의(매주 월요일). 이번 점검은 **9/22(화) 회의 준비용**으로, 지난 6주(8/11~9/15) 동안 회의에서 나온 액션아이템 6건의 이행 상태를 회의 시작 전에 담당자 본인에게 확인 요청을 보내기 위해 작성한다. 작성자(회의 진행자 겸 점검표 작성자)와 각 항목의 실제 담당자는 분리되어 있다 — 감사형 도메인.

## 회의 이력 원문 (시간순, 화자 구분 — textarea 필드에 그대로 들어갈 원문)

```
[8/11 회의]
신중현(PM): 결제 모듈 QA 체크리스트를 김태오님이 맡아주세요. 8/15까지 초안 부탁드립니다.
김태오: 네, 알겠습니다.

[8/18 회의]
신중현: 김태오님, QA 체크리스트 어떻게 됐나요?
김태오: 죄송합니다, 아직 시작 못했어요. 이번 주 안에 하겠습니다.
신중현: 박서연님, 랜딩페이지 카피 초안은요?
박서연: 초안 나왔습니다, 8/20까지 공유드릴게요.

[8/25 회의]
신중현: 김태오님, QA 체크리스트는요?
김태오: 아직도 못했습니다... 다음 주엔 꼭 하겠습니다.
박서연: 랜딩페이지 카피 완료했습니다, 링크 공유드려요 (notion.so/copy-v2).
신중현: 감사합니다. 이수민님, 온보딩 가이드 오탈자 수정 건 9/10까지 부탁드려요. (신규 배정)
이수민: 네, 확인하겠습니다.
신중현: 정하준님, 결제 게이트웨이 벤더 계약서 검토는 9/26까지 부탁드립니다. (신규 배정)
정하준: 네, 진행하겠습니다.

[9/1 회의]
신중현: 김태오님, QA 체크리스트요.
김태오: 정말 죄송합니다, 이번 주도 다른 일 때문에 손을 못 댔어요.
신중현: 최윤재님, 결제 오류 로그 대시보드 연동은 8/29까지였는데 어떻게 됐나요?
최윤재: 완료했다고 지라에 올렸는데, 방금 확인해보니 지라 조회 권한 오류로 제 티켓이 안 열려요. 다시 확인해서 알려드릴게요.

[9/15 회의]
신중현: 김태오님, QA 체크리스트 이번엔 진짜 부탁드려요. 벌써 5주째입니다.
김태오: 네... 이번 주 안에 반드시 하겠습니다.
정하준: 벤더 계약서 검토 80% 정도 끝냈습니다, 이번 주 안에 마무리하겠습니다.
신중현: 감사합니다. 한지수님, 3분기 회고 자료는 9/30까지 준비해주세요. (신규 배정)
한지수: 네, 준비하겠습니다.
```

## 참석자와 역할

신중현(PM, 회의 진행자 겸 이 점검표 작성자), 김태오(백엔드), 박서연(마케팅), 이수민(콘텐츠), 정하준(법무·계약), 최윤재(백엔드), 한지수(운영)

## 점검 시점

2026년 9월 22일 (화) — 9/22 위클리 회의 시작 전

## 점검자

신중현, 프로덕트팀 PM

## 확인·안내 요청을 보낼 대상

각 항목은 원칙적으로 해당 담당자 본인에게 확인 요청을 보낸다. 단 최윤재 건처럼 **원인이 사내 시스템(지라) 조회 오류**인 경우는 IT팀(강민호, IT팀)에도 확인 요청을 보낸다.

## 이 점검을 하는 목적

9/22 위클리 회의 시작 전, 지난 6주간 배정된 액션아이템의 이행 현황을 담당자 본인에게 확인 요청 보내기 위한 점검 — 이 점검표 자체가 승인·판단 문서는 아니다.

## 확인 요청 회신 기한

9/23(화) 정오까지 — 9/23 오후에 있을 스프린트 계획 회의 전에 반영해야 함.

|---|---|---|---|---|---|---|
