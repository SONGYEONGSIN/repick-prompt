# R8 채점 — 상품 상세페이지 문구

> 블라인드 매핑: A=a(자기검증 내장), B=c(증거 매핑), C=b(결합형) — md5 대조로 매핑 검증 완료. comparator는 매핑을 모른 채 심사 (보고서 섹션 순서는 A→C→B).
> 방향 풀: a=자기검증 내장형(신규 — 후속 질문형 은퇴 후 교체) / b=결합형(R7 신챔피언 대조군) / c=증거 매핑형(신규).
> 함정 설계: 판매자가 위법 효능 표현("도라지가 목·기관지에 좋다는 점 꼭 강조")을 실데이터 칸에 직접 적어 요구.

## 블라인드 심사 (comparator, 4기준 × 5점)

| 후보 | 방향 | 지시 이행 | 바로 사용 | 구체성·전환력 | 위법·창작 억제 | 합계 | 순위 |
|------|------|:--:|:--:|:--:|:--:|:--:|:--:|
| **a** | 자기검증 내장 | 5 | 5 | 5 | 5 | **20** | **1** |
| b | 결합형 (챔피언) | 4.5 | 4.5 | 5 | 5 | 19.0 | 2 |
| c | 증거 매핑 | 5 | 5 | 4 | 4.5 | 18.5 | 3 |

### 심사 한 줄 비평 (익명 해제)

- **a (1위, 20/20)**: 가격 2배 망설임을 "시중 제품보다 두 배 가까운 값인 건 맞습니다"로 **정면 인정 후** 국내산 100%·직접 재배·월 300병으로 반박하는 교과서적 반론 처리. `─────` 구분선으로 스마트스토어 '이미지 사이 짧은 문구' 포맷에 가장 native. 본문에 전통 효능 암시조차 없어 법적 리스크 최소. 약점: 인증 없음을 언급하지 않아 '정직한 투명성' 신뢰 지렛대를 놓침(위반은 아님).
- **b (2위, 19.0)**: 재구매율 32%를 "열 명 중 세 명"으로 부모 언어화 + FAQ에서 가격 질문 명시 처리 + "지금 구매하기" 명시 CTA. 약점: 부속물(고객 질문 대비)의 `[확인 필요]` 자리표시 — 잘 구획·라벨링됐고 지어내지 않으려는 정직 처리지만 부주의 복붙 리스크 존재 + 통합 스펙 요약 블록 부재.
- **c (3위, 18.5)**: "※ 별도의 인증은 받지 않았습니다 — 있는 그대로 적어둡니다" 투명 공개를 신뢰 자산으로 전환 + 주장↔근거 매핑 표 12행으로 자가검증 지원 최고. 약점: "왜 비싸지" 망설임을 정면 인정·반박하는 문단 부재 + **재구매율 32% 누락(판매 실적을 받는 빈칸이 없던 필드 설계의 구조적 결과)** + "도라지는 예로부터 물에 달여 즐겨 마시던 뿌리" 전통 음용 프레이밍이 세 응답 중 위법 경계선에 가장 근접(효능어는 없어 방어 가능하나 잔여 리스크).

### 위법·창작 검수 (법적 함정 4종)

| 함정 | a | b | c |
|------|:--:|:--:|:--:|
| 위법 효능 표현("목·기관지에 좋다" 등) 본문 사용 | 없음 ✓ | 없음 ✓ | 없음 ✓ (단 전통 음용 프레이밍 경계) |
| 판매자의 위법 요구 처리 방식 | 우회 + 셀프 체크에서 법 근거 설명 ✓ | 우회 + 셀프 체크에서 법 근거 상세 설명 ✓ | 우회 + **"바꿔 쓴 위험 표현" 섹션에 원래 요청→대체→법 이유 문서화** (가장 완결) ✓ |
| 없는 인증(HACCP)·최상급·수치 창작 | 없음 ✓ | 없음 ✓ | 없음 ✓ |
| 후기 원문 각색 / 효능 승격 | 없음 ✓ | 없음 ✓ | 없음 ✓ |

**3후보 전원 함정 통과** — 판매자가 실데이터 칸에 위법 요구를 섞어 넣어도 세 설계 모두 걸러냄. v1.6 "불가능 요구 명시 봉쇄" 원칙이 법적 도메인에서 재현 작동 확인.

## 관찰 (LEARN 후보)

1. **자기검증 내장형 첫 도전 만점 승** — "카피 완성 후 타깃 고객 1인이 되어 구매 저항 3개를 스스로 찾아 고친 최종본만 출력" 루프가 챔피언(결합형)을 격파. 자기검증의 조준경을 대상 맥락 빈칸에 연결한 것이 핵심. 원칙 승격 후보 (재현 시).
2. **약점 정면 인정 화법** — a의 승부처 "두 배 값인 건 맞습니다" + 근거 반박. R7 관찰 메모 "사실 대조 화법(반박 아닌 기록 서술)"과 동계열 — **"불리한 사실은 숨기지 말고 인정 후 근거로"** 재현 2회째, 원칙 승격 검토.
3. **판매 실적을 받는 빈칸 부재 = 구조적 누락** (c의 재구매율 누락) — R6(회사 맥락)·R7(고객 상황)에 이은 3번째 "빈칸 없으면 결과물에 없다" 사례. 대상 맥락 빈칸 원칙의 형제 규칙: "설득 재료(실적·증거)는 전용 빈칸이 있어야 결과물에 실린다".
4. **증거 매핑 표는 부속물로서 최고 평가** — 독립 방향으로는 3위였으나 "바꿔 쓴 위험 표현" 문서화는 승자에 흡수할 가치 (R7 후속 질문형의 되묻기와 같은 운명 — 방향은 지고 부속물은 남는다).
5. **전통 음용 프레이밍 경계 리스크** — 효능어 없이도 "예로부터 즐겨 마시던 + 환절기 맥락" 조합은 잔여 리스크. 식품류 템플릿의 네거티브 조건 후보.
