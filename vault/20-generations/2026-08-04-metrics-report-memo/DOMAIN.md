# DOMAIN — 지표 리포트 해석 메모 (R25)

> named query 실행: [[prompt-principles]] · ledger · MEMORY 근거 답변. 방향 풀 설계 직전 산출.

## 1. 본질 리스크

**가짜 정밀함(fake precision)과 인과관계 오독**이 1순위 실패 원인이다. 지표 리포트 해석은 숫자를 받아 "왜 이렇게 됐는가"를 말하는 작업인데, 이 도메인은 두 겹의 함정을 갖는다:
- **노이즈를 시그널로 오독** — 표본이 작거나 기간이 짧은 변동을 의미 있는 추세로 서술 (R15의 "감의 출처는 감으로 남긴다" v1.14가 겨냥한 것과 같은 축이지만, 여기서는 raw 데이터 자체가 애매한 수치일 때 재현된다).
- **상관을 인과로 서술** — "A 지표가 오르고 B 지표도 올랐으니 A가 B의 원인"이라는 서술을 raw가 뒷받침하지 않는데도 확정형으로 씀. R9·R24가 반복 확인한 "raw에 없는 구체적 세부(등가·확정 관계)를 만들어내지 않는다" 원칙(v1.9, v1.22)이 이 도메인에서 가장 크게 시험받는다 — 지표 해석은 본질적으로 "왜"를 요구하는 작업이라 이 유혹이 다른 도메인보다 강하다.

## 2. 본질 루프

**측정이 본질인 도메인이다.** 이 타깃은 backlog가 명시하듯 마케팅 실험 기획(R12, 성과 판정 카드)의 **뒷단** — 실험을 돌린 뒤 나온 숫자를 해석해 다음 행동(계속/중단/피벗)을 정하는 단계다. R12·R15·R20 세 라운드 모두 "측정 본질 도메인에서는 결합형 표준보다 실험 문법(가설-지표-판정) 방향이 우세"를 확인했다 — 이 타깃은 그 패턴의 네 번째 후보다. 다만 이전 세 라운드는 "측정을 설계"하는 입장(무엇을 잴지 정하기)이었고, 이번은 "이미 나온 숫자를 해석"하는 입장이라는 차이가 있다 — 시그널/노이즈 구분과 다음 판단이 핵심이지, 지표 설계 자체는 아니다.

## 3. 결과물의 소비 방식

의사결정자(PM·마케터·팀 리드)가 대시보드에서 숫자를 뽑아본 뒤, **다음 액션을 정하기 위해** 짧게 훑는 메모다. 회의 자료처럼 정독되기보다, work-report(R5)·process-judgment(R11)류에 가깝게 **첫 문단만 읽고 판단**하는 소비 패턴일 가능성이 높다 — "그래서 계속할까 말까"가 최상단에 없으면 지표 나열로 읽힌다.

## 4. 유사 라운드 전례

- **R11 process-judgment** — 판단 문서. 승부처는 "하지 말 것" + 가장 싼 첫 실험 + 판정 기준의 착지 완결성(행동 착지, v1.11). 이 타깃도 "해석 후 다음 행동"을 요구하므로 같은 구조가 유효할 가능성이 높다.
- **R12 marketing-email / R15 insta-content / R20 sns-ad-copy** — 측정 본질 도메인 3연전. 실험 문법(가설-실행/관찰-지표-판정) 방향이 결합형을 이긴 패턴. 이번 타깃은 "실행" 대신 "이미 나온 숫자"가 입력이라는 점이 다르다.
- **interview-insights(analysis 유일 기존 라이브러리)** — 근거 원문 인용 요구가 환각 억제의 핵심 장치. 지표 해석도 "이 수치가 어디서 나왔나"를 원문(raw 숫자)과 대조시켜야 창작을 막는다.

## 5. 방향 풀 추천

결합형 표준(a)을 기본 포함하고, 본질 리스크·루프를 정면으로 겨냥한 방향을 최소 1개 포함한다.

- **a — 결합형 표준**: 4요소 + 근거 원문 인용 + raw 창작 금지 + 행동 착지(하지 말 것 + 판정 기준). 범용 기본선.
- **b — 시그널/노이즈 판별형 (도메인 본질 정면 겨냥)**: 지표별로 "이게 진짜 이상인가, 노이즈인가"를 먼저 판정하게 요구사항에 내장(기준선·표본 크기·기간 대비). 인과 주장에는 반드시 확신도 표시("확정" / "추정" / "상관관계만 확인, 원인 미확정")를 달게 강제 — R15의 "감의 출처는 감으로 남긴다"를 정량 지표 도메인으로 확장하는 시도.
- **c — 판단 착지 우선형**: 문서 최상단에 "그래서 어떻게 할까"(계속/중단/조정 중 하나 + 한 줄 이유)를 R5 결정요청상단고정처럼 배치하고, 그 아래에서 지표별 근거를 전개. R11의 행동 착지(하지 말 것 + 가장 싼 다음 확인 + 판정 기준)를 강하게 내장.

domain-fit 예측: 본질 리스크·루프를 정면 겨냥한 **b가 우세**할 것으로 예측한다 (누적 실적 참고용, 4승 7패로 신뢰도는 낮음 — R21 이후 계속 빗나가는 추세를 감안해 강한 확신은 아님).
