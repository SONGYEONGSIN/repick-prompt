# SCENARIO — R25 지표 리포트 해석 메모

> 3후보(a/b/c) 공통 테스트 시나리오. 아래 사실이 values.json에 채워지는 전부다 — 심사자는 이 문서만 보고 결과물의 창작 여부를 대조하므로, 여기 없는 숫자·사건이 결과물에 등장하면 창작이고, 여기 있는 숫자·사건이 정당하게 등장하면 창작이 아니다.

## 인물·서비스

- 서비스: "노트메이트" — AI 요약 기능이 있는 노트 앱 (개인/팀용 SaaS, 14일 무료체험 후 유료 전환)
- 화자: 그로스팀에서 온보딩·전환 퍼널을 담당하는 3년 차 마케터 박세은. 이번에 다룰 배너 변경을 본인이 직접 제안하고 실행했다.
- 이 메모를 받는 사람: 그로스팀장 김하늘 — 데이터 근거 없는 롤백·확대를 둘 다 싫어하며 표본 크기부터 물어보는 스타일. 8월 스프린트 계획 회의(8/8) 전까지 계속/중단/조정 여부를 정해야 한다.

## 무엇에 대한 지표인가

- 지표: 무료체험 → 유료 전환율 (14일 체험 종료 시점 기준, 체험 시작 코호트별 집계)
- 원래 목표: 이번 분기 목표 전환율 9% 이상 (직전 분기 평균 8.45%에서 개선)
- 이번 실험/변경: 7월 21일, 결제 유도 배너를 "설정 페이지 안"에서 "대시보드 상단 고정"으로 옮김 — 더 잘 보이게 해서 전환율을 올리려는 목적

## 실제 원본 수치 (기간별)

- 변경 전 4주 (6/23~7/20) 주간 전환율: 8.5% → 8.2% → 8.7% → 8.4% (평균 8.45%, 비교적 안정)
- 변경 전 4주 주간 체험 시작 인원: 350명 → 365명 → 340명 → 355명대
- 변경 후 1주차 (7/21~7/27): 체험 시작 310명, 전환율 7.9%
- 변경 후 2주차 (7/28~8/3): 체험 시작 265명, 전환율 6.1%
- 참고: 사이트 전체 방문자 수도 지난달 대비 약 15% 감소 추세 (7월 넷째 주부터)
- 작년 동기(2025년 7월 말~8월 초) 전환율은 8.5%에서 7.8%로 소폭 하락한 전례가 있음 (여름휴가철 계절적 하락 패턴으로 팀 내 추정)

## 같은 기간에 있었던 다른 변화·이벤트

- 7/21: 배너 위치 변경 배포 (이번에 판단할 그 변경)
- 7/24 새벽 2시~5시: 결제 시스템 장애 발생 (야간이라 실사용자 영향은 적었을 것으로 추정되나 정확한 영향 규모는 파악되지 않음)
- 7/25부터: 여름휴가 시즌 시작, 회사 전체 트래픽이 전반적으로 줄어드는 추세 (위 방문자 15% 감소와 동일 사건)
- 7/29: 경쟁 서비스가 무료체험 기간을 14일에서 30일로 연장했다는 소식을 팀이 전해 들음 (팀 내부에서 관찰·전언 수준, 확실한 근거 자료는 없음)

## 팀 내 기존 의심(가설)

- 일부는 "배너가 대시보드 상단에 있으면 오히려 부담스러워서 이탈이 늘었을 것"이라고 의심
- 다른 일부는 "여름휴가 시즌 트래픽 질 저하 때문"이라고 봄
- 팀 전체가 동의하는 결론은 아직 없음

## 이전에 비슷하게 시도했던 것

- 5월에 결제 유도 문구만 바꿔본 적 있음 — 배너 클릭률은 올랐지만 실제 전환율에는 유의미한 차이가 없었음

## 다음 확인에 쓸 수 있는 자원 / 제약

- 개발 리소스 배정 없음 — 이번 주 안에 코드 변경 없이 확인 가능한 것만 가능
- 새로운 A/B 테스트를 처음부터 설계해 돌릴 시간은 없음 (다음 스프린트 전까지)
- 데이터 분석에 쓸 수 있는 본인 시간은 주 2시간 정도

## 판단 시한

- 8월 8일까지 — 8월 스프린트 계획 회의 전에 계속/중단/조정 여부를 정해야 함
