# DOMAIN — 요구사항 출처 역추적 표 (R38)

Named query 답변 (domain-fit.md, GENERATE 직전 실행).

## 1. 본질 리스크

이 도메인은 지금까지 소비한 "감사 가능성" 축(R29~R37)과 방향이 하나 다르다 — 지금까지는 전부 **입력 원문의 사실을 결과물에 정확히 옮기는가**(회의 발언·계약 조항·개정 전후 등)를 감사했다. 이 타깃은 반대다: **결과물(이미 완성된 산출물)의 항목 하나하나를, 그것을 뒷받침한다고 주장하는 출처(발언·문서)와 실제로 대조**하는 것이다.

본질 리스크는 **역추적을 수행하는 AI 자신이 근거를 창작하는 것**이다 — "이 항목의 출처가 안 보인다"고 정직하게 답하는 대신, 그럴듯한 근거처럼 보이는 문장을 원문에서 찾아 억지로 짝짓거나(견강부회), 원문에 없는 인용을 만들어 붙이는(가짜 인용) 실패가 1순위다. 이는 raw 창작 금지(v1.9·v1.25)가 지금까지 막아온 "결과물 작성 단계의 창작"과 다른 층위 — **감사 단계 자체의 창작**이다. 이 도메인이 성립하려면 "출처 없음"을 결과로 인정할 수 있어야 하는데, 그 인정 자체가 이 작업을 수행하는 AI에게는 실패로 느껴질 유인이 있다(모든 항목에 짝을 채우고 싶은 압력).

## 2. 본질 루프

만들면 끝인 1회성 감사 산출물이다. 소스 산출물(원본 문서)이 개정될 때 재실행될 수 있으나, 발송·측정 루프는 없다 — 결정 요청 상단 고정(v1.4/v1.23)의 "작성자≠결정권자 감사형" 조건이 적용되는 감사 가능성 축의 다른 항목들과 같은 구조.

## 3. 결과물의 소비 방식

결정권자·검수자가 결과물 항목 하나를 짚고 "이게 어디서 나온 거야?"라고 물었을 때 즉시 짝을 확인하는 **대조 열람형** — 정독이 아니라 항목별 스팟체크. 표 형태로 항목↔출처가 1:1로 나열돼야 스캔이 빠르다.

## 4. 유사 라운드 전례

- [[2026-08-10-requirement-compliance-check/DECISION|R31]] (규정·요건 대조표) — 방향은 반대(고정 목록→원문)지만 "역방향 스캔"(v1.29, 목록 밖 항목도 훑기) 메커니즘이 구조적으로 가장 가깝다. 이번 타깃은 처음부터 "산출물 항목 → 근거"가 유일한 방향이라는 점에서 v1.29가 만든 여벌 스캔이 이번엔 **주 임무**가 된다.
- [[2026-08-09-data-verification-memo/DECISION|R30]] (데이터 검산 메모) — "재확인형 자기검증"(v1.28, 원문을 다시 훑어 빠뜨린 사실 확인)이 이 타깃의 핵심 동작과 거의 동일 — 다만 R30은 수치 대조, 이번은 임의 텍스트 항목 대조.
- [[2026-08-18-vendor-comparison-scorecard/DECISION|R37]] (벤더 비교 평가표) — "근거가 아예 없는 조합은 확인 필요로 고정"이 이 타깃의 "출처 없음" 판정과 같은 계열.

## 5. 방향 풀 추천

- **a. 결합형 표준** — 4요소 + 항목마다 원문 직접 인용 요구 + 확인 상태 라벨(v1.27) 3분류(출처 확인/부분 근거/출처 없음) 재사용. 검증된 장치의 조합.
- **b. 무출처 우선 노출형 (본질 리스크 정면 겨냥)** — "직접 인용 아니면 출처 없음"을 엄격한 이분법 규칙으로 요구사항에 못박는다(중간 등급을 허용하지 않아 견강부회·가짜 인용 여지를 원천 차단). "출처 없음" 항목은 표 하단이 아니라 **별도 상단 요약 블록**으로 먼저 모아 결정권자가 가장 먼저 보게 한다.
- **c. 근거 강도 등급형** — 직접 인용(원문 문장 그대로) / 간접 추론(원문 사실에서 논리적으로 도출되나 문장 자체는 없음) / 무근거 3단계로 등급을 매긴다. b가 이분법으로 리스크를 봉쇄한다면 c는 회색지대(간접 추론)를 정직하게 드러내는 반대 가설 — 다만 "간접 추론"이라는 중간 등급 자체가 견강부회의 도피처가 될 위험이 있다(완전 신설·삭제 등급 고정 원칙 v1.31·v1.32이 경고하는 "중립 카테고리로 무게 축소"와 같은 함정).

**예측**: b가 이길 것으로 본다. 이 도메인의 본질 리스크(감사 단계의 창작)를 정면 봉쇄하는 유일한 방향이고, 최근 라운드(R31~R37) 패턴상 도메인 본질을 정면 겨냥한 이분법·고정 규칙형이 강했다.
