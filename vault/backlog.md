# 진화 백로그 — 타깃 대기열

자동 라운드(`/prompt-evolve --auto`)가 소비하는 타깃 작업 대기열 + 후보 설계 방향 가설.

## 소비 규칙

0. **선행 가드 (라운드 시작 전 필수)**: 열린 `evolve/*` PR이 있으면 새 라운드를 시작하지 않는다 — 미머지 PR은 백로그를 갱신하지 못해 다음 라운드가 같은 타깃을 중복 집는다 (R14가 R11 미머지분과 같은 타깃 반복한 사고). 아래 질의 결과가 `0`이어야 진행하고, 아니면 "직전 라운드 PR 미처리"만 보고하고 종료.

   ```
   gh pr list --state open --json headRefName --jq '[.[] | select(.headRefName | startswith("evolve/"))] | length'
   ```

   **`gh pr list --head 'evolve/'` 를 쓰지 마라** — `--head`는 접두사가 아니라 정확한 브랜치명을 받는다. `evolve/*` PR 8건이 실재하는 상태에서 `0`을 반환하는 것을 실측 확인했다(2026-07-31). 이 가드는 도입 이후 줄곧 무력했다.
1. 위에서부터 첫 번째 미완료(`- [ ]`) 항목을 꺼내 `$TARGET`으로 사용한다.
2. 라운드 완료 시 해당 항목을 `- [x]`로 바꾸고 뒤에 ` → <run-slug> (R<n>)`을 덧붙인다.
3. 새 타깃은 맨 아래에 추가한다 (우선순위가 높으면 위로).
4. 대기열이 비면 라운드를 돌지 않고 "백로그 소진"만 보고한다 — 임의 타깃 생성 금지.

## 방향 가설 (GENERATE 소비)

라운드의 후보 $N개 중 1개의 설계 방향으로 배정해 검증하는 가설 대기열 (라운드당 1개). 검증 완료 시 `- [x]`로 바꾸고 ` → <run-slug> (R<n>, 순위/채택 여부)`를 덧붙인다. 외부 지식은 여기서 실측을 거쳐야만 DNA에 오를 수 있다 (LEARN 게이트의 실측 근거 요건).

- [ ] **재량 확장은 출력 형식까지 완전히 통제해도 재현되는가** (R34 통제 한계의 재검) — R34는 등급 고정형(a)이 재량형(b)을 3/3 라운드로 이겼고 v1.32로 반영됐지만, **사람 리뷰에서 통제 결함이 드러났다**: 처치 변수(등급 고정 규칙) 외에 출력 형식 `다음 행동`의 등급 분기 목록이 b에만 `재실험 설계`를 포함했고, 감점된 두 관찰 중 하나(요청받지 않은 재실험 제안)가 바로 그 어휘였다 — 재량이 아니라 템플릿이 흘린 것으로 보는 편이 자연스러워 귀속 불가로 기록했다 ([[2026-08-13-ab-test-verdict/DECISION|R34 DECISION]] 통제 한계 절). 남은 근거는 raw 밖 인과 해석 관찰 하나뿐이다.
  - **검증 설계**: R34와 같은 통제쌍을 다시 세우되 **출력 형식의 등급 분기 목록·절 구성·요구사항 개수까지 a·b를 문자 그대로 동일하게** 맞춘다. 오직 "등급을 규칙으로 고정하는가 / 판정자 재량에 맡기는가" 한 문장만 다르게 한다. 등급 카테고리 이름과 각 등급의 후속 조치 문구도 양쪽에 같은 목록으로 넣는다(한쪽에만 있는 어휘가 없어야 한다).
  - **재현 도메인**: 대상이 여럿이라 재량이 개입할 표면이 넓은 **벤더·업체 비교 평가표**가 적합하다. 기준마다 일관되게 등급을 매겨야 하고, "종합적으로 고려" 여지를 주면 특정 후보에 유리하게 서술이 기우는지 관찰할 수 있다.
  - **결과물에 흔적이 남는가**: 남는다. 등급 라벨과 판정 근거 문장이 산출물에 그대로 보이고, raw 밖 해석·용도 이탈 제안도 문장 단위로 대조 가능하다.
  - **판정**: 어휘 비대칭을 없앤 상태에서도 재량형에서만 raw 밖 해석·역할 이탈이 나오면 **채택** → v1.32를 재현 확인으로 승격. 두 후보가 갈리지 않으면 **기각** → R34의 차이는 통제 결함이 만든 것이었고 v1.32는 근거가 관찰 1건뿐이므로 "재현 실패"로 낮춰 기록한다.

- [x] **완전 신설·완전 삭제 등급 고정은 다른 대조 도메인에서도 재현되는가** (v1.31 첫 검증의 재현) — R33에서 b(영향도 등급 겨냥형)가 *"완전히 사라진 조항은 등급을 실질적 변경으로 고정하라"*를 요구사항에 못박아, 확정 지급일이 삭제되고 불확정 문구("별도 공지")로 대체된 함정을 3라운드 전부 방어했다. 반대로 a는 같은 항목을 "수정"으로 완화 분류하고 요약에 "삭제 0건"이라 자기모순까지 냈다(환각축 14/30 최하위, b는 28/30) ([[2026-08-12-revision-comparison-memo/DECISION|R33 DECISION]]). **다만 R33은 등급 고정 장치 유무 외에도 후보 설계가 여럿 달랐다** — 첫 검증이라 순효과가 격리되지 않았다.
