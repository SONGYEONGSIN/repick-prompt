# 진화 백로그 — 타깃 대기열

자동 라운드(`/prompt-evolve --auto`)가 소비하는 타깃 작업 대기열 + 후보 설계 방향 가설.

## 소비 규칙

0. **선행 가드 (라운드 시작 전 필수)**: 열린 `evolve/*` PR이 있으면 새 라운드를 시작하지 않는다 — 미머지 PR은 백로그를 갱신하지 못해 다음 라운드가 같은 타깃을 중복 집는다 (R14가 R11 미머지분과 같은 타깃 반복한 사고). `gh pr list --state open --head 'evolve/'`가 비어야 진행. 비어 있지 않으면 "직전 라운드 PR 미처리"만 보고하고 종료.
1. 위에서부터 첫 번째 미완료(`- [ ]`) 항목을 꺼내 `$TARGET`으로 사용한다.
2. 라운드 완료 시 해당 항목을 `- [x]`로 바꾸고 뒤에 ` → <run-slug> (R<n>)`을 덧붙인다.
3. 새 타깃은 맨 아래에 추가한다 (우선순위가 높으면 위로).
4. 대기열이 비면 라운드를 돌지 않고 "백로그 소진"만 보고한다 — 임의 타깃 생성 금지.
