# 진화 백로그 — 타깃 대기열

자동 라운드(`/prompt-evolve --auto`)가 소비하는 타깃 작업 대기열.

## 소비 규칙

1. 위에서부터 첫 번째 미완료(`- [ ]`) 항목을 꺼내 `$TARGET`으로 사용한다.
2. 라운드 완료 시 해당 항목을 `- [x]`로 바꾸고 뒤에 ` → <run-slug> (R<n>)`을 덧붙인다.
3. 새 타깃은 맨 아래에 추가한다 (우선순위가 높으면 위로).
4. 대기열이 비면 라운드를 돌지 않고 "백로그 소진"만 보고한다 — 임의 타깃 생성 금지.

## 대기열

- [ ] 이력서 작성
- [ ] 면접 예상 질문과 답변 준비
- [ ] 비즈니스 이메일 회신 작성
- [ ] 발표 자료 개요와 스크립트 작성
- [ ] 뉴스레터 작성
- [ ] 사업 제안서 작성
- [ ] SNS 광고 카피 작성
- [ ] 유저 페르소나 정의
- [ ] 서비스 FAQ 작성
- [ ] 보도자료 작성
