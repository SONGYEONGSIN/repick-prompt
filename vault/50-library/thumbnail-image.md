# 썸네일 이미지 생성

씨앗 — 사용자 제공 검증 프롬프트

## 필드

```json
[
  {
    "key": "topic",
    "label": "주제",
    "type": "text",
    "placeholder": "예: AI 자동화로 주 4일 일하기"
  },
  {
    "key": "emotion",
    "label": "핵심 감정",
    "type": "select",
    "options": [
      "긴장감",
      "호기심",
      "신뢰감",
      "충격"
    ],
    "help": "썸네일이 시청자에게 일으켜야 할 감정 하나."
  },
  {
    "key": "style",
    "label": "스타일",
    "type": "select",
    "options": [
      "실사",
      "3D",
      "일러스트",
      "시네마틱"
    ]
  },
  {
    "key": "subject",
    "label": "주 피사체",
    "type": "select",
    "options": [
      "인물",
      "제품",
      "화면 UI",
      "추상 오브젝트"
    ]
  },
  {
    "key": "background",
    "label": "배경 요소",
    "type": "text",

    "label": "피하고 싶은 요소",

  }
```

## 본문

```
당신은 클릭률 높은 썸네일을 설계해온 이미지 프롬프트 전문가입니다.

아래 조건을 모두 반영한 썸네일 이미지 생성 프롬프트를 작성해주세요.

주제: {{topic}}
핵심 감정: {{emotion}}
스타일: {{style}}
주 피사체: {{subject}}
배경 요소: {{background}}
주 색상: {{color}}
비율: {{ratio}}
텍스트 포함 여부: {{text_included}}
피하고 싶은 요소: {{avoid}}

요구사항:
- 한눈에 주제가 보이도록 구도를 잡아주세요. 썸네일은 피드에서 작게, 스치듯 노출되므로 주제가 즉시 읽히지 않으면 클릭으로 이어지지 않기 때문입니다.
- 배경은 복잡하게 만들지 말고, 주 피사체가 잘 드러나게 해주세요. 작은 크기로 줄면 복잡한 배경은 뭉개져 시선을 흩뜨리고, 피사체가 배경에 묻히면 무슨 썸네일인지 알 수 없기 때문입니다.
- 클릭을 유도할 만한 대비와 긴장감을 살려주세요. 비슷한 썸네일이 늘어선 피드에서 강한 대비가 스크롤을 멈추게 하는 거의 유일한 무기이기 때문입니다.
- 지나치게 난잡한 소품, 작은 디테일 남발, 의미 없는 텍스트는 피해주세요. 이미지 AI가 흔히 만드는 왜곡·잡동사니·깨진 글자가 아마추어 느낌을 줘 클릭을 떨어뜨리기 때문입니다.
- 결과는 선명하고 상업용 썸네일 느낌이 나야 합니다. 흐릿하거나 조악한 이미지는 콘텐츠 품질까지 의심하게 만들어 클릭을 막기 때문입니다.

최종 프롬프트만 출력해주세요.
```

## 해부

### 역할

> 클릭률 높은 썸네일을 설계해온 이미지 프롬프트 전문가

역할 없이 조건만 주면 AI가 이미지를 직접 그리려 들거나 조건을 나열만 합니다. '프롬프트 전문가'로 고정해야 도구에 붙여넣을 완성형 프롬프트가 나옵니다.

### 조건 명세

> 감정 / 스타일 / 피사체 / 색상 / 비율

이미지 생성은 형용사보다 명세가 중요합니다. '멋지게'는 통제 불가능하지만 '시네마틱 + 딥블루 + 16:9'는 재현 가능합니다.

### 구도 지시

> 한눈에 주제가 보이도록 / 주 피사체가 잘 드러나게

썸네일은 작은 크기로 노출됩니다. 축소돼도 읽히는 구도를 요구사항으로 박아둡니다.

### 네거티브 조건

> 피하고 싶은 요소 / 난잡한 소품·의미 없는 텍스트 금지

이미지 AI의 흔한 실패(왜곡, 잡동사니)를 미리 차단합니다. 원치 않는 것을 말하는 것도 프롬프트의 절반입니다.

### 출력 제한

> 최종 프롬프트만 출력해주세요.

설명 없이 결과만 받아 이미지 생성 도구에 바로 붙여넣을 수 있습니다.

## 팁

- 이 프롬프트의 결과물을 Midjourney·DALL-E 등 이미지 도구에 그대로 붙여넣으세요. 도구용 영문 프롬프트가 필요하면 "영어로 번역해서"를 붙이세요.
- 같은 조건으로 감정만 바꿔 2~3장 만들어 A/B 테스트하면 클릭률 차이를 확인할 수 있습니다.
