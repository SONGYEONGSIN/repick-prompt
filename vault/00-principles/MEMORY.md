> 라운드별 핵심 학습 1줄씩. 상세는 각 라운드의 DECISION.md, 정제본은 [[prompt-principles]].

- (seed) 2026-07-12 — 사용자 제공 검증 프롬프트 10개에서 4요소 DNA 역추출 (v1)
- R1 2026-07-12 cold-email — b(가이드 최대화) 승. 승부처는 문장력이 아니라 **발송 세트 완결성**(서명·팔로업·체크리스트). 최소 빈칸(a)은 서명 없는 메일로 3위 — "적은 빈칸 ≠ 바로 사용". optional 토큰 요구사항 줄 재사용 금지(c).
- R2 2026-07-12 prototype — c(프레임워크 내장) 승 20/20. 최소 빈칸(a)은 실데이터 받을 칸이 없어 가짜 수업 20개를 창작, 12점 3위 — **결과물에 담길 실데이터는 필수 빈칸으로**.
- R3 2026-07-12 webpage — c(프레임워크 내장) 승 20/20·환각 0. **검증된 방법론은 요구사항 문장으로 내장** — 구조를 몰라도 전환형 페이지가 나온다. b의 경미 감점: 주어진 후기에 '재구매' 속성 각색 — 근거는 원문 그대로.
- R4 2026-07-12 reels-script — c(프레임워크 내장) 승 20/20, **3연속**. 숏폼 문법(무음 자막·2~3초 전환·어절 분량) 내장. a의 감점: **실행 여건(혼자·장비)을 빈칸 없이 일반 가정으로 처리** → 혼자 촬영 불가 장면.
- R5 2026-07-12 work-report — c(프레임워크 내장) 승 19/20, **4연속**·휴먼 게이트 승인. 3후보 전원 환각 0(구체성·억제 만점)으로 승부는 구조로 — **결정 요청을 기한과 함께 문서 최상단에**(a는 요청이 맨 아래라 동점 패배). b의 DNA 위반: 보고 기간 빈칸 부재 → 제목·헤더용 메타 실데이터도 빈칸 필요. 공정성 주석: 시나리오는 후보 생성 완료 후 작성할 것.
- R6 2026-07-13 cover-letter — c(프레임워크 내장) 승 20/20, **5연속**·휴먼 게이트 승인. 방향 풀 교체('최소 빈칸'→'후속 질문형', 'b'→구조+가이드 결합) 후 라운드 바닥 점수 12→19로 상승 — 방향 풀 진화 유효. 승부처는 **검증형 부속물**(제출 전 셀프 체크·대안 첫 문장 후보·면접 예상 질문 세트, 마진 0.5 타이브레이커). 관찰 메모: ① 대상 밀착 문서(자소서·제안서)는 **대상의 현재 맥락(전략·제품) 빈칸**이 회사 특정성을 가른다(b 유일 감점 원인, a 강점 원인 — 재현 시 원칙 승격) ② 후속 질문형의 되묻기는 부속물로는 강점이나 본문의 완성도 선언을 흔들면 감점(스스로 '초안' 규정 + 내부 메모 노출).
- R7 2026-07-13 cs-reply — **b(결합형) 승 20/20 — 프레임워크 내장 5연승 종료.** 구조 내장 + 코치형 help + **대상 맥락 빈칸**(situation: 첫 구매·선물·화남 정도)의 결합이 승인. 승부처: 불가능 요구(내일 도착)의 **명시 봉쇄**("지키지 못할 약속은 하지 않겠다") + "한 겹" 주장을 반박 아닌 우리 기록 서술로 + 리뷰 협박 비거래적 대응. 대상 맥락 빈칸은 R6 관찰 재현으로 원칙 승격(v1.6). 후속 질문형은 2연속 열세(17점)로 독립 방향 은퇴 — 되묻기는 부속물로 흡수. 관찰 메모: 사실 대조 화법(반박 아닌 기록 서술) 재현 시 승격 / 재발 방지 약속은 원인 미확정과 충돌 주의.
