# Prompt Principles — RE:PROMPT 템플릿 DNA (v1)

> 현재의 "프롬프트 DNA". 모든 템플릿은 이 원칙 위에서 작성·개정된다.
> repick-design의 design-principles.md와 같은 역할 — LEARN 단계가 surgical하게 갱신한다.

## 4요소 구조 (모든 템플릿의 뼈대)

| # | 요소 | 역할 | 예 |
|---|------|------|----|
| 1 | **역할** | AI에게 직업·관점을 고정 | "당신은 한국어 유튜브 교육형 채널의 작가입니다" |
| 2 | **맥락** | 결과의 방향을 결정하는 변수 | 대상/목표/톤/길이/제약 |
| 3 | **요구사항** | 검증 가능한 품질 기준 | "첫 15초 훅을 강하게" (X: "잘 써줘") |
| 4 | **출력 형식** | 받아서 바로 쓰는 구조 강제 | "제목 후보 3개 + 장면별 스크립트" |

## 필드 설계 원칙

- **빈칸은 6±3개** — 적으면 통제력이 없고, 많으면 초보자가 이탈한다.
- select 필드는 **칩 + 자유 입력 병행** — 선택지는 가이드일 뿐 구속이 아니다.
- 선택(optional) 필드가 비면 **그 줄을 제거** — 반쪽짜리 줄("- 참석자: ")이 복사되지 않게.
- 모든 필드에 **실전 예시 placeholder** — 초보자는 형식이 아니라 예시에서 배운다.
- **사용 맥락 부속물을 필드로** — 이메일류는 발신자(서명) 필드 필수. 부속물이 빠지면 결과물이 CTA에서 그냥 끊긴다 (R1: 최소 빈칸 후보가 서명 없는 메일로 3위).
- **optional 필드의 토큰을 요구사항 줄에 재사용 금지** — 값이 비면 지침 줄 자체가 소실된다 (R1-c 구조 리스크).
- **결과물에 담길 실데이터는 필수 빈칸으로** — 화면·페이지에 실제 표시될 콘텐츠(목록·수치·후기)를 묻지 않으면 AI가 그 자리를 창작으로 메꿔 "내 것이 아닌" 결과가 된다 (R2: 최소 빈칸 후보가 가짜 수업 20개를 창작해 3위).
- **실행 여건(장비·인력·장소 제약)은 기본값에 맡기지 않는다** — 빈칸으로 받거나 요구사항 문장으로 고정. 여건이 비면 AI가 실현 불가한 지시를 낸다 (R4: 여건 미확보 후보가 '혼자 촬영 불가 장면'으로 3위). 여건상 **불가능한 요구에는 얼버무리지 말고 불가능을 명시하고 대안으로** — "지키지 못할 약속은 하지 않겠다"를 결과물이 스스로 말하게 하는 것이 승부처 (R7: 불가능 약속 명시 봉쇄가 만점 1위 결정 요인).
- **대상 맥락 빈칸**: 결과물이 특정 대상 1곳을 겨냥하는 문서(자소서·제안서·CS 답변)는 대상의 현재 맥락(상태·전략·관계·감정)을 받는 전용 빈칸이 특정성을 가른다 — 없으면 "어디에나 보낼 법한" 결과가 된다 (R6: 회사 맥락 칸 없던 후보가 유일 감점 / R7: `situation` 빈칸이 첫 구매·선물·화남 정도를 받아내 만점 승리 — 재현 승격).

## 품질 장치 (템플릿에 반복 배치)

- **근거 요구**: "원문 표현을 짧게 인용해주세요" — 환각 억제
- **추정 표시**: "확실하지 않은 내용은 추정이라고 표시해주세요" — 리서치류 필수
- **행동 착지**: 출력 마지막은 "다음 주 실험 3개"류 — 읽고 끝나지 않게
- **발송 세트 착지**: 본문만이 아니라 실사용에 필요한 세트(서명·팔로업·발송 전 체크리스트)까지 출력 형식으로 요구 — "바로 사용 가능성"을 가르는 결정 요인 (R1 승부처). 제출류 문서는 세트에 **핵심 문장의 대안 후보(발산→수렴) + 제출 전 셀프 체크 + 다음 관문 대비물**(자소서→면접 예상 질문)까지 — 부속물이 "오늘 바로 제출·검증"을 지원하는지가 동급 후보의 타이브레이커 (R6 승부처, 마진 0.5점)
- **발산→수렴**: "7개 제안 → 1개 상세" 깔때기 구조
- **네거티브 조건**: 피하고 싶은 것 명시 — 이미지·글쓰기류 필수
- **프레임워크 내장**: 도메인의 검증된 방법론(랜딩 전환 구조, 프로토타입 스코프 컷, 숏폼 문법, 보고서 BLUF 등)은 빈칸으로 묻지 말고 요구사항 문장으로 내장 — 초보자 입력 품질과 무관하게 구조 품질이 보장된다 (R2~R6 5연속 승자 패턴, 제작·글쓰기·문서·커리어 전반). **R7부터 내장 단독은 차별화가 아닌 기본기** — 승자는 내장 + 코치형 help + 대상 맥락 빈칸의 결합형 (R7: 결합형이 내장 단독을 20 vs 19.5로 첫 추월)
- **결정 요청 상단 고정**: 수신자의 결정·행동이 목적인 문서(보고서·요청서류)는 요청 항목을 문서 끝이 아닌 **최상단에 기한과 함께** 배치 — "첫 줄만 읽는 상사"가 즉시 움직일 수 있어야 한다. 요청을 맨 아래 두거나 기한을 비우면 액션 유도력이 떨어진다 (R5 동점 타이브레이커 승부처)

## 금지 (anti-slop)

- 형용사만 있는 요구사항 ("멋지게", "전문적으로" 단독 사용)
- 검증 불가능한 출력 형식 (형식 미지정)
- 하나의 템플릿에 두 가지 이상의 직업 목적 혼합
- 초보자가 채울 수 없는 전문용어 라벨
- 결과물 본문 안에 구조 마커(①②③) 표기 — 학습용 해설은 별도 섹션에만 (R1-c: 발송 전 수작업 제거 유발)

- v1.2 (2026-07-12, R2·R3) — 실데이터 필수 빈칸 / 프레임워크 내장 추가
