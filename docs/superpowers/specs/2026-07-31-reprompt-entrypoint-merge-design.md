# S2 — 진입점 병합 + 배포 (설계)

> 2026-07-31 · 스코프 S2 (전체 3단계 중 2단계) · 선행 [[2026-07-25-vault-as-library-source-design|S1]] 완료(PR #8·#9)

## 배경 — S1이 연 것과 남긴 것

S1이 라이브러리 원본을 `vault/50-library/*.md` 마크다운으로 옮겼다. 그 결과 **플러그인에 라이브러리를 실을 수 있게 됐다** — TS 배열 안에 있는 한 불가능했던 일이다. S2는 그 가능성을 실제 배포로 바꾼다.

S1 설계가 S2에 할당한 것은 넷이다: 단일 `/reprompt`, 플러그인에 DNA+라이브러리 동봉, DNA 사본 해소, 클라우드 루틴 호출형 갱신.

## 목표 정정 — "DNA 사본 해소"는 달성 불가능하다

S1이 확정한 제약은 *"플러그인은 DNA와 승격 라이브러리를 **데이터로 실어 나른다**. 공장은 집에 두고 제품만 배포한다"*이다. 다른 레포에서 동작하려면 실어 날라야 하고, 실어 나른다는 것은 **사본이 존재한다**는 뜻이다. 스탠드얼론 정책을 버리지 않는 한 사본은 없앨 수 없다.

실제로 달성 가능하고 가치 있는 목표는 이것이다:

> **번들 자산을 수동 사본에서 빌드 산출물로 강등한다.**

S1이 `templates.ts` → `templates.generated.ts`에서 이미 푼 문제와 같은 모양이다. 원본은 볼트, 배포물은 생성, 가드는 바이트 일치.

## 지금 가드는 막지 못한다

`scripts/wiki-lint.mjs:72-82`의 플러그인 DNA 드리프트 검사는 `warns.push()`이고, wiki-lint는 warn이 있어도 exit 0을 낸다(2026-07-30 "0 fail, 1 warn → exit 0" 실측). 즉 **검사는 있지만 아무것도 차단하지 않는다.** 동기화는 `prompt-evolve` SKILL이 지시하는 수동 `cp` 한 줄에 의존하며, R17에서 그 한 줄을 잊어 v1.14가 배포본에 잔존했다. 같은 사고가 지금도 그대로 가능하다.

**사본 1개도 강제하지 못하는 상태에서 S2는 사본을 30개로 늘린다.** 가드 강화가 동봉의 전제 조건이지 부수 작업이 아니다.

## 확정된 결정 2건

| 결정 | 선택 | 근거 |
|---|---|---|
| 번들 형식 | **볼트 md 그대로 바이트 복사** (DNA 1 + 라이브러리 29 + `_categories.md`) | 번들 포맷이 볼트와 동일해 ① 생성이 바이트 복사로 끝나고 ② 가드가 바이트 비교로 끝나며 ③ **reprompt의 레포-내 경로와 스탠드얼론 경로가 같은 코드가 된다**. 새 포맷·파서·실패 표면이 생기지 않는다 |
| 가드 강도 | **wiki-lint FAIL 승격 + 생성 스크립트** | 수동 `cp`를 없앤다. 검사가 차단하지 않으면 없는 것과 같다 |

**감수하는 비용**: `plugin/` 44K → 약 380K(8배). 이는 `0298c5f`(Narrow-2, "플러그인 루트를 `plugin/`으로 좁힘 — 설치 bloat 제거")의 의도와 충돌한다. 필드+본문만 추린 단일 JSON으로 절반 이하로 줄이는 대안을 제시했으나, 포맷 이원화가 만드는 복잡도(별도 생성 로직·별도 가드·볼트와 다른 읽기 경로)보다 크기를 감수하는 쪽을 택했다. **Narrow-2의 결정은 이 라운드에서 의도적으로 되돌린다** — 그때는 실을 것이 없었고 지금은 있다.

## 설계

### 1. 번들 생성 — `scripts/build-plugin-bundle.mjs`

```
vault/00-principles/prompt-principles.md  →  plugin/skills/reprompt/dna/prompt-principles.md
vault/50-library/*.md (29 + _categories)  →  plugin/skills/reprompt/library/*.md
```

- 순수 바이트 복사. 변환 없음
- 대상 디렉토리를 먼저 비워 **볼트에서 삭제된 파일이 번들에 잔존하지 않게** 한다 (복사만 하면 삭제가 전파되지 않는다)
- 실행 후 요약 출력: `✓ DNA v1.18 + 라이브러리 29종 번들`
- 커밋 대상이다 — 플러그인 설치자는 이 레포를 빌드하지 않고 파일만 받는다

### 2. 가드 — wiki-lint 확장

기존 5a(DNA WARN)를 **FAIL로 승격**하고 라이브러리 번들 검사를 추가한다:

| 검사 | 조건 | 판정 |
|---|---|---|
| DNA 번들 일치 | `plugin/.../dna/prompt-principles.md` ≠ 볼트 원본 | FAIL |
| 라이브러리 번들 일치 | 파일 집합 또는 바이트가 `vault/50-library/`와 다름 | FAIL |
| 번들 잔존 파일 | 볼트에 없는 파일이 번들에 있음 | FAIL |

메시지는 원인이 아니라 **행동**을 지시한다: `node scripts/build-plugin-bundle.mjs 를 실행하라`.

### 3. 진입점 병합 — 라우터로서의 `/reprompt`

두 스킬을 한 파일로 합치지 **않는다**. S1 제약 "공장은 집에 두고 제품만 배포한다"에 따라 진화 루프는 플러그인에 실리면 안 되고, 합치면 89+84줄이 한 파일에 쌓여 배포물이 비대해진다.

대신 **진입점만 단일화한다**:

```
/reprompt [작업] [--target ...] [--evolve]
   │
   ├─ --evolve 명시  → 볼트 레포인가?
   │                    ├─ 예   → prompt-evolve 스킬로 위임 (5단계 진화 라운드)
   │                    └─ 아니오 → 거부 + 이유 안내 (공장이 없는 곳)
   │
   └─ 기본 (자동 3층)
        1층  라이브러리 히트  → 승격 템플릿을 뼈대로 쓰고 빈칸을 대화 맥락에서 충전
        2층  히트 없음        → 현행 6단계로 DNA에서 새로 깎는다
        3층  반복 신호        → "백로그 타깃으로 올릴까?" 제안  ← S3가 근거를 채운다
```

**1층과 2층의 차이**는 뼈대의 출처다. 1층은 라틴 방진 심사를 통과해 승격된 검증된 뼈대를 쓰고, 2층은 뼈대가 없어 DNA 4요소로 조립한다. 결과물 형식(`BRIEF/PROMPT/RATIONALE/OUTPUT/INSPECTION`)은 동일하다.

**히트 판정**은 규칙이 아니라 모델 판단으로 한다 — 한국어 자연어 요청과 템플릿 `title`/`description`의 대조라 문자열 매칭은 취약하다. 애매하면 임의로 정하지 말고 HUMAN GATE에서 "이 템플릿을 쓸까요, 새로 깎을까요?"를 묻는다.

**3층은 S2에서 자리만 만든다.** 반복 판정의 근거(`~/.reprompt/usage.jsonl` N회 집계)는 S3가 만들므로, S2는 훅과 인터페이스만 두고 실제 제안은 S3가 채운다. 근거 없이 제안하면 그 자체가 환각이다.

### 4. 루틴 호출형 갱신

현재 클라우드 루틴 프롬프트는 SKILL의 절차를 **복제**해 담고 있다. 그 복제본이 낡아 2026-07-30 하루에 두 번(검증 순서, 선행 가드 구문) 고쳐야 했다. 절차의 출처가 둘이면 반드시 갈라진다.

호출형으로 바꾼다 — 루틴 프롬프트에는 **루틴만 아는 것**(타깃 선정, 선행 가드, 브랜치·PR 규칙)만 남기고 절차는 SKILL 단일 출처로:

```
vault/backlog.md 첫 미완료 항목을 타깃으로 `/reprompt --evolve --auto` 를 실행한다.
```

## 마이그레이션과 호환

- `/prompt-evolve` 직접 호출은 계속 동작한다 — `/reprompt --evolve`가 위임하는 대상이 그것이다. 진입점을 단일화하는 것이지 스킬을 없애는 것이 아니다
- `prompt-evolve` SKILL의 LEARN 마지막 항목(수동 `cp` 지시)을 `node scripts/build-plugin-bundle.mjs`로 교체한다
- 플러그인 `version` 1.0.0 → **1.1.0** (기능 추가, 파괴적 변경 없음)
- `RELEASING.md` 런북에 번들 생성 단계를 넣는다

## 검증

### TDD 순서 (전부 RED 먼저)

1. `build-plugin-bundle.test.mjs` — 생성물이 볼트와 바이트 일치 / **볼트에서 삭제된 파일이 번들에서도 사라지는지**(복사만으로는 안 되는 경로) / 재실행 멱등성

### 스탠드얼론 실증

레포 **밖** 임시 디렉토리에서 플러그인만 설치한 상태를 만들어 확인한다. 이것이 이 스코프의 존재 이유이므로 통과 없이 완료 선언하지 않는다.

- DNA를 번들에서 읽는가 (볼트가 없으므로 폴백 경로만 존재)
- 라이브러리 29종을 읽어 1층 히트가 나는가
- `--evolve`가 거부되는가
